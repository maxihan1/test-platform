## 🛑 §3. 내부 게이트 — 표를 승인받는다

표를 쓴 **직후** `AskUserQuestion` 으로 멈춘다. **산문 3지선다 금지.**

선택지 — `이대로 케이스 N건 만든다` / `표를 고쳐 달라` / `중단`

**근거** — 1등급은 게이트 1(계획 승인)이 없어서 파일 N 개를 다 쓴 뒤에야 사람이 본다.
분해가 어긋나 있으면 N 건을 통째로 다시 쓴다. **표는 싸고 케이스는 비싸다.**

**★ 합친 줄이 있으면(R15) 선택지를 하나 더 세운다.**

`합친 이름 이대로 케이스 N건 만든다` / `합친 이름을 고쳐 달라` / `표를 고쳐 달라` / `중단`

**산문 요약에 섞어 두고 「이대로」를 받는 것으로 갈음하지 마라.** 합친 케이스의 `name` 은
**관문 2 의 글자 대조에서 빠지는 유일한 문장**이라 여기서 눈에 안 띄면 **끝까지 아무도 안 본다.**
요약에는 셋을 적는다 — ① 어느 줄들을 합쳤나 ② **합친 `name` 한 문장** ③ 그 `tcId` 에
**저장된 입력값 묶음이 있으면 기대값 칸이 늘어난다**는 것.

`N` 은 표 줄 수가 아니라 **서로 다른 `tcId` 수**다.
