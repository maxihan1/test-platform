### 앱(Appium) — 공용 부품을 쓴다 (2026-11-15 · 정본 SPEC 도메인/러너 §5.2 「앱 공용 부품」)

기다리기 · 지금 화면 가르기 · 적기 · 토스트 · 권한 창은 kit 이 준다 — `import { 뜰때까지, 먼저뜨는것, … } from '@platform/kit/parts'`. 도우미 · 화면 객체가 kit 에서 값으로 가져올 수 있는 곳은 이 입구뿐이다(그 밖은 K7). 케이스도 부품은 여기서 가져온다 — `defineCase` · `test` · `verify` 는 지금처럼 `@platform/kit` 에서. **같은 일을 서비스 도우미에 다시 짜지 않는다.** 서비스 도우미에는 그 앱의 주소(id)와 화면 흐름(로그인 · 서버 고르기)만 둔다.

| 하려는 일 | 부품 |
|---|---|
| 요소가 뜨기 · 사라지기를 기다린다 | `뜰때까지(driver, 주소, 시간)` · `사라질때까지` — 됐는지를 돌려준다(던지지 않는다). 판정은 `verify` 로 |
| 조건이 될 때까지 기다린다 | `될때까지(driver, async () => …, 시간)` — 고정 시간 쉬기(`pause` · `setTimeout`) 대신 |
| 지금 보이나(기다리지 않고) | `보이나(driver, 주소)` |
| 지금 화면이 어느 것인가 | `먼저뜨는것(driver, { 시작: 주소, 홈: 주소 }, 시간)` — 먼저 보이는 것의 이름, 안 뜨면 `undefined` |
| 굴려야 보이는 요소 | `스크롤해서찾기(driver, 글자)` |
| 칸에 적는다 · 키보드를 내린다 | `칸에적기(칸, 값)` · `키보드완료(driver)` — 아래 「입력 칸」 줄 |
| 토스트 글 | `토스트글(driver, 상자 주소)` — 아래 「토스트 글은 한 번에」 줄. 시스템 토스트는 `//android.widget.Toast` |
| 권한 창 | `권한창답하기(driver, '허용' \| '거부')` — 뜨면 답하고 `true`, 안 뜨면 `false` |
| 권한을 준 · 뺀 상태에서 | `권한상태에서(driver, { 준다: [...], 뺀다: [...] }, async () => { … })` — 시험 대상 앱의 권한을 창 없이 바꾸고 구간이 끝나면 되돌린다. 이름은 `android.permission.…` 온 이름. 준 권한을 빼면 앱이 다시 켜진다(새로 준 권한은 구간 뒤에 빼니 그때도) — 그 다음 줄은 앱 화면을 기다린다 |
| 알림 창 · 푸시 | `알림창열기(driver)` 로 내리고 푸시 요소를 누른다. 닫기는 `driver.back()`, 시험 대상 앱으로 돌아오기는 `driver.activateApp(꾸러미)` |
| 요소 안에서 밀기 · 끌어 놓기 · 확대 축소 | `요소안에서밀기(driver, 주소, '위' \| '아래' \| '왼쪽' \| '오른쪽')` · `끌어놓기(driver, 집을 주소, 놓을 주소)` · `벌리기` · `오므리기(driver, 주소)` — 전부 요소 주소만 받는다. 화면 전체 굴리기는 `driver.swipe` · `스크롤해서찾기` |
| 서명 칸 · 패턴 잠금 · 그림판 — 요소 하나 안의 자리 | `요소위에그리기(driver, 주소, [[가로 %, 세로 %], …])` — 점은 그 요소 안 %(0~100). 점 하나면 누르기, 여럿이면 누른 채 긋기. 화면 좌표 · 지도 핀은 보류(SPEC 공통/2-명세선언 「요소가 없는 자리는 누르지 않는다」 예외) |
| 칸 비우기 · 폰 키 · 여러 칸 인증번호 · 클립보드 | `칸비우기(칸)` · `키누르기(driver, '홈' \| '최근 앱' \| '지우기' \| '탭' \| '붙여 넣기')` · `포커스칸에치기(driver, 값)` — 칠 때마다 다음 칸으로 넘어가는 화면만 첫 칸을 누른 뒤 쓴다(그 밖의 칸은 아래 「입력 칸」) · `클립보드읽기(driver)` · `클립보드쓰기(driver, 값)` |
| 빠르게 두 번 · 길게 누르기 · 앱 다시 켜기 | `두번누르기(칸)` · `길게누르기(driver, 주소)` · `앱다시켜기(driver, 꾸러미)` |
| 앱 생명 주기 | `뒤로보냈다오기(driver, 초)` · `딥링크열기(driver, 주소)` · `화면껐다켜기(driver)` · `앱비우기(driver, 인자?)` · `인자로켜기(driver, { 이름: 값 })` — `mobile: clearApp` · `mobile: startActivity` 를 직접 안 쓴다 · `앱다시깔기(driver)` · `옛판에서올리기(driver, async () => { … })` — 둘은 시험 대상 앱만(`tpx-author` `app.md` §3 「앱 생명 주기」) |
| 여러 요소의 글 | `글자들(driver, 주소)` |
| 앱 안 웹 화면(웹뷰) | `웹뷰에서(driver, async () => { … })` — 안에서는 웹 주소와 WebdriverIO(`waitForDisplayed` · `isDisplayed` · `setValue`)로 쓰고 위 네이티브 부품은 못 쓴다(`tpx-author` `app.md` §2) |

- **계속 움직이는 화면에서만 `움직이는화면에서(driver, async () => { … })` 로 감싼다** — 자동으로 넘어가는 배너 · 재생 중인 영상처럼 멈추지 않는 화면은 명령마다 10초를 꽉 채워 기다린다(폰 기록 「Waiting up to 10000ms for the device to idle」). 감싼 구간만 1초로 낮추고 끝나면 kit 이 되돌린다. **`updateSettings` 로 직접 낮추고 두지 않는다** — 그 10초가 다음 화면의 로딩을 기다려 주던 것이라, 낮춘 채로 넘어가면 로딩 중인 화면에서 요소를 못 찾는다. 구간 안에서 화면이 바뀌면 `뜰때까지` 로 직접 기다린다

### 앱(Appium) — 누르기 · 읽기 (2026-11-04 · 실행 21003 · 21004)

- **입력 칸은 누르지 않고 값만 넣는다**(`clearValue` · `setValue`) — 누르면 키보드가 뜬다. 내리려고 보낸 ESC 는 대화창을 닫고(UI-114 등 14건), 뒤로 가기는 키보드가 늦게 뜨는 안드로이드 13 에서 화면을 닫는다(FN-305 · 404). kit `칸에적기`
- **목록 끝에 잘린 칸은 읽지 않는다** — 안쪽 글 칸이 화면 구조에 없다. 다 보이는 칸만 읽고 나머지는 밀어서 다 보이게 한 뒤 읽는다(UI-089 · FN-325 · FN-345)
- **대화창이 떠 있으면 그 뒤 토스트 · 화면 글은 못 읽는다**(안드로이드 13) — 모든 창 보기(`enableMultiWindows`)도 안 잡혔다. 누른 뒤 곧바로 창을 닫고 읽는다. 토스트는 4초라 창을 닫기 전에 다른 확인을 하면 놓친다. 창이 남는지도 봐야 하면 그것을 먼저 보고 한 번 더 누른 뒤 닫는다(FN-260 · 357 · 360, DMA `취소하기눌러보기`)
- **토스트 글은 한 번에 찾아 읽는다** — 「떴나」와 「글」을 따로 물으면 느린 폰에서 그 사이에 사라진다. 상자 · 글 칸을 기다림 없이 찾아 글이 나올 때까지 되풀이한다(FN-260, kit `토스트글`)
- **빠르게 두 번 누르기는 하나만 들어가도 넘어간다** — 첫 누름으로 화면이 바뀌면 둘째는 「없음」 오류다. 판정은 결과(주문 수)로 한다(FN-404, kit `두번누르기`)
- **화면 글의 띄어쓰기 개수는 따지지 않는다** — 공백을 하나로 접은 뒤 견준다(UI-079 · 078)
- **줄을 이름표 낱말로 찾지 않는다** — 그 낱말이 화면에 없을 수 있다. 화면에서 읽은 꼴로 찾는다(UI-113 주소 줄은 「[06236] 서울 …」)
