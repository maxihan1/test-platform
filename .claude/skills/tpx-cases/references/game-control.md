## 게임 조작 — 끊기지 않게 움직이기 (2026-11-25 · GAME-F6-02)

움직이거나 싸우는 게임을 직접 해 보거나(탐색 플레이 · 학습) 그 조작을 케이스 · 미션에 쓸 때 연다. 정본은 명세 `docs/spec/도메인/게임.md` §3.10 「조작 도우미」다.

### 1. 메뉴는 CLI, 판은 조작 도우미

| 무엇을 하나 | 어떻게 |
|---|---|
| 창을 열고 닫기 · 글자 넣기 · 한 번 눌러 결과 보기 | `npx control-cli` 하나씩 — 명령마다 트리와 화면이 남는다 |
| 걷기 · 싸우기 · 줍기 · 시간 안에 여러 번 누르기 | 조작 도우미 — 함수 하나를 한 번에 돌린다(§2) |

CLI 는 명령마다 화면이 멎기를 최대 3초 기다렸다 찍는다. 게임 시간은 그동안에도 흘러 걷다 서고 맞다 진다. 같은 조작을 한 프로세스에서 보내면 명령 하나가 0.04초쯤이다(2026-11-25 Cats Go! 실측 — 눌러 둔 채 위치를 2.5초에 57번 읽었다).
**AI 는 작전을 정하고 손은 스크립트가 움직인다** — 판을 시작하기 전에 무엇을 언제 할지 정해 함수로 쓰고, 판이 끝난 뒤 기록을 보고 하나만 고친다. 판 도중에 명령을 하나씩 생각해 보내지 않는다.

### 2. 조작 도우미 — 쓰고 부르기

`tests/<폴더>/helpers/<이름>.helper.ts` 에 첫 인자가 `game` 인 함수를 쓰고 이 명령으로 돌린다. `game` 은 케이스 몸통이 받는 것과 같은 드라이버다 — 여기서 된 함수를 케이스 · 미션이 그대로 부른다.

```bash
npx tsx scripts/authoring-game-play.ts <폴더> <이름> <함수> '<인자 JSON 배열>' --max 180
```

- 디바이스를 잡고(`npx control-cli hold` — PC 게임은 `--pc`) 게임을 켜 둔 채 부른다. 한 번에 450초까지(기본 120초)다. 더 긴 판은 함수를 나눠 이어 부른다 — 게임은 그대로 돈다
- 함수가 던지거나 한도를 넘겨도 눌러 둔 키 · 손가락을 놓고 시간 배율을 부르기 전 값으로 되돌린다
- 돌려준 값 · 그 사이 게임 로그 · 오류 · 장면 알림을 찍고, 원본과 끝 화면은 `<자료 폴더>/game-play/` 에 남긴다. **돌려주는 값은 필요한 것만 짧게** — 8,000자에서 잘린다
- 첫 인자가 `game` 인 GM 명령 도우미도 이 명령으로 부른다(`authoring-game-state.ts` 는 첫 인자가 `admin` 인 것만)

### 3. 쓰는 꼴

```ts
import type { GameDriver } from '@platform/kit';

type 자리 = [number, number, number];
const 위치 = (game: GameDriver) => game.get('/Player(Clone)', 'Transform.position') as Promise<자리>;

export async function 누른채로<T>(game: GameDriver, 키: string, 읽기: () => Promise<T>, 됐나: (값: T) => boolean, 한도초: number): Promise<T> {
  const 끝 = Date.now() + 한도초 * 1000;
  await game.keyDown(키);
  try {
    for (;;) {
      const 값 = await 읽기();
      if (됐나(값) || Date.now() >= 끝) return 값;
    }
  } finally {
    await game.keyUp(키);
  }
}

export async function 오른쪽으로(game: GameDriver, 목표x: number): Promise<{ 닿음: boolean; x: number }> {
  const 처음 = await 위치(game);
  const 뒤 = await 누른채로(game, 'RightArrow', () => 위치(game), (p) => p[0] >= 목표x, 10);
  return { 닿음: 뒤[0] >= 목표x, x: 뒤[0] - 처음[0] };
}
```

- **누르고 → 읽고 → 떼기** — 얼마나 눌러야 하는지 시간으로 어림하지 않는다. 눌러 둔 채 값(위치 · 체력 · 개수)을 읽다가 되면 뗀다. `key(이름, { duration })` 은 그 시간 동안 아무것도 못 읽는다 — 짧은 누르기 · 길이가 정해진 누르기에만 쓴다
- **두 방향 · 조합** — `keyDown('W')` 뒤 `keyDown('D')`, 방향을 바꿀 때는 놓을 것만 `keyUp`. 한 번에 누르는 조합은 `key('A+LeftShift')`
- **되풀이 규칙** — 「체력이 줄면 기지로 · 자원이 되면 심기 · 떨어진 것 줍기 · 가까운 적이면 공격」을 위에서부터 보고 맞는 것 하나를 하는 반복으로 쓴다. 판마다 규칙 하나만 고친다
- **판 기록** — 반복 안에서 1초쯤마다 한 줄(지난 시간 · 체력 · 자원 · 처치 · 내 위치)을 배열에 모아 돌려준다. 오래 도는 함수는 같은 줄을 `console.log` 로도 찍는다
- **폰 터치** — 버튼 하나는 `touchDown(주소)` → 읽기 → `touchUp(번호)`, 끌기는 `drag(주소, 닿을 주소, { duration })`. 화면 좌표는 쓰지 않는다. 게임 안 위치 값은 쓴다
- **끝에 다 놓는다** — `finally` 에서 `keyUp` · `touchUp` 을 부른다. 케이스에서 눌린 채 끝나면 다음 단계까지 남는다
- **누르는 시간은 실제 시간이다** — 시간 배율을 0.25 로 낮추면 1초를 눌러도 게임에서는 0.25초만 간다(같은 실측 — 원래 속도 5.99칸 · 0.25배 1.56칸). 늦춰서 익힌 조작은 원래 속도로 다시 해 본다. 케이스는 늘 원래 속도다 — 케이스와 도우미에서 시간 배율을 바꾸지 않는다

### 4. 안 될 때 볼 차례

1. 기록의 끝 화면 — 다른 창이 떠 있나(공지 · 일시정지)
2. 읽은 값이 안 바뀐다 — 주소가 다른 복제본이다(`(Clone)` · 여러 명). `control-cli find` 로 다시 찾는다
3. 키가 안 먹는다 — 게임이 읽는 입력이 무엇인지 본다(`ping` 의 `input`). 메뉴가 포커스를 쥐고 있으면 먼저 닫는다
4. 같은 자리에서 세 번 안 되면 방법을 바꾼다 — 같은 명령을 되풀이하지 않는다
