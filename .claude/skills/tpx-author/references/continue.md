# tpx-author — 남은 요구로 이어 작성

프롬프트에 `--- 이어 작성 ---` 절이 있으면 이 파일을 따른다. 없으면 상관없다.
**정본은 `docs/spec/도메인/작성.md` §3.6 「★ 원장」 「남은 요구로 이어 작성」이다.** 여기는 자식이 할 일만 적는다.

이 요청은 **반영(병합)이 끝난 앞 요청**이 다 못 덮은 요구만 맡는 새 요청이다. 자료(기획서)와 대조 설정은 앞 요청 것 그대로다.
작업방은 main 판이다 — **앞 요청의 표 · 케이스가 이미 들어 있다.** 이어하기(`resume.md`)와 다르다 — 그쪽은 멈춘 작업방을 넘겨받고, 이쪽은 병합된 main 에서 새로 연다.

## 1. 맡을 번호

- 절에 적힌 **`continue.json` 의 `남은` 이 이번 일 전부**다. 에이전트가 main 표와 원장을 맞대 뽑았다 — 「다음 요청」 제외와 「빠짐」이다
- 그 밖의 번호는 앞 요청이 끝냈다(케이스 · 닫힌 제외). **다시 맡지 않는다**

## 2. 표 — 이미 있는 줄은 손대지 않는다

`docs/cases/<접두사>.md` 는 새로 쓰지 않는다. 남은 번호마다 이렇게 한다.

| 그 번호가 표에서 | 할 일 |
|---|---|
| 「제외」의 `다음 요청` 줄 | 케이스로 만들면 **그 제외 줄을 지우고** 「요구사항」에 케이스 줄을 더한다. 이번에도 시간 안에 못 하면 줄을 그대로 둔다 |
| 어디에도 없다(빠짐) | 케이스 줄 또는 맞는 종류의 「제외」 한 줄(`2-requirements.md` 「원장」) |

- **새 줄 출처 칸에는 남은 번호만 적는다** — 앞 요청이 덮은 번호를 같이 적으면 그 번호의 칸으로 가서 앞 케이스 tcId 를 물려받고, 앞 케이스를 고쳐야 한다(도메인/작성 §3.6 「칸과 번호」 2026-10-04)
- **남은 번호가 아닌 줄은 고치지 않는다** — 앞 요청의 요구 줄 · 케이스 · 「요구 아님」 · 「되돌릴 수 없음」 · 「자료 없음」 · **「사람이 뺌」** 전부. 사람이 병합 뒤 고친 줄일 수 있다
- tcId 는 `npm run ledger:number` 가 매긴다(`SKILL.md` 2단계) — 앞 요청의 줄은 안 건드리고 새 줄만 칸 번호를 받는다. 앞 케이스의 tcId 를 다시 쓰지 않는다. 명령이 종료 코드 2 면 종류별로 표와 `tests/<폴더>` 에 이미 있는 가장 큰 번호 다음부터다(UI 는 `-UI-` 번호열, 기능은 옛 꼴과 `-FN-` 을 통틀어 — `two-kinds.md` R17)
- `다음 요청` 을 새로 적지 않는다 — 관문 0 이 형식 오류로 잡는다(`SKILL.md` 「멈출 때」와 같다). 남은 번호가 많아 다 못 하면 **했던 것까지 관문을 통과시키고** 나머지는 `다음 요청` 줄을 그대로 둔다 — 다음 이어 작성이 맡는다

## 3. 역방향(대조) 원본이면

프롬프트에 `--- 역방향 ---` 절도 같이 있으면 `reverse.md` 를 따르되 **범위를 남은 번호로 좁힌다.**

- **훑기** — 남은 번호의 요구가 말하는 화면(과 그 한 칸)만 본다. 앞 요청이 본 화면을 다시 훑지 않는다 — 훑기 예산(30분)을 남은 것에 쓴다
- **`diffs.json`** — 남은 번호에서 찾은 차이만 적는다. 차이 번호는 `D1` 부터 새로 매긴다(이 요청의 차이다)
- **표시 · 역기획서** — 에이전트가 이번 요청의 `diffs.json` 으로 만든다. 앞 요청이 표시한 것을 다시 적지 않는다
- 미확정 꼬리표 사유의 「작성 요청 N」은 **이번 요청 번호**다(에이전트가 역방향 절에 적어 준다)

## 4. 관문은 전부 — 원장 대조는 전체 원장으로

- 관문 0 은 원장 절의 명령 그대로다 — **전체 원장**을 main 표 + 이번에 더한 줄로 맞댄다. 앞 요청이 덮은 번호도 그대로 덮여 있어야 초록이다
- 관문 1~4 는 `SKILL.md` 의 명령 그대로다 — 폴더 전체를 돈다(보통 작성이 이미 케이스가 있는 서비스에서 도는 것과 같다)
- 결과 요약(`SKILL.md` 「결과 요약」)에 한 줄을 더한다 — `이어 작성: 작성 요청 <원본> 의 남은 요구 N개 → 케이스 a · 제외 b · 다음 요청으로 남김 c`
