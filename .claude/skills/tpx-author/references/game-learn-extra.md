# 게임 배우기 — 그때 여는 글 (2026-11-25 · GAME-F6-05)

`game-learn.md` 를 따르다가 아래 일이 생겼을 때만 연다. 정본은 명세 `docs/spec/도메인/게임.md` §3.10 「게임 배우기」 · 「게임에 대해 배운 것」이다.

## 랜덤

같은 조건인데 결과가 다르면 바로 「뒤집힘」이나 버그로 적지 않는다. 잰 실수(시점 · 지연) · 아직 모르는 조건 · 남(봇 · 사람이 디바이스를 만짐)을 먼저 찾고, 남은 것이 랜덤이다.

- **횟수** — 랜덤일 만한 것(글에 확률 · % · 드랍 · 치명 · 랜덤, 전투 결과 · 등장 · 보상 · 선택지)은 **10번부터**, 확률을 말하려면 **30번부터**다. 모자라면 「n번 중 k번」만 적고 `SEEN` 이다. 앞 세션이 같은 빌드 · 같은 조건으로 잰 것이 있으면 그 수에 이어 센다
- **꼴**(`shape`) — 고정 `FIXED` · 폭 `RANGE`(본 최소~최대) · 확률 `RATE`(k/n) · 목록 `LIST`(나온 것마다 횟수) · 앞에 매임 `DEPENDS`(천장 · 셔플 — 나온 순서도) · 모름 `UNKNOWN`. 본 범위를 한도로, 본 비율을 확률로 적지 않는다
- **방법을 견줄 때** — 이겼다 졌다만 보지 않고 게임이 주는 숫자로 본다. 3판에 크게 다르면 끝, 애매하면 10판까지 간 뒤 되돌린다
- **줄인다** — 대상 하나 · 자리 고정 · 같은 시작 조건. 서버 게임은 결과 고정 명령이 있으면 쓴다. 난수 씨앗 고정은 배울 때만이고 그렇게 본 것은 `marks: ["SEED"]` 다(분포 근거가 아니다)

## 서버가 있는 게임

- 가이드에 적힌 서버 로그 · API 도 「볼 눈」이다
- GM · 어드민 API 는 **시작 조건을 맞출 때만** 쓴다. 캐릭터는 이름이 `qacrawl` 로 시작하는 것만 만들어 쓰고 서버 전체 초기화는 하지 않는다
- 만든 캐릭터는 세션 사이에 지우지 않는다 — 다음 세션이 잇고, 케이스를 쓰는 세션이 작성 끝에 지운다(`game.md` §4)
- 사람이 쓴 서비스 가이드와 잰 것이 다르면 가이드를 따르고 그 줄에 `marks: ["HUMAN"]` 을 단다. 다시 재도 계속 다르면 `ODD` 다

## 오래 걸리는 것

- 성장표는 다 채우지 않고 몇 점만 잰다(처음 · 초반 둘 · 중간 · 끝). 중간부터는 시작 조건(GM · 시험 기능)으로 맞춘다
- 판 사이 되풀이(돈 모으기)는 스크립트만 돌린다. 이때만 시간 배율을 올려도 된다 — 그때 본 시간 · 값은 근거로 쓰지 않는다
- 날짜가 바뀌어야 보이는 것은 시계를 바꾸지 않는다. `ASK` 줄 `data` 에 `"볼날": "YYYY-MM-DD"` 를 적으면 그날부터 배울 것이 된다

## 여럿이 하는 게임

한 명으로 먼저 배우고, 둘이면 무엇이 달라지나(참가 · 화면 나눔 · 재화 나눔 · 상대 수 · 승패 · 한 명 나가기)를 `ASK` 로 둔다. 두 명은 한 함수에서 키보드(1P)와 가상 패드(2P)를 번갈아 돈다 — 2P 는 서 있기부터. 세 명부터와 다른 사람의 계정이 있어야 하는 것은 `"막힘": "아직 안 해 봄 — <까닭>"` 이다.

## 기본 종류에 안 맞는 줄

기본 종류에 안 맞는 줄이 **셋** 모였을 때만 `KIND` 줄(열쇠 `kind:<이름>` — 답하는 질문 · 예 · 기본 종류로 왜 안 되나)로 새 종류를 만든다. 게임 하나에 스무 개까지다. 세션 끝에 겹치는 종류는 합치고 줄이 셋 밑인 종류는 되돌린다.
