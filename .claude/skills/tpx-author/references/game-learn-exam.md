# 배운 것 시험 — 지도만 보고 (2026-11-25 · GAME-F6-03 · F6-05 에서 뗌)

게임 시험 세션만 이 파일을 연다. 정본은 명세 `docs/spec/도메인/게임.md` §3.10 「게임 배우기」 「시험」이다.

`game-exam.json` 의 줄(확인된 것)이 정말인지 본다. 기획서 · 가이드 · `game-play/` · `game-guide.txt` 를 열지 않는다. 지도는 찾기 명령으로 읽는다. 디바이스는 놓지 않는다(`release` 금지 — 에이전트가 놓는다). 앞 세션이 끊긴 채라면 `npx control-cli -s=g input-reset` 부터 한다.

1. **첫 판을 끝까지** — 지도와 조작 도우미만으로 첫 스테이지를 시작부터 판이 끝날 때까지 한다(이기든 지든). 조작 도우미 부르기 명령이 찍은 기록 파일 이름을 적는다
   ```bash
   echo '{"끝":true,"이김":false,"까닭":"<어디서 왜 끝났나>","기록":"<기록 파일 이름>.json"}' | npx tsx scripts/authoring-learn-exam.ts <자료 폴더> 판
   ```
2. **예측** — 시험감마다 `잰것` 에 **없는 조건**을 하나 정하고 값을 먼저 적는다. 적은 예측은 못 고친다
   ```bash
   echo '[{"열쇠":"rule:<이름>","조건":"<안 해 본 조건>","예측":{"값":5}},{"열쇠":"calc:<이름>","조건":"<안 해 본 조건>","예측":{"최소":3,"최대":8}}]' | npx tsx scripts/authoring-learn-exam.ts <자료 폴더> 예측
   ```
   고정 줄은 값, 재는 값이 흔들리는 시간 · 위치와 랜덤 줄은 범위, 나올 것이 정해진 줄은 `{"목록":[…]}` 이다
3. **재기** — 원래 속도로 잰다(`--freeze` 를 쓰지 않는다). 랜덤 줄은 세 번 이상 재서 다 적는다. 잰 것은 지도 줄의 표본에도 더해 적는다(`npx tsx scripts/authoring-learn-note.ts <자료 폴더>` — 같은 열쇠를 다시 적으면 통째로 바뀌니 앞에 잰 것을 같이 옮긴다)
   ```bash
   echo '[{"열쇠":"rule:<이름>","잰값":[5]},{"열쇠":"calc:<이름>","못잼":"<까닭>"}]' | npx tsx scripts/authoring-learn-exam.ts <자료 폴더> 결과
   ```
4. 맞혔나는 프로그램이 매긴다 — 틀린 줄은 프로그램이 「덜 봄」으로 내린다. 스스로 믿음을 고치지 않는다. 다 했으면 「시험 끝」 한 줄로 끝낸다
