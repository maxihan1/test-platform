# tpx-author — 고친 요구만 다시 작성(반영)

프롬프트에 `--- 반영 ---` 절이 있으면 이 파일을 따른다. 없으면 상관없다.
**정본은 `docs/spec/도메인/작성.md` §3.6 「★ 표준 기획서」 「사람이 고칠 때」 「고친 요구만 다시 작성」이다.** 여기는 자식이 할 일만 적는다.

사람이 「PRD 관리」에서 요구를 고치고 「바뀐 요구 N건 테스트에 반영」을 눌렀다. **자료(기획서)는 없다** — 표준 기획서가 입력이다.
작업방은 main 판이라 **표 · 케이스가 이미 들어 있다.** 이 요청은 그중 바뀐 요구에 닿는 것만 고친다. 다른 줄 · 케이스는 손대지 않는다.

## 1. 맡을 것 — `apply.json`

절에 적힌 `apply.json` 이 이번 일 전부다. 에이전트가 기준 판(마지막 반영 때 판)과 지금 판을 견주고, main 표(지도 ①)에서 덮던 케이스를 찾아 적었다.

| 칸 | 뜻 |
|---|---|
| `다시씀[]` | 문장이 바뀐 요구. `옛문장` · `새문장` · `다시쓸종류`(정상 · 경계 · 예외 · UI 가운데) · `케이스`(그 번호를 덮던 tcId 와 축) |
| `새항목[]` | 덮는 케이스가 없는 번호 — 새로 더했거나, 바뀌었는데 표가 아직 안 덮었다 |
| `지움[]` | 지운 번호. `지울케이스` 는 그 번호만 덮던 것 · `남길케이스` 는 다른 요구도 덮는 것 |

요구 문장은 원장 사본의 `문장` 에서 읽는다(`prd.md` §5). `옛문장` 이 `null` 이면 기준 판에 없던 번호인데 표가 이미 덮고 있다(기준 판이 없거나 새로 더한 번호) — 그 번호의 케이스를 네 종류 모두 새 문장으로 고쳐 쓴다.

## 2. 다시씀 — 종류별로 고쳐 쓴다

- **`다시쓸종류` 에 든 축의 줄 · 케이스만 새 문장대로 다시 쓴다.** 정상 · UI 는 문장이 바뀌면 늘 든다. 경계 · 예외는 설계(경계 값 · 예외 기법)가 바뀌었을 때만 든다 — `npm run ledger:design -- <원장 사본>` 이 새 칸과 시험 값을 준다
- **덮던 케이스가 있으면 새로 만들지 않고 그 파일을 고친다.** 표 줄의 tcId 는 그대로 둔다 — 같은 칸이면 번호 명령이 같은 번호를 준다
- 새 설계에 칸이 생기면(예: 한도가 생겨 경계 칸) 표에 줄을 더하고 `npm run ledger:number` 로 번호를 받는다. 칸이 없어지면 그 줄을 지우고 케이스를 「지움」과 같은 방법으로 지운다(아래 3)
- **`다시쓸종류` 에 없는 축은 그대로 둔다.** 다만 그 케이스의 기대값(숫자 · 문구)이 새 문장과 정면으로 어긋나면 그 기대값만 고친다 — 고친 것은 결과 요약에 tcId 로 적는다
- 표 줄의 결과 칸 · 조작 칸은 새 문장대로 고친다. 케이스의 `verify` 는 표 결과 칸 그대로다(R11)

## 3. 새 항목 · 지움

- **새 항목** — 보통 작성처럼 표에 줄을 더하고 케이스를 쓴다(`SKILL.md` 2 · 4단계). 출처 칸은 그 번호다
- **지움** — `지울케이스` 는 케이스 파일을 지우고 표의 그 tcId 칸을 「제거함(<tcId>)」로 바꾼다(보류 케이스 제거와 같은 꼴). 다른 칸은 그대로 둔다
- `남길케이스` 는 파일을 남기고 **지운 번호만 출처로 단 표 줄**을 지운다. 그 줄의 확인(`verify` 단계)도 케이스에서 뺀다. 출처에 다른 번호도 적힌 줄은 지운 번호만 출처 칸에서 뺀다
- 지울 케이스를 쓰는 Page Object · Component 는 다른 케이스가 안 쓰면 같이 지운다
- 에이전트가 끝난 뒤 `지울케이스` 파일이 남았는지 보고 PR 본문 머리에 경고로 띄운다 — 못 지운 까닭이 있으면 결과 요약에 적는다

## 4. 관문은 전부

- 관문 0 은 원장 절의 명령 그대로다 — **전체 원장**을 main 표 + 이번에 고친 줄로 맞댄다. 맡지 않은 번호도 그대로 덮여 있어야 초록이다
- 관문 1~4 는 `SKILL.md` 그대로다 — 폴더 전체를 돈다
- 결과 요약(`SKILL.md` 「결과 요약」)에 한 줄을 더한다 — `반영: 다시 씀 a(고친 케이스 b) · 새 항목 c(새 케이스 d) · 지움 e(지운 케이스 f · 남긴 케이스 g)`
