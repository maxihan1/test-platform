# /tpx-author

맥 작성 경로 전용 체인. **`/tpx` 일곱 단계를 타지 않는다** — [6] 독립 검사는 관문 넷과 겹치고
[7] 병합은 사람이 화면에서 누르므로 자식이 할 일이 없다 (2026-09-23 첫 한 바퀴 실측,
`docs/plans/2026-09-23-작성-전용체인.md`).

**맥이 작업방을 만들고, 자식은 파일만 남기고, 맥이 commit·push·PR 을 한다.**
정본 흐름은 `docs/spec/도메인/작성.md` §3.6 이다.

## 입력 — 맥이 프롬프트로 준다

- **자료 목록** — 파일 경로와 원래 이름, 피그마 주소
- **tcId 접두사** — 서비스 단위 (`tpx-cases` §1 의 2)
- **테스트 폴더** — `tests/<폴더>`
- **대상 화면 주소** — 없으면 아래 「멈출 때」를 따른다

## 선행 읽기

**없음.** `tpx-cases` 를 따라 읽는 것 말고는 여는 것이 없다. `/tpx` 컨트롤러와 명세 장을 싣지 않는다.

---

## 하지 않는 것

맥이 전부 한다. 자식이 하면 맥의 commit·push 와 부딪히거나 턴이 먼저 끝나 멈춘다.

- **git 명령 전부** — commit·branch·checkout·stash·push 포함
- **gh 명령 전부** — PR 만들기·ready·병합
- **`/tpx` 와 다른 체인 스킬 호출**
- **Bash 의 `run_in_background`** — 모든 명령은 앞에서 끝까지 기다린다
- **AskUserQuestion** — 답할 사람이 없다. 사람은 PR 본문에서 표를 본다
- **작업 폴더 밖 파일 수정** — 바꾸는 것은 `tests/<폴더>/*.spec.ts` 와 `docs/cases/<접두사>.md` 뿐이다.
  다른 파일이 바뀌면 맥이 push 를 거부한다

---

## 절차 — `tpx-cases` 를 이 순서로 따른다

`tpx-cases` 의 규칙(R1~R16 · 관문 넷 · 종료 조건)을 **그대로** 쓴다. 이 스킬이 덮어쓰는 것은
아래 적은 자리뿐이다. `tpx-cases` 가 git·초안 PR·[6]·게이트 2 를 전제로 적은 문장은 **이 스킬이 이긴다.**

1. **§1 입력 확인** — 「입력은 자료 목록이다」대로 자료를 전부 읽는다
2. **§2 요구사항 표** — `docs/cases/<접두사>.md` 에 쓴다. **중간에 멈추지 않는다**
3. **§3 내부 게이트는 건너뛴다** — 표를 그대로 확정한다. 게이트가 물었을 것
   (합친 줄의 `name` · 자료 어긋남으로 `판정 불가` 가 된 줄)은 **결과 요약에 싣는다.** 사람이 PR 본문에서 본다
4. **§4 selector 확정 → §5 케이스 작성**
5. **§6 관문 넷** — 형식 · 표 대조 · 3회 실행 · 일부러 부수기
6. **§7 표 되채우기** — 1~3 만. **4 커밋은 하지 않는다** (맥이 한다)

관문 1·3 명령은 `tpx-cases` §6 과 같다. 파이프로 넘기지 않는다.

```bash
npm run typecheck   > /tmp/tc.log 2>&1; echo "EXIT=$?"
npm run check:tests > /tmp/ct.log 2>&1; echo "EXIT=$?"
npx playwright test tests/<폴더> --project=desktop --repeat-each=3 --reporter=line > /tmp/pw.log 2>&1; echo "EXIT=$?"
```

## 멈출 때

`tpx-cases` 가 「멈추고 묻는다」고 적은 자리에서는 **묻지 않고 거기서 끝낸 뒤 결과 요약에 사유를 싣는다.**

- **피그마를 못 읽었다** — `tpx-cases` §1 의 3 대로 표에 `못 읽음: <주소> — <에러 첫 줄>` 을 적고 **§3 이후로 가지 않는다**
- **대상 화면 주소가 없다** — selector 를 확정할 수 없으므로 표까지만 쓰고 멈춘다
- **케이스가 같은 이유로 3회 빨강** — `tpx-cases` §6 종료 조건대로 그 케이스만 `보류` 로 두고 나머지는 계속 간다

## 끝내기 전에

**띄운 명령이 전부 끝났는지 확인하고 끝낸다.** 첫 한 바퀴에서 자식이 background 검사를 기다린다며
턴을 먼저 끝내 맥이 멈췄다 (2026-09-23).

## 결과 요약 — 마지막에 표준출력에 찍는다

맥이 이것을 PR 본문에 싣는다. **관문 3 의 3회 실행 결과가 병합 근거다** — CI 가벼운 길은 케이스를 돌리지 않는다.

```
요구사항 N줄 → 케이스 M건 · 합친 것 J건 · 보류 K건
관문 1 형식: EXIT=<값>
관문 2 표 대조: <일치 / 어긋난 줄>
관문 3 3회 실행: <pw.log 의 마지막 요약 줄 그대로 — 예: 9 passed> · EXIT=<값>
관문 4 부수기: <무엇을 바꿨나 · 어느 문장이 빨개졌나>
합친 것: <tcId · 합친 name 한 문장 · 어느 요구 줄들인지>
판정 불가·보류: <사유 한 줄씩>
못 읽은 자료: <주소나 파일 — 에러 첫 줄 / 없음>
표: docs/cases/<접두사>.md
```

멈춘 경우에도 이 모양으로 찍고, 못 간 관문은 `안 돌림(<사유>)` 으로 적는다.
