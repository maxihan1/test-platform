11. API (API)

화면이 쓰는 기능을 같은 서버의 /api 아래 JSON 으로 제공한다. 로그인은 쿠키 세션으로 유지된다.

11.1 공통 규칙

  --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  ID            요구사항                                                                                                                                                                                                                                       구분
  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- -------------------
  REQ-API-001   요청과 응답 본문은 JSON 이다. 성공은 200(조회 · 수정) · 201(생성) · 204(삭제, 본문 없음) 로 응답한다.                                                                                                                                          필수

  REQ-API-002   실패는 { "code": "...", "message": "..." } 형태로 응답한다. 입력 오류 400 VALIDATION, 로그인 필요 401 UNAUTHORIZED, 권한 없음 403 FORBIDDEN, 없음 404 NOT_FOUND, 충돌 409 CONFLICT 이다. message 는 화면에 그대로 보여 주는 한국어 문장이다.   필수

  REQ-API-003   목록 조회는 page(1부터) · size 를 받고 { "items": [...], "total": N, "page": N, "size": N } 로 응답한다.                                                                                                                                       필수

  REQ-API-004   POST /api/reset 은 모든 데이터를 테스트 계정 표의 초기 상태로 되돌리고 204 로 응답한다.                                                                                                                                                        필수

  REQ-API-005   일부 응답은 네트워크 상황에 따라 0.1~1.5초 늦게 올 수 있고, 리뷰 조회는 가끔 500 UNAVAILABLE 로 실패할 수 있다. 화면은 이 경우에도 REQ-COM-008 · REQ-SHP-026 대로 동작해야 한다.                                                               필수
