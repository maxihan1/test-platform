2. 공통 (COM)
ID
요구사항
구분
REQ-COM-001

필수
REQ-COM-002
“커뮤니티” 메뉴에 마우스를 올리면 하위 메뉴 “자유게시판” · “질문게시판” · “후기게시판” 이 펼쳐지고, 마우스를 치우면 닫힌다. 하위 메뉴를 누르면 해당 분류가 선택된 게시판 목록으로 간다.
필수
REQ-COM-003
비로그인 상태에서는 오른쪽에 “로그인” · “회원가입” 링크가 보인다. 로그인 상태에서는 “{이름}님” · “마이페이지” · “로그아웃” 이 보이고, 관리자에게는 “관리자” 링크가 추가로 보인다.
필수
REQ-COM-004
장바구니 아이콘 옆에 담긴 상품 줄 수가 빨간 숫자 배지로 나온다. 0개면 배지를 숨긴다. 비로그인 상태에서는 배지를 숨긴다.
필수
REQ-COM-005
로그인 상태에서는 머리글에 알림 종 아이콘이 있다. 내 글에 새 댓글이 달리면 종 옆에 읽지 않은 알림 수가 나온다. 종을 누르면 알림 목록이 펼쳐지고, 목록을 열면 모두 읽음 처리되어 숫자가 사라진다. 알림 수는 10초마다 새로 가져온다.
선택
REQ-COM-006
로그인이 필요한 화면(글쓰기 · 장바구니 · 주문서 · 마이페이지 · 1:1 문의)에 비로그인으로 들어가면 로그인 화면으로 보낸다. 로그인하면 원래 가려던 화면으로 돌아간다.
필수
REQ-COM-007
처리 결과는 화면 아래 가운데에 짧은 알림(토스트)으로 3초간 보여 주고 사라진다.
필수
REQ-COM-008
서버 응답을 기다리는 동안 버튼은 눌리지 않게 막고 버튼 글자 대신 로딩 표시를 보여 준다.
필수
REQ-COM-009
없는 주소로 들어가면 “페이지를 찾을 수 없습니다” 화면과 “홈으로” 버튼을 보여 준다.
필수
REQ-COM-010
화면 아래쪽에 바닥글이 있고 “이용약관” · “개인정보처리방침” 링크와 “© 2026 DemoMarket” 문구가 있다. 페이지를 한 화면 이상 내리면 오른쪽 아래에 “맨 위로” 버튼이 나타나고, 누르면 맨 위로 올라간다.
선택
REQ-COM-012
페이지를 80px 이상 내리면 머리글이 화면 위에 붙어 따라 내려오고 높이가 64px 에서 48px 로 줄어든다.
필수
REQ-COM-013
처음 방문하면 화면 아래에 쿠키 안내 띠 “서비스 개선을 위해 쿠키를 사용합니다.” 와 “동의” 버튼이 나온다. “동의” 를 누르면 사라지고 이 브라우저에서는 다시 나오지 않는다. 동의하기 전까지 띠는 화면 아래 내용을 덮는다.
필수
REQ-COM-014
모달과 팝업은 0.3초 동안 서서히 나타나고 서서히 사라진다. 토스트는 아래에서 밀려 올라온다.
선택
REQ-COM-011
화면 너비가 768px 이하면 메뉴가 햄버거 버튼 하나로 접힌다. 버튼을 누르면 메뉴가 왼쪽에서 밀려 나온다.

요구사항

REQ-HOME-002

필수
REQ-HOME-004

필수
REQ-HOME-005

필수
REQ-HOME-006

필수
REQ-HOME-007
배너 아래에 “인기글” · “최신글” 탭이 있다. 기본은 “인기글” 이고 좋아요 순 5건, “최신글” 은 작성 순 5건을 보여 준다. 글 제목을 누르면 게시글 상세로 간다.
필수
REQ-HOME-008
탭 아래에 “추천 상품” 8개가 가로 한 줄로 나오고 좌우로 넘겨 볼 수 있다. 추천 상품의 순서는 홈에 들어올 때마다 무작위로 바뀐다. 상품 카드에 마우스를 올리면 상품 설명 한 줄이 말풍선(툴팁)으로 뜬다.
선택
REQ-HOME-009
탭 위에 “타임세일 종료까지 HH:MM:SS” 카운트다운이 있고 1초마다 줄어든다. 종료 시각은 매일 자정이다.
필수
REQ-HOME-010
홈을 연 뒤 이벤트 띠 배너 “🎉 가을 맞이 전 상품 무료 배송” 이 서버에서 늦게 도착해 배너와 탭 사이에 끼어 들어간다. 띠가 들어오면 그 아래 내용이 아래로 밀려난다. 띠의 X 를 누르면 닫힌다.
필수
REQ-HOME-011
홈에 머문 지 5~15초 사이 어느 시점에 “만족도 설문” 모달이 뜬다. “참여하기” 는 고객센터로, “다음에” 는 모달을 닫는다. 한 번 닫으면 브라우저 탭을 닫기 전까지 다시 뜨지 않는다.

4.1 회원가입
ID
요구사항
구분
REQ-MEM-001

필수
REQ-MEM-002
아이디 옆 “중복 확인” 버튼을 누르면 이미 있는 아이디일 때 “이미 사용 중인 아이디입니다”, 없는 아이디일 때 “사용 가능한 아이디입니다” 를 보여 준다. 중복 확인을 하지 않았거나 확인 뒤 아이디를 고치면 가입할 수 없다.

REQ-MEM-004

REQ-MEM-005
비밀번호 입력칸 오른쪽 눈 모양 버튼을 누르면 입력한 비밀번호가 글자로 보이고, 다시 누르면 가려진다.
선택
REQ-MEM-006
이름(필수, 2~10자) · 이메일(필수, 이메일 형식) · 휴대폰(선택, 숫자만 10~11자) · 생년월일(선택, 날짜 선택기) 을 입력받는다. 휴대폰 칸에는 숫자 외의 글자가 입력되지 않는다.
필수
REQ-MEM-007
성별은 “선택 안 함” · “남성” · “여성” 라디오 버튼이며 기본값은 “선택 안 함” 이다.
필수
REQ-MEM-008
관심 분야는 “패션” · “전자기기” · “도서” · “식품” 중 여러 개를 고를 수 있는 체크박스다. 최대 3개까지 고를 수 있고, 4번째를 고르면 토스트 “관심 분야는 최대 3개까지 선택할 수 있습니다” 가 나오고 선택되지 않는다.
필수
REQ-MEM-009
약관은 “(필수) 이용약관 동의” · “(필수) 개인정보 수집 동의” · “(선택) 마케팅 수신 동의” 세 개다. “전체 동의” 를 체크하면 셋이 모두 체크되고, 셋 중 하나라도 해제하면 “전체 동의” 도 해제된다.
필수
REQ-MEM-010
각 약관 옆 “보기” 를 누르면 약관 전문이 모달로 뜬다. 모달은 “확인” 버튼 · 오른쪽 위 X · 바깥 영역 클릭 · ESC 키로 닫힌다.
필수
REQ-MEM-011
필수 항목이 모두 채워지고 필수 약관 둘에 동의해야 “가입하기” 버튼이 눌린다.
필수
REQ-MEM-012

필수
REQ-BRD-005
검색 조건 드롭다운 “제목” · “내용” · “작성자” 중 하나를 고르고 검색어를 넣어 검색한다. 검색어는 2자 이상이어야 하며, 1자 이하로 검색하면 토스트 “검색어를 2자 이상 입력하세요” 가 나온다.

REQ-BRD-006

필수
REQ-BRD-007

필수
REQ-BRD-008
분류 · 검색 · 정렬 · 페이지는 주소창에 남아서, 새로 고치거나 뒤로 가기를 해도 같은 목록이 보인다.
필수
REQ-BRD-009
