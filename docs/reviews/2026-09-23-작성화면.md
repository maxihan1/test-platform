**[자기검사]** `/tpx` 체인 [6] 이 띄운 검사다. 사람이 따로 돌린 것이 아니다.

- 선언 등급 **3** (WEB·GUARD·SPEC·DOC) · 실측 등급 **3** (COMPOSE·TESTS·WEB·DOC·SPEC·GUARD)

  정본으로 들고 있는데 계획의 §2.7 목록에 그 파일이 없었다. 검사 중에 넣었다

## ★ BLOCKER 둘 — **간판 기능이 통째로 죽어 있었다**

둘 다 같은 뿌리다. **초안 PR 주소를 아무도 적지 않았다.**

| | 무엇이 안 됐나 |
|---|---|
| **1** | 맥이 초안 PR 을 만들어도 **그 주소를 서버에 안 알렸다** → 화면에 「PR 열기」도 「머지」도 영원히 안 뜬다 |
| **2** | 머지 요청 줄은 **태어날 때부터 PR 주소가 비어 있다** (`줄세우기` 의 INSERT 에 그 칸이 없다) → 맥이 `gh` 를 쳐 보지도 않고 100% 실패 |

**검사가 못 잡은 이유가 분명하다.** 머지 검사가 `머지할수있나({ kind: 'MERGE', prUrl: 'https://...' })`
로 **주소가 실려 온다고 가정한 입력을 직접 만들어 넣었다.** 서버가 그 값을 안 채운다는 사실이
검사 밖에 있었다 — **순수 함수만 검사할 때 늘 생기는 틈**이고, 여기서는 **기능 전체가 죽은 채로
1175개가 전부 초록**이었다.

**고친 방식** — 서버를 안 건드렸다. 집기 응답에 원본 번호가 이미 실려 오므로 **맥이 원본을 읽는다.**

## ★ BLOCKER 보다 위험했던 것 하나

집기 응답을 **「204 가 아니면 집은 것」**으로만 갈랐다. 서버가 500 을 내면 Fastify 가 오류 본문을
JSON 으로 실어 보내는데 **그것이 「집은 한 건」으로 통과**한다.

```
것.id       → undefined  →  /requests/undefined/stage   → 400 (안 던짐)
것.specText → undefined  →  빈 기획서로 claude 실행       → 한도 소모
                          →  집었으니 안 쉰다 → 즉시 반복
```

**DB 가 죽어 있는 동안 빈 기획서로 `claude` 를 끝없이 돌린다.** 이 저장소가 과금 안전핀에 들인
공(`실비청구_환경변수`·`푸시막힘`)이 **그 문을 지난 뒤에** 통째로 샜다.
→ **200 이고 번호가 숫자일 때만** 받게 고쳤다.

## 반영한 주의 — 열둘 중 열

| 무엇 | 어떻게 |
|---|---|
| 연결 실패·5xx 에 맥이 통째로 죽었다 | 기다렸다 다시 묻는다. **던져서 끝내는 것은 거절(401·403)뿐** |
| 평문(`http://`) 주소로 비밀번호가 망에 흐를 수 있었다 | 같은 기계가 아니면 거부 |
| 파일로 비밀번호를 먹일 수 있었다 (`< 비밀.txt`) | `isTTY` 가 아니면 거부 |
| 쿠키를 속성까지 통째로 되돌려 보냈다 | 이름=값만 (`auth/gate.test.ts` 와 같은 모양) |
| **줄 격자가 깨졌다** — 첫 칸이 4px 로 뭉개짐 | 실행 기록과 같은 `.gutter`·`.tcid`·`.title`·`.right` |
| 목록이 저절로 안 바뀌어 「멈춘 듯」이 안 떴다 | 5초마다 다시 읽는다 |
| 머지를 눌러도 화면이 그대로라 또 누르게 된다 | 방금 선 줄로 보낸다 |
| 「멈춘 듯」이 알려만 주고 길을 안 줬다 | 「새 요청으로 다시 넣으세요」를 같이 적는다 |
| `.error-text`·`.authoring-new` 규칙이 없었다 | 더했다 |
| 「시작 시각이 없을 수 있다」는 주석이 **사실이 아니었다** | 집기가 한 UPDATE 로 같이 적는다는 사실로 고쳤다 |

## 안 고치고 적어 둔 것 둘

- **멈춘 행을 되살릴 길이 없다.** 집기는 대기 중만 집고, 끝내기는 집은 쪽만 부를 수 있다.
  실제로 닫으려면 **맥이 켜질 때 자기 이름으로 잡힌 `RUNNING` 행을 먼저 훑어 닫아야** 한다 —
  통로는 이미 있지만 **이번 범위를 넘는다.** 화면이 최소한 사람이 할 수 있는 일은 알려 준다
- **목록 응답이 안 쓰는 칸까지 전부 보낸다** (기획서 본문 통째 포함). 응답 모양을 좁히는 것은
  §1.2 계약 변경이라 여기서 고칠 일이 아니다

## 눈으로 확인 — 검사가 못 보는 자리

도는 컨테이너는 **8시간 전 빌드**라 이 화면이 아니다. 그래서 저장소의 확립된 기법을 썼다 —
**제품 CSS 원본을 불러 DOM 을 재현해 실측**했다 (학습 기록 `admin-screen-qa-via-css-harness`).

```
격자   4px | 128px | 754px | 264px      ← 실행 기록과 같은 네 칸
칸들   gutter:4 · tcid:128 · title:754 · right:264
오류   rgb(155,36,24) 굵기 600
입력   108px
가로넘침 0
```

**고치기 전이었다면 첫 칸(종류)이 4px 로 뭉개졌을 자리다.**
