## 이 PR 중에 난 사고

새 검사(임시 git 저장소)가 pre-push 훅 안에서 돌 때 훅이 물려준 `GIT_*` 를 따라 **이 작업방 저장소**에 `init` 커밋(42dee0b, 파일 대부분 삭제)을 만들고 로컬 origin/main 을 옮겼다. 그 커밋이 PR 브랜치에 push 됐다. 원격 main 은 멀쩡했다.
복구 — 로컬 브랜치 되돌림(작업 트리 그대로) · fetch · 원격 브랜치는 강제 푸시 없이 `-s ours` 병합(내용 차이 0).
원인 제거 — `gitEnv()` 로 `GIT_*` 를 걷는다. 미끼 `GIT_DIR` 검사 RED→GREEN, 실제 push 훅이 검사를 돈 뒤에도 브랜치·origin/main 그대로. 두 렌즈 모두 「고침은 충분」.
