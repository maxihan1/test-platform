### 지적과 처리
1. **(code BLOCKER · spec 치명) 진척 반쪽이면 상세 화면이 죽는다** — 서버가 progress 없던 행에 `{childRunning:false}` 한 칸을 썼고 화면은 다 찬 줄 믿었다 → 서버는 없던 progress 를 비워 두고, 화면은 숫자 칸이 다 찬 것만 그린다. 반쪽 검사 더함 · spec-review A7 로 승격
2. **(code A · spec 중대) 신호 3분이 올리는 중의 살아 있는 에이전트를 끊는다** → 에이전트가 한 건 내내 30초마다 신호(`authoring-heartbeat.ts`) · 띄운 직후 첫 진척 곧바로
3. **(code 주의 · spec) 자식 전 중단이 409·「올리는 중」 오문구** → 자식 전(progress 없음)도 멈춤 요청을 받고, 에이전트가 자식을 띄우기 전에 보고 USER 로 닫는다 · 「올리는 중」은 progress 가 있고 childRunning false 일 때만
4. **(code) 틱이 409 를 버린다 · 떠 있는 틱이 늦게 닿는다** → 409 면 abort · 끝내기 전에 떠 있는 틱을 기다린다
5. **(security) lastAction 이 비밀번호 거르개를 안 탄다** → `사유거르기` + 피그마 토큰 가림 뒤 저장
6. **(code) 이모지 반쪽이 jsonb 에서 500** → 글자 단위로 끊되 서버 UTF-16 상한 안에서 멈춘다(`글자자르기`)
7. **(code) 머지 행 STOPPED** → finish 400 BAD_STOP
8. **(code 정리)** stop.ts 가 store 의 db 를 씀 · 상세 한 번 읽기(`상세읽기`) · `번호` 를 `authoring/params.ts` 로(routes ↔ stop 순환 끊음)
