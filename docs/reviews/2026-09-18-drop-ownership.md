## G — TDD

**지우는 작업의 RED 는 거꾸로 온다.** 그물을 먼저 놓고, 배선을 끊어 빨갛게 만든 뒤,
구현을 지워 초록으로 되돌렸다.

```
판별식 추가 직후:   초록
배선만 끊은 뒤:     빨강   ← 「구현은 있는데 아무도 안 부른다: ownership」
구현까지 지운 뒤:   초록
```

**중간의 빨강이 비-공허 증거다.**

그 뒤 `code-review` 가 이 판별식의 구멍 넷을 찾아 다시 썼고, **뮤테이션 다섯**으로
확인했다 — 시점 바꾸기 · matcher 좁히기 · 없는 모드 배선 · 침묵 되살리기 ·
구현만 지우기. 전부 빨간불, 되돌리면 초록.

**G2 테스트를 느슨하게 고친 흔적 → 없다.** 기존 `guard.test.mjs` 5건은 한 글자도 안 건드렸고
끝까지 초록이다. 새로 더한 셋은 **조이는 방향**이다.

**가드가 여전히 도는 것도 연기로 확인했다.** `rm -rf /` 를 넣으니
「[차단] 루트 경로 삭제」가 그대로 나온다 — 지운 것은 소유 경로 판정뿐이다.

**지우기 전 구현도 돌려 봤다.** `WORKSTREAM=C` 를 주니 정확히 막았다 (EXIT=2).
고장 나서 지운 게 아니라 **쓰지 않기로 해서** 지웠다.

### 전제를 흔든 지적 — 받아들여 근거를 고쳤다

**「지운 구현은 멀쩡했다.」** 리뷰가 개명 전 `guard.mjs` 를 직접 돌려 보였고, 나도 재현했다.

```
WORKSTREAM=C 를 주고 reporting 파일을 고치려 하면
  → [차단] WS-C 소유 경로 밖이다   EXIT=2
안 주면
  → EXIT=0
```

**「훅에 안 닿는다」가 아니었다.** `.claude/settings.local.json` 의 `env` 에 넣으면 닿는다.
그 파일은 이 기계에 실재한다(`permissions` 키를 이미 들고 있다). **아무도 안 넣었을 뿐이다.**

두 번째 근거였던 「병렬 전제가 사라졌다」도 과했다 — `WORKFLOW.md:16,:27,:88` 과
`WORKSTREAMS.md:1,:107,:496` 이 아직 병렬 모델을 적고 있다.

**결정은 그대로다** (2026-09-18 사용자가 쓰지 않기로 정했다). **근거만 정직하게 고쳤다** —
`CLAUDE.md §1.1` · `docs/HOOKS.md` · `spec-review` 세 곳의 설명을 「구현은 멀쩡했고
켜는 자리를 아무도 안 채웠다」로 바꿨다.

### 판별식의 구멍 넷 — 고치고 뮤테이션으로 확인

처음 판별식은 **모드 이름만** 봤다. 리뷰가 통과한다고 증명한 것들이다.

| 무엇 | 왜 위험한가 |
|---|---|
| 시점을 안 본다 | `bash` 를 PostToolUse 로 옮기면 **강제 push 를 돌고 난 뒤에** 막는다 |
| `matcher` 를 안 본다 | `Edit|Write|MultiEdit` → `Edit` 로 좁혀도 초록 |
| `[a-z]+` 로 자른다 | `tests2` 가 `tests` 로 보여 없는 모드를 배선해도 초록 |
| 소스를 정규식으로 읽는다 | 주석의 `mode === 'x'` 를 구현으로 센다 |

**고치다 같은 부류를 한 번 더 냈다.** 주석을 걷어내려고 블록 주석 정규식을 넣었더니
`guard.mjs:133` 의 문자열 `tests/**` 가 주석을 열어 **뒤쪽 `review` 모드를 통째로 삼켰다.**
그래서 **텍스트를 읽지 않기로 했다** — 각 모드로 `guard.mjs` 를 **실제로 돌려** 본다.

뮤테이션 다섯 전부 빨간불, 되돌리면 초록.

### 같이 고친 런타임 침묵

`guard.mjs` 가 모르는 모드에 조용히 `exit 0` 했다. **이 침묵이 원래 버그를 살렸다** —
배선만 있고 구현이 없는 훅이 매번 돌면서 아무 말도 안 했다. 이제 알린다.

### 넘긴 것

**`check:workflow` 가 CI 에도 pre-push 에도 없다.** 판별식이 자동으로는 한 번도 안 돈다 —
개명 PR 에서도 같은 지적이 나왔고 그때 미뤘다. 리뷰의 더 날카로운 말 —
「이 PR 은 죽은 검사 묶음에 하나를 더 얹고 그걸 안전 근거라 부른다」. 맞는 말이다.
**pre-push 에 넣으면 무한 재귀**라 (`hook-contract` 가 진짜 훅을 돌린다) CI 쪽만 별건으로 연다.

그 밖 — `HOOKS.md` 빠져나가기 절의 `printf >` 가 `settings.local.json` 을 통째로 덮어쓴다는
경고가 사라진 것, 설치 확인의 기대값 `exit=2` 가 실제로는 `0` 인 것. 둘 다 pre-existing 이다.
