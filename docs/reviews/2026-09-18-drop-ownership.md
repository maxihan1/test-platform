## G — TDD

**지우는 작업의 RED 는 거꾸로 온다.** 그물을 먼저 놓고, 배선을 끊어 빨갛게 만든 뒤,
구현을 지워 초록으로 되돌렸다.

```
판별식 추가 직후:   3 통과 / 0 실패
배선만 끊은 뒤:     2 통과 / 1 실패   ← 「구현은 있는데 아무도 안 부른다: ownership」
구현까지 지운 뒤:   3 통과 / 0 실패
```

**중간의 빨강이 비-공허 증거다.** 판별식이 실제로 어긋남을 잡는다.

**G2 테스트를 느슨하게 고친 흔적 → 없다.** 기존 `guard.test.mjs` 5건은 한 글자도 안 건드렸고
끝까지 초록이다. 새로 더한 셋은 **조이는 방향**이다.

**가드가 여전히 도는 것도 연기로 확인했다.** `rm -rf /` 를 넣으니
「[차단] 루트 경로 삭제」가 그대로 나온다 — 지운 것은 소유 경로 판정뿐이다.
