## 고친 것

- **BLOCKER — 두 번째 CSS 파일** `authoringStatus.css` 의 옛 토큰 38곳을 대응표대로 옮겼다. 작성 상태 카드의 바탕 · 테두리 · 포커스 링이 사라지고 있었다
- **BLOCKER — 인라인 `var(--rule)`** 다섯 자리를 `--line-2`(중립 띠) · `--chart-track`(진행 막대 빈 칸)으로. 같은 문자열을 기대하던 화면 검사 넷도 새 이름으로
- **검사 구멍** — 「쓰는 토큰이 다 정의돼 있다」가 `styles.css` 만 읽었다 → 화면 폴더의 CSS · ts · tsx 전부. 「판정 도형 색을 글자색으로 쓰지 않는다」 검사를 더했다
- **판정 글자색** — 인라인 아홉 자리를 `-text` 로(`STATUS_TEXT_COLOR`). 줄 hover 바탕 위 `--fail` 4.10 · `--na` 4.32 였다
- **모달 위치** — 화면을 연 직후 판의 `transform` 움직임 동안 포털 없는 모달이 판에 붙어 잘렸다(화면 QA 가 20초로 늘려 재현). 판은 투명도로만 나타난다
- **줄마다 되풀이되는 채운 버튼** — 케이스 「실행」 · 실행 「결과 보기」 · 항목 「상세」 · 시나리오 「실행」 · 증적 「받기」를 테두리 버튼으로. 주 버튼은 화면에 하나
- **확정 버튼 빨간 테두리**(`.btn.set-warn`) · **접힌 하위 메뉴 포커스 링** · **접힌 레일 간격** · `color-scheme` 을 `:root` 로
- **밝은 테마 흔적** — 입력칸 바탕 `--well`, 작성 폼 textarea, 파일 고르기 단추, 설정 권한 칩, 눌린 거르개 칩(흰 반전 → 한 단계 밝은 면)
