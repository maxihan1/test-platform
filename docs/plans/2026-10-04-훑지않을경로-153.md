# 서비스 설정 「훑지 않을 경로」 — 지역 사이트를 작성 범위에서 뺀다

등급: 3 · 갈래: contracts · WS-F · WS-E · WS-작성 · 2026-10-04

## 도메인 정리

| 어디 | 바뀌는 것 |
|---|---|
| DB `service` | 칸 `crawl_exclude TEXT[] NOT NULL DEFAULT '{}'` (공통/4-데이터모델) |
| Admin API | `GET/POST/PATCH /api/settings/services` 에 `crawlExclude: string[]` · `GET /api/auth/me` 의 `services[].crawlExclude` (도메인/인증 §7) |
| 화면 | 설정 > 서비스 폼 「테스트 폴더」 아래 여러 줄 입력칸(시안 A — 2026-10-04 사용자) (도메인/인증 §8.8) |
| 작성 에이전트 | me 에서 받아 화면만 역방향 절의 크롤러 명령에 `--exclude <경로>` · 보조의 「더 갈 곳」에서도 뺀다 (도메인/작성 §3.6) |

## 왜

CDY 크롤 57장 중 34장이 대전 · 경남 지역 사이트(`/daejeon/…` · `/gyeongnam/…`)다. 구조가 본 사이트와 달라 자동으로 사본을 못 가른다(링크를 빼고 견줘도 34장 중 32장이 다름). 사용자가 「뺀다 · 서비스 설정에 · 시안 A」를 골랐다(2026-10-04).

게이트 0 승인(계약 변경 블록 — 명세 도메인/인증 §7 에 싣는다).
- 칸 값: 각 줄 `/` 로 시작 · 공백 없음 · 100자 이하 · 20개 이하. 판정은 마디 경계(`/daejeon` 은 `/daejeon/about` 을 빼고 `/daejeonx` 는 안 뺀다)
- 화면만에만 적용 — 대조는 원래 기획서 화면만 본다
