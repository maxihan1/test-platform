# 작성 대기줄 — 표 · 통로 일곱 · 권한

등급: 3 · 갈래: WS-작성 · 2026-09-22

## 도메인 정리

**BC** — `Authoring` (`docs/spec/도메인/작성.md` §3.6). 애그리거트 루트는 `AuthoringRequest`.

| 건드리는 컨텍스트 | 무엇 |
|---|---|
| **Authoring** (신설) | 대기줄 표 · 통로 일곱 |
| **Auth** | 등급 표를 서버에 세운다 (`gate.ts`) · 라우트표에 새 틀 등록 (`scope.ts`) |
| 나머지 넷 | **안 건드린다** — Catalog · Execution · Reporting · Runner |

**관련 절** — `도메인/작성` §3.6 · §7 · `공통/4-데이터모델` §6 · `도메인/인증` §7.

**`packages/kit` 을 안 건드린다 (실측).** `result` 는 `ExecuteResponse`·`StepResult` 모양 그대로이고
admin 이 `web/api.ts` 에서 **이미 그 타입을 import 한다.**

## 왜

**엔진은 이미 돈다.** `npm run authoring-agent -- <기획서 경로>` 가 기획서 한 장을 테스트 코드와
초안 PR 로 바꾼다. 그런데 **사람이 셸에서 경로를 손에 쥐여 줘야만** 움직이고, 화면도 맥도 서로를 모른다.

이 PR 은 **화면과 맥이 만나는 자리**를 세운다. 화면은 다음 PR 이라 **이번 PR 이 끝나도 화면에는
아무것도 안 보인다.**

**명세가 설계도를 통째로 들고 있다** (PR #52, 2026-09-22 병합). 표의 칸도 통로 이름도 이미 적혀 있어
**이번 일은 옮기는 것이지 정하는 것이 아니다.**

### 게이트 0 에서 정해진 것 — 넷

| 무엇 | 정한 것 | 누가 |
|---|---|---|
| 셸 진입점 | **PR 2 에서 없앤다.** 이번엔 그대로 두고 명세에 「PR 2 가 없앤다」를 박는다 | **사용자** |
| `status` 개수 | **넷 그대로** — 「몇이 충분한가」는 화면이 답한다 (PR 2) | 체인 |
| `screenshot_dir` | **대기줄 행 번호로 가른다** — 명세가 「가장 가깝다」고 이미 적었다 | 체인 |
| 맥 비밀값 자리 | **PR 2 로 미룬다** — 맥이 로그인을 시작하는 것이 PR 2 다 | 체인 |

`params` 로 무엇을 바꿀 수 있나 · 한 번에 몇 건까지 세우나 — **안 정한 채로 둔다.**

### ★ 명세 한 줄을 고친다 — 대리 혼동

```
[계약 변경 필요]
대상:    공통/4-데이터모델 §6 — 「집어 가는 일은 한 줄 UPDATE 라 누가 집었는지를
         적는 칸을 따로 두지 않는다」
현재:    잠금을 근거로 칸을 두지 않는다. 그 근거는 지금도 맞다
제안:    칸을 하나 더한다 (집은 쪽). 잠금 문장은 지우지 않고 왜 다른 이유로 칸이
         생겼는지를 덧붙인다 (CLAUDE.md §2.7 ②)
이유:    집은 쪽을 안 적으면 operator 누구나 finish 에 임의의 prUrl 을 실을 수 있고,
         뒤에 admin 이 머지를 누르면 그 사람이 고른 PR 이 병합된다. 사람 게이트는
         「이 요청을 머지할까」만 묻고 「이 prUrl 이 그 요청이 만든 것 맞나」는 아무도 안 본다
영향:    WS-작성(이 PR) · 화면 PR(집은 쪽을 보여줄지)
상태:    반영 완료 (2026-09-22, docs/spec/공통/4-데이터모델.md §6)
```

**마이그레이션은 되돌리기가 금지**라 이번에 안 넣으면 표를 또 얹게 된다.

### ★ 실측 — 검사 환경에 구멍이 있다

| 잰 것 | 값 |
|---|---|
| 이 기계 `DATABASE_URL` | **비어 있다** (`echo "[${DATABASE_URL}]"` → `[]`) |
| 로컬 postgres | **떠 있다** — `localhost:5433`, 표 11개 (`authoring_request` 없음) |
| **CI 의 postgres** | **없다** — `.github/workflows/ci.yml` 에 `services:` 도 `DATABASE_URL` 도 **0건** |

**그래서 이 PR 의 DB 검사는 CI 에서 안 돈다.** 손으로 `DATABASE_URL` 을 붙여 **연속 3회** 돌리고
그 사실을 게이트 2 요약에 싣는다. **「CI 초록」을 이 PR 의 증거로 쓰지 않는다.**

> **이것 자체가 별건이다.** CI 에 DB 를 붙이는 일은 `GUARD` 표면이고 이 PR 범위가 아니다 —
> 게이트 2 요약에 넘긴다.
