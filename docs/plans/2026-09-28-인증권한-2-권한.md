### BLOCKER 1 — 옛 등급 대조가 「어느 기능에 묶였나」를 못 잡는다 (ceo)
옛 `viewer`·`operator` 를 옮긴 값은 기능 셋을 한꺼번에 가져, 통로를 엉뚱한 기능에 묶어도(예 `POST …/evidence` 를 `(cases, write)`) 초록이다.
틀린 묶임은 기능 하나만 가진 member 에서만 드러난다. → (틀, 메서드)마다 기능을 고정하는 검사를 더한다. `DELETE /api/param-sets/:id` 는 `/api/cases` 밖이라 따로 적는다

### BLOCKER 2 — 집이 `route.ts` 에 케이스로 박혀 있다 (design)
`route.ts` 의 `집 = '#/cases'` · `돌아갈자리()` · `layout.ts` `지금자리()` 기본값. 케이스가 `none` 인 사람은 로그인하면 못 보는 화면에 떨어진다 (화면공통 §8 「남은 자리 중 맨 위가 집」 위반). → 할 일 7 에 `route.ts` 를 넣고 집을 권한으로 고른다. 로그인 뒤 돌아갈 자리 검사

### BLOCKER 3 — 할 일 8 이 버튼 하나만 숨긴다 (design)

5. **넷 다 `none` 일 때 한 줄 안내** (eng·design) — 문구 단언 · 번역 · 서비스 0건 안내(`빈띠사유`)와의 순서
6. **`none` 인 기능 주소를 직접 친 사람이 무엇을 보나** (design) — 명세에 없다 → 게이트 1 에서 사용자 결정
7. **설정 폼 세부** (design) — 등급 select → 운영 켜고 끄기 · admin 을 끌 때 처음 권한값 · 마지막 운영 안내 문구 · 목록 요약 모양(`none` 표시 · 순서) · 경고 `role="status"` · 「저장은 막지 않는다」 단언
8. **`gate.ts` 가 이미 305줄** (eng) — 표를 `auth/routeTable.ts` 로 떼어 낸다
