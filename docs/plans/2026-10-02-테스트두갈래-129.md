## 왜

PR #128 이 UI Test · Page Object · `-UI-`/`-FN-` 를 「대기」로 남겼다. 지침만 켜면 올리기 허용 목록(`cases-only.mjs:28`)이 그 파일을 거부해 요청이 FAILED 가 된다
(LEARNINGS 2026-10-02 「지침보다 판별식 먼저」). 그래서 **글자로 번호 · 파일 모양을 판별하는 곳을 먼저 넓히고** 마지막에 지침을 켠다.
번호 꼴: `<접두사>-<3자리>`(옛 꼴, Functional 로 본다) · `<접두사>-UI-<3자리>` · `<접두사>-FN-<3자리>`. FN 은 옛 번호와 한 번호열(옛 최댓값 다음부터), UI 는 001 부터.
