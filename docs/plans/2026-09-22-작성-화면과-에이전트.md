# 테스트 작성 화면 ＋ 에이전트를 대기줄에 붙인다

등급: 3 · 갈래: WS-작성 · 2026-09-22

## 도메인 정리

**컨텍스트** — 작성(Authoring). 정본은 `docs/spec/도메인/작성.md` §3.6 · §7.

**이 PR 은 새 도메인 규칙을 만들지 않는다.** 이미 선 것을 잇는 일이다.

| 이미 선 것 | 어디 | 언제 |
|---|---|---|
| 대기줄 표 `authoring_request` | `db/migrations/` · 공통/4-데이터모델 §6 | PR #56 |
| 서버 통로 여덟 | `apps/admin/src/authoring/` · 도메인/작성 §7 | PR #56 |
| 경로→등급 표 | `apps/admin/src/auth/gate.ts` · 도메인/인증 §7 | PR #56 |
| 기획서 → 케이스 엔진 | `.claude/skills/tpx-cases/` | PR #44·#50·#59 |

**영향** — WS-E(화면)의 `apps/admin/src/web/**` 에 자리가 하나 는다. 자리 목록의 정본은
`공통/5-화면공통.md` 이고 **명세에는 이미 들어가 있다** — 코드가 따라가는 일이다.

## 왜

**주문서만 쌓이고 아무도 안 집어 간다.**

실측 — `apps/admin/src/web/` 에 작성 화면 파일 **0개**, `scripts/authoring-agent.ts` 에 서버 호출
**0건**. 통로 여덟은 서 있는데 **부르는 쪽이 양쪽 다 없다.**

그리고 지금 유일하게 도는 길(`npm run authoring-agent -- <기획서 경로>`)은 **admin 을 아예 안 불러
로그인을 지나지 않는다.** 대기줄을 만든 뒤에도 두면 **「로그인을 안 지나는 작성 경로」가 남는다** —
§3.5 가 러너 포트를 닫으며 막은 뒷길과 같은 성질이다. **이 PR 이 그것을 치운다.**

### 정해진 것 다섯 — 다시 묻지 않는다

1. **맥 비밀번호를 저장하지 않는다. 켤 때 물어본다** — 설계 문서가 「숨은 데몬으로 두지 않는다」로
   이미 정했다. 사람이 켜므로 한 번 치는 것이 공짜다. **맥에 남는 비밀값 0**
2. **사진은 안 만든다** — 실측으로 「지금 아무도 안 올린다」를 확인했다. 안 올리니 볼 것도 없다
3. **재실행 값 바꾸기 · 줄 상한 · 실패한 것 치우기 — 셋 다 안 한다.** 명세의 「아직 안 정했다」 줄을 그대로 둔다
4. **에이전트는 `AUTHOR` 와 `MERGE` 만 처리한다** — `RERUN` 은 바꿀 값을 안 정해 내용이 없다
5. **`테스트 작성` 은 `테스트 케이스` 다음 자리** · 영어 이름 **`Authoring`**
