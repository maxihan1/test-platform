등급: 3 · 갈래: 없음(하네스·문서) · 2026-09-18

## 도메인 정리

제품 도메인을 건드리지 않는다. `docs/SPEC.md` 를 두 줄 고치지만 **둘 다 「누가 이 표를 읽는가」
주석**이고 제품 명세가 아니다.

계약 넷(`types.ts` · 러너 HTTP · DB 표·칸 · Admin API) 어디에도 안 걸린다 → **계약 변경 없음, 게이트 0 불필요.**

등급이 3인 것은 `docs/SPEC.md` 가 `SPEC` 표면(3등급)이기 때문이다. 바꾸는 내용은 가볍다.

## 왜

`/tp` 체인이 오케스트레이터가 하던 일을 전부 가져갔다. 두 벌을 두면 **세션이 어느 쪽을
따를지 모른다.** 특히 `CLAUDE.md §0`(세션 시작 6단계)이 `/tp` 와 같은 일을 서로 다르게 적고 있다.

사용자 지시 — 「이전 오케스트레이터 관련 레거시는 모두 제거해줘」(2026-09-18).
