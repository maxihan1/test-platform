등급: 3 · 갈래: WS-작성 · 2026-09-29

## 도메인 정리

작성 에이전트(역방향) — 자료 받기 · 글자 변환(`authoring-run.ts` 사본에서) · 표시 사본(`authoring-marking.ts` 표시준비 → `authoring-docx.ts` 메모달기) · 올리기 검사(`authoring-upload.ts`).
타입 · API · DB 변경 없음. 명세 `도메인/작성.md` §3.6 「★ 역방향」 남는 한계 문장만 바뀐다 (게이트 0 승인 2026-09-29).

## 왜

5873 · 5875 가 케이스를 다 만들고 올리기에서 「비밀번호가 들어 있다」로 멈췄다. 기획서 원본에 테스트 계정 비밀번호가 적혀 있어
표시 사본(`메모달기` 글들)에서 걸린다 — 자식이 고칠 수 없어 이어하기로도 못 푼다. 사용자 「업로드되면 먼저 파악해서 가리고 시작」.

### 할 일 2. 표시 사본(워드)에서 글 칸만 가린다 — 조각으로 갈려도

- **RED** — `글칸가리기(xml, 비밀)` 이 ① 한 `<w:t>` 안의 비밀번호 ② 여러 `<w:t>` 로 갈린 비밀번호를 가리고 ③ 속성값(`w:rsidR="1234"`)은 그대로 둔다.
  `메모달기(…, 비밀)` 결과 `글들` 에 원문이 없고 가린 문장을 anchor 로 줘도 메모가 붙는다. 속성에만 있으면 XML 그대로 · 누설 검사가 잡는다
- **GREEN** — `<w:t>` 글을 이어 붙여 찾고 걸친 칸마다 고쳐 쓴다(첫 칸에 가림표, 나머지 칸은 걸친 글자를 뺀다). 메모달기가 XML 파트마다 문단 찾기 **전에** 적용. `표시준비` 가 `비밀` 을 넘긴다. 머리 주석 불변식 고침
- **REFACTOR** — 없음
