## 왜 · 실측

WORKSTREAMS 📐 E2E 2번. 넘겨받은 숙제 「testDir 밖 파일은 안 잡힌다」를 [2] 에서 실행으로 쟀다.
① 기본 설정으로 `/tests` 밖 spec 경로를 주면 `No tests found` EXIT=1 ② 전용 설정의 고정 spec 이 `tests/todo/TODO-001.spec.ts` 를 동적 import 하면 불러와진다. 명세 설계(고정 spec + 전용 설정)가 맞다.

## 설계 (계약 밖 — 이 PR 이 정한다)

- **kit 시나리오 모드 켜기** — 환경변수 `PLATFORM_SCENARIO_MODE=1`. `defineTest` 가 `PLATFORM_SCAN` 분기 옆에서 Playwright 에 등록하는 대신 본체를 **`globalThis` 등록부**에 `tcId` 로 넣는다 — 케이스 파일과 고정 spec 이 kit 을 다른 경로로 불러도 한 등록부를 본다
- **건너뛰기** — `RunScope.skip?: ReadonlySet<string>`. `step()` 이 그 제목이면 본문을 안 돌리고 `{ status: 'PASS', durationMs: 0, assertions: [], skipped: true }` 를 순번을 올려 적는다. 진행 줄도 안 흘린다
- **`runScenarioCase`** — kit 이 낸다. 받은 `RunScope` 의 실패 표시를 부품마다 새로 세우고, 입력값을 그 케이스 명세로 해석해 본체를 돌린다. 멈춤 신호는 여기서 끝내고 진짜 예외는 올린다
- **결과 줄** — 부품이 끝날 때마다 고정 spec 이 `@@SCENARIO_PART@@{ScenarioPartResult}` 한 줄을 흘린다. 끝에 한 번이 아니라 **부품마다**인 이유: 제한 시간에 죽이면 끝 줄이 안 나와 「어디까지 갔나」가 사라진다(러너 §5.2 「parts: 파싱된 것이 있으면 그것」). 워커 출력이라 전용 리포터가 `onStdOut` 으로 **전부** 되돌려 쓴다(LEARNINGS 2026-09-21 [WS-C])
- **안 돈 부품 채우기는 러너가 한다** — 줄이 없는 순번을 `NA` + `NOT_RUN`(죽였으면 `TIMEOUT`)으로. 고정 spec 이 채우면 자식이 죽었을 때 못 채운다
- **스크린샷 경로** — 러너가 `PLATFORM_RUN_ID`·`PLATFORM_HISTORY_ID` 를 명세대로(`<runId>`/`scenario` · `trial`/`<trialId>`) 넘긴다. kit 은 안 고친다

### BLOCKER 1 — 전용 설정이 같은 폴더의 vitest 파일까지 집어 간다 (둘 다)
Playwright 기본 무늬가 `*.test.ts` 도 잡는다. `testMatch: 'scenario.spec.ts'` 를 박는다.

### BLOCKER 2 — 결과 줄 없이 끝난 실패가 「안 돌았음」으로 보고된다 (둘 다)
본체 예외 · import 실패 · 등록부에 `tcId` 없음 · 자식 사망이면 실패한 부품이 `NOT_RUN` 이 되고 원인이 사라진다. `runParts` 가 예외를 잡아 그 부품 `FAIL` 줄을 흘리고 멈춘다. 러너는 잘린 끝 줄을 버리고, 안 죽였는데 FAIL 줄 없이 모자라면 첫 빈 부품을 `FAIL` 로 두고 stderr 꼬리를 전체 `error` 에 싣는다.

### BLOCKER 3 — kit 이 두 벌로 불리면 `step()` 이 문맥을 못 찾는다 (eng)
등록부만 `globalThis` 로 두면 본체 안 `step()` 은 자기 kit 의 AsyncLocalStorage 를 본다. 시나리오 모드 `defineTest` 가 **자기 인스턴스로 감싼 실행 함수**를 등록한다. 검사로 고정.

### BLOCKER 4 — API 주소가 대상 밖으로 샌다 (ceo)
`//evil.com/x` 는 `/` 로 시작해도 다른 호스트가 된다. `baseUrl` 에 경로가 붙으면 날아간다. `//` 시작은 400, 주소는 끝 `/` 를 떼고 문자열로 잇는다.

- 진행 줄 버리기 — 시나리오 자식은 `running` 지도에 안 올린다 · `/progress` 에 안 뜬다를 검사로

- 실측이 인터넷·맨 끝에 있다 — fixture 케이스(`page.setContent`)로 인터넷 없이 도는 실측을 기본으로 두고 할 일 2 직후로 당긴다. 러너 이미지 확인은 완료 조건

- WORKSTREAMS 4번에 러너가 보장하는 것(오류 값 의미 · `trialId` 형식)을 넘긴다
