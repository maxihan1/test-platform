## 왜

역방향 미확정 케이스는 화면 값을 기대값으로 쓴다. 확정 집계에 섞으면 버그를 지키는 케이스가 「사람이 판정한 초록」이 되고,
미확정 실패(화면이 바뀌었다는 신호)는 확정 실패처럼 보여 실행 판정을 흔든다. 명세 PR #73 게이트 0 에서 승인된 계약을 반영한다.

사용자 결정 (2026-09-26, [2] 빈칸 질문)
- Slack 「실패한 케이스」 목록 — 확정 실패를 먼저, 미확정 실패는 `(미확정)` 꼬리를 붙여 뒤에 적는다
- 미확정만 돌린 실행(확정 항목 0)의 Slack 머리 — `[미확정]`, 그 안에 실패가 있으면 `[미확정 · 실패 N]`
