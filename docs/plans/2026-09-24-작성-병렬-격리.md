A 자식이 B 자식의 environ(피그마 토큰)·자료·트리를 읽고 쓴다. 자식이 남긴 백그라운드 프로세스가 검사 뒤 파일을 바꿔치기할 수 있다.
고칠 것: 슬롯마다 uid(기본값 + 순번) · 작업 뿌리 0700 · 자식이 끝나면 검사 전에 그 uid 프로세스를 전부 죽인다.

### BLOCKER 3 (eng) — `node_modules` 링크가 매 건 push 거부를 부른다
`.gitignore` 의 `node_modules/` 는 링크에 안 맞아 `?? node_modules` 가 바뀐 파일로 잡힌다.
고칠 것: 사본 `info/exclude` 에 `/node_modules`. RED 에 「준비 직후 status 가 비었다」.

### BLOCKER 4 (ceo) — 동시 작업 상한이 없다 (eng 주의 6 과 같다)
서비스 수 = 동시 수. `mem_limit 4g` 는 한 건 기준이라 OOM 으로 전부 죽고, 구독 한도도 N배로 닳는다.
고칠 것: `AUTHORING_MAX_PARALLEL`(기본 2) 세마포어 · mem_limit 을 상한에 맞춘다 · 한도 걸린 실패를 사람이 읽을 사유로.

### BLOCKER 5 (ceo) — `latest` 무인 최신화에 확인·되돌리기가 없다 (eng 주의 5 와 같다)
설치 실패만 막고, 설치는 됐는데 `-p`·`--disallowedTools` 동작이 바뀐 판은 못 막는다. 재생성하면 이미지 판으로 돌아간다. npm 레지스트리 길이 필요하다.
고칠 것: 올린 뒤 연기 확인(판 번호 · 깃발 존재 · 막은 도구가 막히는지) → 실패하면 직전 판으로 되돌린다 · 판을 기록 · SETUP 에 적는다.

### 주의 (요약)
- `--fallback-model` 은 과부하·미제공일 때만 넘어간다 — 구독 한도 대비가 아니다. 문구를 맞춘다 (eng·ceo)

- 사본 바탕 자리 미정 · 죽은 뒤 남은 사본 정리 (ceo)
- `clone` 에 `--bare` 명시 · gh 도 사본 환경이나 `--repo` 로 (eng)
- 링크 검사가 중간 폴더를 못 본다 — realpath 가 트리 안인지 + `isFile()` 만 읽는다(FIFO) (eng)
