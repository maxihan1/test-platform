## 도메인 정리

작성 BC. 게이트 0 승인 (2026-09-28). 사용자 결정은 아래 표가 전부다.

| 정한 것 | 값 |
|---|---|
| 무엇을 이어받나 | **파일** — 표 · 케이스 · 차이 파일 · 본 화면 기록. 대화(`--resume`)는 이어 붙이지 않는다 |
| 어디에 두나 | **작성 에이전트 디스크** — `author-<번호>` 폴더를 지우지 않는다. 서버 `author` 의 `/work` 는 볼륨으로 |
| 얼마나 두나 | 중단만 **7일**. 성공 · 실패 · 폐기 · 이어받아 끝나면 곧장 지운다 |
| 무엇이 중단인가 | 지금 다섯 + **CRASH**(작성 중 끊김) · **REJECTED**(올리기 거절, 이유는 `error`). 실패는 자식을 띄우기 전 설정 · 자료 문제만 |
| 시간 한도 | 120분 유지 — 까닭 문구만 「이어하기의 안전망」으로 |
| 화면 | 시안 **A**(번호 셋 나란히) · 카드 제목 「해야 할 일」 → **「다음 단계」** · 문구 「중단된 자리의 테스트 N개를 이어받아 남은 작업을 이어서 합니다」 — 「표」 같은 안쪽 말을 쓰지 않는다 |

| 계약 | 지금 | 바꾼 뒤 |
|---|---|---|
| DB `authoring_request_stop_reason_check` | 다섯 | + `CRASH` · `REJECTED` |
| DB `authoring_request.resume_from` | 없음 | `BIGINT NULL REFERENCES authoring_request(id)` · RERUN 에만 · 한 중단 요청은 한 번만(부분 유일 색인) |
| `POST /authoring/requests` | RERUN 은 처음부터 | `{ kind: RERUN, sourceId, resume: true }` — 원본이 STOPPED · `finished_at` 7일 이내 · 폐기 안 됨 · 아직 안 이어받음. 아니면 409 `NOT_RESUMABLE`. 원본이 이어받은 RERUN 이어도 된다 — 새 행의 `source_id` 는 맨 처음 AUTHOR, `resume_from` 은 멈춘 그 행 |
| `finish` | STOPPED 이유 넷 | + CRASH · REJECTED(`error` 필수) |
| 상세 · 목록 | — | `resumeFrom` · `canResume` |
| 집기 응답 | — | 행에 `resumeFrom` (빚기가 싣는다) |

에이전트 규칙(명세 §7 에 적는다) — STOPPED 면 폴더를 남긴다. 켤 때와 한 시간마다 남은 폴더를 훑어 **그 행이 STOPPED · 7일 이내 · 폐기 안 됨**이 아니면 지운다(폴더의 `보관.json` 이 서비스를 알려 준다). 이어받는 행은 `resumeFrom` 사슬을 거슬러 **처음 찾은 폴더**를 `author-<자기 번호>` 로 옮겨 쓴다. 없으면 처음부터 하고 단계 글에 「보관한 것이 없어 처음부터」를 적는다.

### BLOCKER 1 — 올리기에서 멈춘 것을 이어받으면 반드시 다시 거절된다 (eng)
올리기는 커밋을 먼저 한다(`authoring-upload.ts:138-147`). 그 뒤 검사·push·PR 이 실패하면 커밋이 사본에 남아, 이어받은 자식이 아무것도 안 바꾸면 「바뀐 파일 없음」, 바꾸면 「커밋 수 2」로 또 거절된다.
고칠 것 — 폴더를 넘겨받은 직후 `git reset <보관.json 기준 sha>`(파일은 두고 커밋만 푼다). 할 일 5 RED 에 넣는다.

### BLOCKER 2 — 훑어 치우기가 도는 건 · 꺼지며 끊긴 건의 폴더를 지운다 (eng)
도는 건과 꺼지며 끊긴 건(finally 가 안 돎)은 `보관.json` 이 없다. 「모양이 틀리면 지운다」에 걸려 AGENT_RESTART·CRASH 폴더가 켤 때 사라진다 — 이어하기의 주된 경우다.
고칠 것 — `보관.json`(서비스 · 기준 sha)은 **사본을 만들 때** 쓴다. 훑기는 지금 이 에이전트가 잡은 번호를 건너뛴다.

### BLOCKER 3 — 보관 폴더를 같은 자리의 다음 건이 7일 동안 읽는다 (eng)
자리 uid 는 자리 번호에 고정이라, 다음 건(다른 서비스일 수 있다)이 같은 uid 로 옛 기획서 · 트리를 읽고 쓴다. 지금은 곧장 지워 없던 노출이다.
고칠 것 — 보관할 때 root 소유로 돌리고(`chown -hR 0:0`, 0700), 이어받을 때 새 자리 uid 로 넘긴다. 맥(uid 없음)은 건너뛴다.

### 주의
1. **끝내기가 치우기보다 먼저라 옮기기 경쟁** (eng) — 앞 자리가 자식을 거두는 사이 이어받기가 폴더를 옮길 수 있다. `보관.json` 에 「보관 끝」 표시를 치우기 뒤에 적고, 없으면 기다리지 않고 처음부터
2. **caseFiles 가 실행마다 0 부터** (eng · design) — 「테스트 N개」는 기준 sha 대비 새 케이스 파일 수로 센다(`git ls-tree` 기준). 카드의 「만든 케이스 파일」과 한 말로 맞춘다
3. **누설 거절을 중단으로 둘지** (eng ↔ ceo 충돌) — eng: FAILED 로 두고 폴더 즉시 삭제. ceo: 중단으로 두되 `resume.md` 첫 규칙을 「거절된 파일부터 고친다」로 · `error` 에 원문이 안 섞이는지 검사. **게이트 1 에서 정한다**
