## 명세가 안 정한 것 — 제안 (게이트 1 에서 승인받으면 할 일 1 이 명세에 적는다)

| 무엇 | 제안 |
|---|---|
| 실행 요청 본문 모양이 틀림 · `env` 빈 글자 | 400 `INVALID_REQUEST` |
| 없는 시나리오 | 404 `SCENARIO_NOT_FOUND` |
| 대상 서버가 그 서비스에 없음 | 400 `ENV_NOT_FOUND` (케이스 실행과 같은 글자) |
| 러너가 거절(400·404·500)하거나 닿지 못함 | 실행은 `FINISHED`, 부품 전부 `NA` + 같은 `error.message`(케이스 실행의 「러너가 거절했다: …」·「러너에 닿지 못했습니다」와 같은 문장) |
| 결과가 왔는데 실행이 이미 `RUNNING` 이 아님(재기동 복구가 닫음) | 결과를 버린다 — 먼저 닫힌 것을 덮지 않는다 |
| `GET /api/runs/:runId/scenario` 에 케이스 실행 번호 | 404 `RUN_NOT_FOUND` |
| 시나리오 사진이 없음 · `seq` 가 숫자가 아님 | 404 `SCREENSHOT_NOT_FOUND` · 400 `INVALID_REQUEST` |
| 목록 `?kind=` 에 모르는 값 | 조용히 `case` 로 본다 — `state` 와 같다 |
| 목록 줄 `stoppedAt` | 처음으로 `PASS` 가 아닌 부품의 `seq`. 전부 `PASS` 이거나 도는 중이면 `null` |
| `lastRun.verdict` 접기 | 전부 `PASS` → `PASS` · 하나라도 `FAIL` → `FAIL` · 그 밖(`TIMEOUT`·`ABORTED`·러너 고장) → `NA` · 도는 중 → `null` |
| 부품 `timeout_ms` 스냅샷 | 케이스 부품마다 `300000` (제한 시간 계산의 케이스 몫과 같다) |

### BLOCKER 1 — E2E 탭 집계 띠와 `state=failed` 가 늘 0 (eng)

되돌리기는 모양만 보고, API 30초 몫이 새로 붙어 옛 버전이 60분을 넘을 수 있다. 러너 400 → 「부품 전부 NA」 쓰레기 실행. `runnable` 에 제한 시간·크기를 넣어 409 `SCENARIO_NOT_RUNNABLE`.

### 주의 2 — 결과 저장 순서·실패 처리 (eng·ceo)
먼저 `UPDATE test_run … WHERE status='RUNNING'` 0행이면 ROLLBACK, 그다음 부품(`finished_at IS NULL`)·절차. 저장이 던지면 실행이 재기동까지 RUNNING — 잡아서 NA+사유로 닫거나 한계로 적는다. 분배는 `.catch` 로그.

### 주의 3 — 러너 응답 부품 수가 행 수와 다를 때 (eng)
`seq` 로 짝 맞추고, 짝 없는 행은 NA+사유, 모르는·겹친 seq 는 버린다.

### 주의 4 — `skipped_steps`·`mocks`·`step.skipped` 저장 단언이 없다 (eng)
`skippedSteps` 는 `steps.filter(s => s.skipped)` 로 만든다. RED 에 세 칸.

### 주의 5 — 실행 행 칸 · 비활성 서비스 (eng)
`service_id`·`env`·`status`·`triggered_by(_name)`·`notify_slack=false` 단언. `service_id` 가 비면 권한 문이 모두 403. 비활성 서비스 400.

### 주의 6 — 결과 응답에 비밀값 가릴 스키마 없음 (eng)
`parts[]` 에 `paramSchema`·`expectedSchema`·`precondition` 스냅샷을 싣는다(케이스 실행과 같게).

### 주의 7 — 사진 `:seq` 는 절차 순번 (eng)
명세와 RED 에 「절차 순번(시나리오 전체에서 이어짐)」. 부품 2 의 절차 사진으로 확인.

### 주의 8 — 비동기 분배 찌꺼기 · 메타 숫자 (eng)
라우트 검사는 가짜 러너를 두고 `afterAll` 전에 FINISHED 를 기다린다. 「예상 묶음 4개」와 화살표 여섯이 어긋남.

### 주의 9 — WS-D 로 넘기는 일이 기록에 없다 (ceo)
WORKSTREAMS 6번에 「단건 조회 `kind='CASE'` 404 를 E2E 증적으로 바꾼다」.

### 주의 10 — WS-E 결과 화면이 번호만으로 종류를 모른다 (ceo)
`GET /api/runs/:runId` 404 를 시나리오 전용 글자로 가르거나, 「화면은 목록 탭·`/scenario` 로 가른다」를 WS-E 에 넘긴다.

### 주의 11 — ② 가 넘긴 ④(뿌리 밖 경로 500)·⑤(깨진 소스 판별) (ceo)
할 일 5 가 `케이스재료` 를 부르므로 ④ 가 실행 요청까지 500 으로 번진다. 막을지 넘길지 적는다.
