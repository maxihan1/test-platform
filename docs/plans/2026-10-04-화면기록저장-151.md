# 화면 기록 저장 — 바뀐 화면만 다시 훑는다

등급: 3 · 갈래: WS-작성 · 2026-10-04

## 도메인 정리

작성 BC §3.6 「★ 역방향」 크롤러 절과 올리기 허용 목록(`cases-only.mjs` — CI 차선과 작성 올리기가 같이 쓴다). 계약(타입 · API · DB) 변경 없음.
저장 자리는 저장소 `docs/screens/<접두사>/` — 작성 PR 에 실려 병합되면 main 에 남고, 다음 작성의 작업 트리(main 사본)에 그대로 있다.

## 왜

사용자 지시 11. 크롤러(#150)가 구조는 1~3분에 뽑지만, 보조가 화면마다 쓰는 기록(요소 · 규칙 · 오류 문구 · 연 한 칸)은 매번 새로 쓴다. 바뀌지 않은 화면의 기록을 다시 쓰면 다시 작성 · 이어 작성마다 훑기 20분 안팎을 쓴다.
#150 이 남긴 「지난번보다 화면이 줄면 보이게」도 저장본이 있어야 견줄 수 있다.

게이트 0 승인 여섯 문장.
1. `docs/screens/<접두사>/` 에 화면 기록 `.md` 와 `index.json`(주소 · 상태 · 틀 · 구조 지문 · 글자 지문 · 기록 이름)
2. 옮기는 쪽은 에이전트(스크립트) — 작성이 끝나면 자료 폴더의 기록 · 크롤 목록을 이 자리로 복사
3. 지문 둘 — 글자 지문까지 같을 때만 저장 기록을 그대로 쓴다
4. 다음 작성 — 크롤러가 저장본과 견줘 목록에 같음 · 바뀜 · 새 화면. 같음은 저장 기록을 가져다 쓰고 나머지만 보조가 훑는다
5. 크롤 요약에 「저장본에 있는데 이번에 못 본 화면 K장」
6. 올리기 허용 목록에 `docs/screens/<접두사>/` 의 기록 · `index.json`(이름 꼴 좁게)

## 이름 맞추기 (설계)

보조는 화면 기록을 **크롤 파일 이름으로** 쓴다 — 크롤 `로그아웃/012.yml` → 기록 `out-012.md`, `로그인/007.yml` → `in-007.md`(저장소 파일 이름은 영문 소문자 · 숫자만).
크롤에 없는 화면(더 갈 곳)은 `extra-<영문 이름>.md` — 지문이 없어 저장하지 않고 다음에도 훑는다.
저장본은 `상태 + 틀` 로 맞춘다(번호는 실행마다 바뀐다).

## 게이트 1 결정 (2026-10-04) — 저장 자리를 에이전트 디스크로

사용자 「에이전트 디스크로 바꾸고 진행」. 게이트 0 문장 1 · 2 · 6(저장소 `docs/screens` · 올리기 허용 목록)을 아래로 바꾼다 — 검토 BLOCKER 1(반영 충돌) · 주의 1(main 이력에 개인정보 영구) · 주의 4 의 허용 목록 · 반영 동반 수정이 통째로 사라진다.

- **자리**: 작업 바탕(`AUTHORING_WORK_DIR`, 서버 `/work` 볼륨) 아래 `screens/<접두사>/` — root 소유 0700. 보관 훑기는 `author-<번호>` 만 보므로 안 건드린다. 디스크가 비었거나 다른 기계면 저장본 없음 — 전부 훑는다(안전한 쪽)
- **넣기**: 자식을 띄우기 전에 에이전트가 저장본을 자료 폴더 `kept/` 로 복사(`새로쓰기` — 지우고 `wx`). 크롤러 `--keep <자료>/kept/index.json`
- **갈기**: 올리기 때 에이전트가 자료 폴더 `crawl/list.json` · `crawl/summary.json` · `screens/*.md` 를 읽어 **이번에 본 화면만** 저장본에 갈아 끼운다. 기록 첫 줄 `# <크롤 주소>` 로 목록과 맞추고, 안 맞으면 저장하지 않는다. 지우기는 화면만 · 멈춘 까닭 「다 봄」일 때만(BLOCKER 2). `list.json` 이 없으면 아무것도 안 한다
- **안전**(BLOCKER 3): 자료 폴더에서 읽는 파일은 lstat 일반 파일 · nlink 1 · realpath 가 자료 폴더 안 · 200KB 이하. 저장 폴더는 에이전트가 만들고 링크면 쓰지 않는다. 파일은 임시 이름에 쓰고 rename
- **지문**(주의 3): 글자 지문은 `.yml` 전체(입력칸 머리 포함, 숫자만 0). 기록마다 훑은 날 — 30일이 지나면 「바뀜」으로 본다. 요약 「저장본 같음 N · 바뀜 M · 새 화면 K · 못 본 화면 L · 가장 오래된 것 D일」
- **이어하기**(주의 2): `resume.md` 에 「크롤 폴더가 있으면 다시 돌리지 않는다」. extra 기록은 묶음 번호를 붙인다
- 동시 반영: 같은 서비스 두 건이 거의 같이 끝나면 index 를 읽고 고쳐 쓰는 사이에 한쪽 갱신이 빠질 수 있다 — 빠진 화면은 다음에 다시 훑을 뿐이라 둔다(ponytail)
