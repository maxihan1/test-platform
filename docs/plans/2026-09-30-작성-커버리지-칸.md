## 왜

PR #119 가 원장 대조와 셈을 만들었지만 **셈은 PR 본문 글뿐**이다 — 요청마다 몇 % 를 덮었는지 화면에서도 대시보드에서도 못 본다.
게이트 0(2026-09-30 사용자)이 칸 다섯 · `finish result.coverage` · 상세 `coverage` · 작성 화면 한 줄 · Grafana 칸 권한을 승인했다.

## 명세가 안 정한 것 — 제안 (게이트 1 에서 승인받는다)

| 무엇 | 제안 | 까닭 |
|---|---|---|
| 셈 단위 | **실행 하나**. 이어서 작성 · 다시 작성도 각자 원장을 다시 뽑아 대조하므로 그 실행 행에 그 실행의 셈이 선다 | 에이전트가 실행마다 원장을 뽑는다(`authoring-run.ts` `원장준비`) |
| 보류와 케이스 | **`held` 는 `cased` 안에 든다** — `cased` 는 케이스 파일로 덮인 번호(보류 케이스 포함, PR 본문 셈의 「케이스 a」와 같다). `held` 는 그중 **덮은 케이스가 전부 보류**인 번호. `total = cased + excluded + missing` | 명세가 「보류 케이스도 덮는다」로 정했다(§3.6 「덮는다는 것」) · 비율이 `cased / total` 한 번으로 나온다 |
| 보류를 못 셌을 때 | 보류 목록을 못 읽었으면(`heldUnknown`) · 올리기 거절이면(보류 스캔은 DONE 때만 돈다) `held: null` · 칸 `coverage_held` NULL | 0 으로 채우면 「보류 없음」으로 읽힌다 — 토큰 칸과 같은 이유 |
| 언제 싣나 | **원장 대조를 한 뒤의 모든 끝내기** — DONE 과, 대조가 빠짐으로 거절한 `STOPPED · REJECTED`(그때 `missing` 이 찬다). 대조 뒤 push · PR 실패 같은 거절에도 싣는다. 대조 전에 끝나면(테스트 밖 파일 · 시간초과 · 원장 없음) 안 싣는다 — 칸 전부 NULL | 칸 `coverage_missing` 이 0 이 아닐 수 있는 자리는 거절뿐이다 |
| 서버 모양 검사 | 틀리면 `400 { error: 'BAD_COVERAGE' }`. 넷은 0 이상 정수 · `held` 는 정수나 null · `excluded` 는 종류 이름(1~20자) → 0 이상 정수, 종류 10개까지 · `missing` · `later` 는 번호 글(1~60자) 배열 · `cased + Σexcluded + missing 길이 = total` · `held ≤ cased` · `later 길이 ≤ Σexcluded` · `total ≤ 10000`. **종류 이름 목록은 서버에 옮겨 적지 않는다**(정본은 `scripts/authoring-ledger-check.ts`) | 에이전트가 틀리면 끝내기 400 → 에이전트가 FAILED 로 다시 보낸다(2026-09-29 `거절된보고대신`). 닫힌 목록을 둘로 두면 한쪽이 뒤처진다 |
| 칸 짝 | `CHECK` 하나 — 네 칸(`total` · `cased` · `excluded` · `missing`)이 전부 NULL 이거나 전부 차고 합이 맞는다 · `held` 는 NULL 이거나 0~`cased` | 짝이 깨지면 대시보드 비율이 조용히 틀린다 |
| 상세 `coverage` | `{ total, cased, held, excluded: {종류: 수}, missing: [번호], later: [번호] } \| null` — 요청한 그 행의 `result.coverage` 를 그대로(끝내기에서 이미 모양을 봤다). `runs[]` 에는 안 싣는다 | 화면은 최신 실행 상세를 한 번 더 읽는다(§7 「실행 기록」) |
| 화면 한 줄 | Status 카드 숫자 칸 아래 `기획서 요구` 라벨 · `172개 → 케이스 48(보류 3) · 제외 124 · 빠짐 0`. `held` 가 null 이면 `(보류 …)` 를 뺀다. `coverage` 가 null 이면 줄이 없다. 제외 종류별 수는 안 싣는다(종류 이름이 영어 표에 없다) · 판정 색 없음(잉크) | DESIGN 원칙 1 · 한 줄 |
| Grafana 패널 | **「작성 커버리지」 표 하나**(24칸 폭, 맨 아래). 최근 30일(끝난 시각) 끝난 실행 중 칸이 찬 것, 최근 것 먼저 30줄 — `번호 · 서비스 · 방식(보통/화면과 대조/재실행) · 결과(성공/중단 · <이유>/실패) · 요구 · 케이스 · 케이스 % · 보류 · 제외 · 빠짐`. 열 칸은 권한 표의 다섯 + 이미 연 칸뿐 | 「패널이 읽는 칸에만 연다」(데이터모델 「대시보드 칸 권한」) — 칸만 열고 패널이 없으면 그 규칙과 어긋난다. 뿌리로 묶으려면 `source_id` · `resume_from` 을 더 열어야 해서 실행 한 줄로 둔다 |
