## 이 화면에서 걸린 것

- 앱이 Compose 라 resource-id 에 꾸러미가 없다(`login_id`). 러너는 `appium:disableIdLocatorAutocompletion` 을 안 넘겨 `id=login_id` 가 안 찾힌다 — `android=new UiSelector().resourceId("…")` 로 찾는다
- `~login_button` 은 버튼 안쪽 View 라 그 안에 「로그인」 글자가 없다. 글자 · 눌림은 바깥 버튼(UiSelector `login_button`)에서 읽는다
- 아이디 입력칸 값은 적은 직후 읽으면 빈 글자가 나온다 — 칸이 비지 않을 때까지 기다린 뒤 읽는다
- 디바이스 팜 폰의 앱이 대상 서버에 닿지 않아(기본 주소 http://localhost:3002) 로그인 뒤 화면을 못 읽었다. 그때 문구는 토스트가 아니라 로그인 화면 입력칸 아래 글자로 보였다
