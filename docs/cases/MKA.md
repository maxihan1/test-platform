## 이 화면에서 걸린 것

- 결제 수단 · 취소 사유 라디오는 골라짐 정보가 화면에 없다 — 버튼 반응 줄에서 뺐다
- 화면 아래로 가려진 요소는 없는 요소로 잡힌다(Compose) — `밀어서찾기` 로 내린 뒤 찾는다
- 서버 `DELETE` 요청은 본문 없이 `content-type` 을 붙이면 거절된다
