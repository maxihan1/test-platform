## 이 화면에서 걸린 것

- 화면 언어 — 테스트 계정은 언어 설정이 비어 브라우저 언어(영어)로 뜬다. Playwright 실행기가 en-US 를 흉내 내 요청 머리를 덮어쓰므로 `한국어로(page)` 가 창 묶음 가로채기로 `accept-language` 를 바꾼다
- 계정 칸 이름 — 일반 회원은 `loginId` · `loginPassword` 여야 kit 이 채운다(`userId` 는 안 채운다). `expected` 를 빼면 kit 이 명세를 못 만든다 — 없으면 `null`
- 초기 상태 가짜 응답 — 문서를 `route.fetch()` 로 다시 받을 때 한국어 머리를 같이 실어야 한다(`helpers/mock.helper.ts`)
- 30초에 끊긴 케이스는 finally 가 안 돈다 — 계정 이동 리디렉션 · 가져오기 확인 대기 · 자기소개가 남았다. 지난 실행 흔적을 첫 절차에서 풀고 시작한다
- 큰 CSV 가져오기는 화면 양식으로 보내면 확인 화면 대신 첫 화면으로 가서 시간 초과가 났다 — `계정설정화면.가져오기양식보내기` 로 보낸다
- 자기소개 칸은 501자도 받는다(글자 수 표시만 있다) — 저장 단계에서 막히는지 본다
