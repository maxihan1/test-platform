# MTA 서비스 가이드 요약

## 서비스
Mastodon 공식 Android 앱 2.13.5(꾸러미 org.joinmastodon.android)를 디버그 빌드한 것이다. 서버는 https://mastodon.maxihan.com 이고 웹(MTW)과 같은 서버 · 같은 계정을 쓴다.

## 테스트할 때 지킬 것
- 로그인은 앱 밖에서 한다 — 첫 화면 「로그인」 → 서버 주소 → 「다음」 → 폰 Chrome 웹 로그인 → 「승인」 → 앱으로 돌아온다
- Chrome 이 처음 켜지면 Google 계정 화면이 먼저 뜬다 — 「로그아웃 상태 유지」로 넘긴다
- 「mastodon.social 에 가입하기」는 바깥 서버라 누르지 않는다
- 서버 메일(가입 확인 · 암호 재설정)은 서버 안 Mailpit 에만 쌓인다 — 메일 속 링크를 눌러야 하는 흐름은 막힌다
- 테스트가 만든 글 · 미디어 · 목록 · 필터는 케이스 끝에서 지운다. 같은 서버를 웹 · 앱 · 운영툴 · API 테스트가 같이 쓴다
- 계정 상태를 바꾸는 일(정지 · 침묵 · 역할 변경 · 삭제)은 두 번째 사용자에게만 하고 끝에서 되돌린다. qa_admin · qa_mod · qa_user1 은 건드리지 않는다
- 시드는 이름(계정 이름 · 글 내용 · 목록 이름)으로 찾는다. 글 번호 · 계정 번호는 케이스에 넣지 않는다
- 개수는 「n개 이상」으로 확인한다
- 시드는 바꾸지 않는다. 예외 — req_yoon 요청 승인 · 거절, mute_jang 뮤트 · 뮤트 해제, filt_hong 걸러진 알림 수락 · 무시
- 가입 케이스는 사용자명을 tc_signup 으로 시작하게 쓴다
- 앱 첫 화면은 그림이 계속 움직여 명령마다 10초씩 기다린다 — 첫 화면 구간은 kit `움직이는화면에서` 로 감싼다

## 배운 것
- 요령 · 데이터 — 팔로우를 풀면 그 사람이 내 목록 구성원에서도 빠진다 — 시드 팔로우를 건드렸으면 다시 팔로우하고 목록 구성원도 되돌린다
- 요령 · 기다리기 — 로그인 서버 고르기에서 입력 칸과 서버 카드가 같은 글자를 가진다 — 카드는 title id 와 글자를 같이 걸어 누르고 「다음」이 켜질 때까지 기다린다
- 요령 · 공용 서버 — 앱 데이터를 남기는 연결(keepAppData)로는 이 앱이 켜지지 않는다 — 케이스마다 데이터를 지우고 Chrome 에 남은 웹 로그인으로 「승인」만 눌러 들어온다
- 요령 · 데이터 — 다른 테스트가 qa_user1 의 표시 이름 · 필터를 바꿔 둔다 — 표시 이름 · 필터 개수를 고정값으로 기대하지 않는다
- 요령 · 기다리기 — 서버 고르기 칸은 값만 넣으면 서버를 안 찾는다 — 칸을 누르고 마지막 한 글자는 키(mobile: pressKey)로 쳐야 서버 카드가 뜬다
- 요령 · 기다리기 — 화면이 작은 폰은 웹 로그인 암호 칸이 키보드에 가려 안 찾힌다 — 이메일을 넣은 뒤 키보드를 내리고 암호 칸을 찾는다
- 요령 · 공용 서버 — 이메일 확인 대기 계정으로 크롬 웹 로그인을 하면 /auth/setup 세션이 크롬에 남아 그 폰의 다른 로그인이 막힌다 — 확인 대기 화면은 앱 안 가입으로 연다
- 요령 · 데이터 — 폰에 넣은 파일은 글쓰기 「미디어 추가」를 길게 눌러 여는 파일 선택기에서 이름으로 고른다 — 짧게 누르면 뜨는 사진 선택기는 이름이 안 보인다
- 요령 · 데이터 — 해시태그 타임라인은 태그 주소로 안 열린다 — 검색에서 「#태그」를 적고 결과 줄을 누른다
- 요령 · 데이터 — 둘러보기 「소식」 · 「추천」 탭은 대상 서버에 자료가 없어 안내 문구만 보인다 — 카드 · 계정이 있다고 기대하는 케이스는 자료가 생길 때까지 보류다
- 요령 · 기다리기 — 대체 텍스트 화면에서 미리보기를 확대한 뒤 뒤로 오면 그 화면이 남아 글쓰기로 못 돌아온다 — 확대를 본 케이스는 그 뒤 동작을 잇지 않는다
- 요령 · 되돌리기 — 프로필 항목 · 소개 해시태그는 「저장」 · 「추가」를 누르는 순간 서버에 남는다 — 케이스가 더한 것은 끝에서 지우고 시작할 때도 앞 실행이 남긴 같은 머리 이름을 지운다
- 요령 · 기다리기 — 글 본문 가운데를 누르면 해시태그 · 링크가 눌린다 — 글 상세는 본문 왼쪽 끝을 눌러 연다
