# MTA 서비스 가이드 요약

## 서비스
Mastodon 공식 Android 앱 2.13.5 를 우리 포크로 디버그 빌드한 앱이다(패키지 org.joinmastodon.android).
서버는 https://mastodon.maxihan.com 이고 웹(MTW)과 같은 서버 · 같은 계정을 쓴다.

## 테스트할 때 지킬 것
- 로그인은 첫 화면 「로그인」 → 서버 URL 칸에 mastodon.maxihan.com → 「다음」 → 폰 Chrome 웹 로그인 → 앱으로 돌아오는 길이다
- 폰 Chrome 이 처음 켜지면 Google 계정 화면이 먼저 뜰 수 있다 — 「로그아웃 상태 유지」로 넘긴다
- 「mastodon.social 에 가입하기」는 바깥 서버라 누르지 않는다
- 서버 메일(가입 확인 · 암호 재설정)은 서버 안 Mailpit 에만 쌓인다 — 메일 링크를 눌러야 하는 흐름은 막힌다
- 테스트가 만든 글 · 미디어 · 목록 · 필터는 케이스 끝에서 지운다. 웹 · 앱 · 운영툴 · API 테스트가 같은 서버를 쓴다
- 계정 상태를 바꾸는 일(정지 · 침묵 · 역할 변경 · 삭제)은 qa_user2 에게만 하고 끝에서 되돌린다. qa_admin · qa_mod · qa_user1 은 건드리지 않는다
- 시드는 바꾸지 않는다(신고 해결 · 승인 · 정지 · 삭제). 바꾸는 요구는 같은 꼴의 데이터를 케이스가 만들고 끝에서 지운다
- 시드는 이름(계정 이름 · 글 내용 · 목록 이름)으로 찾는다. 글 번호 · 계정 번호 같은 숫자 ID 는 넣지 않는다
- 개수는 「n개 이상」으로 확인한다
- 가입 케이스의 사용자명은 tc_signup 으로 시작한다 — 준비 때 모두 지운다

## 배운 것
- 요령 · 기다리기 — 앱 첫 화면 그림이 쉬지 않고 움직여 누를 때마다 화면 멈춤을 수십 초 기다린다 — 케이스 첫머리에 멈춤 기다림을 끈다(helpers/app.helper.ts 「멈춤기다림끄기」 · 로그인 도우미가 부른다)
- 요령 · 공용 서버 — 폰 Chrome 에 앞 케이스의 웹 로그인이 남아 승인 화면이 바로 뜬다 — 승인 화면의 계정이 넣을 계정과 다르면 웹에서 로그아웃하고 다시 들어간다
- 요령 · 공용 서버 — 이메일 확인 대기 계정으로 웹 로그인하면 Chrome 이 확인 메일 안내 화면에 묶여 다음 케이스 로그인이 막힌다 — 그 계정으로 웹 로그인하지 않는다
- 요령 · 데이터 — 가입 경로 서버 고르기는 입력 칸을 먼저 눌러 초점을 준 뒤 적어야 우리 서버 카드가 뜬다
