## 분해 근거

**요구 1~3 은 한 문단을 셋으로 끊은 것이다** (규칙 R1). §2 첫 문단에 「~되며」와 마침표로
요구가 셋 붙어 있었다 — 등록 · 남은 개수 표시 · 빈 목록 숨김.

**워딩 통일** — 기획서의 「등록된다」·「반영된다」를 **「목록에 ~이 보인다」** 하나로 모았다.
화면에서 눈으로 확인할 수 있는 문장이어야 `verify()` 가 실제 값을 볼 수 있다.

**요구 2 에만 경계 축이 붙었다** (규칙 R3). 기획서가 「할 일이 하나도 없을 때는」이라고
**0건을 명시**했기 때문이다. 나머지에는 범위·개수·상한이 안 적혀 있어 경계를 만들지 않았다.

**예외 축은 하나도 안 만들었다** (규칙 R4). 기획서에 실패·오류 화면이 적혀 있지 않다.

**요구 1 과 2 는 전제·조작이 거의 같지만 합치지 않았다.** 기획서가 「등록」과 「개수 표시」를
별개로 적었고, 합치면 **회귀에서 어느 요구가 깨졌는지 못 가린다.**

**판정 불가 셋은 케이스로 만들지 않는다.** 여기서 AI 가 「그럴듯하게」 해석하면 돌릴 때마다
다른 케이스가 나온다. 기획자에게 되물어야 할 자리다.

## 용어 사전

화면을 실제로 열어 확정했다 (`ariaSnapshot` 탐침).

- **화면 스냅샷 해시**: `73d937f42658` (빈 화면, 2026-09-21)

**다음 실행은 탐침을 돌려 해시를 비교한다.** 같으면 아래 표를 그대로 쓰고 **화면 해석을 하지 않는다.**
다르면 바뀐 부분만 다시 본다. 이 사전이 아끼는 것은 유지보수가 아니라 **생성 비용**이다 —
케이스 파일들은 각자 locator 를 들고 있다.

| 도메인 용어 | 화면에서 무엇 | locator |
|---|---|---|
| 화면 제목 | 맨 위 제목 | `getByRole('heading', { name: 'todos' })` |
| 할 일 입력칸 | 제목 아래 텍스트 상자 | `getByPlaceholder('What needs to be done?')` |
| 할 일 항목 | 목록의 한 줄 | `getByTestId('todo-item')` |
| 할 일 글자 | 그 줄에 보이는 글자 | `getByTestId('todo-title')` |
| 남은 개수 | 목록 아래 문구 | `getByTestId('todo-count')` |
| 완료 표시 | 할 일 왼쪽 동그란 칸 | `getByRole('checkbox', { name: 'Toggle Todo' })` |
| 완료분 지우기 | 완료된 것이 있을 때만 나오는 버튼 | `getByRole('button', { name: 'Clear completed' })` |

## 이 화면에서 걸린 것

같은 화면은 같은 데서 걸린다. 다음 케이스가 처음부터 알게 적어 둔다.

- **빈 목록에서 남은 개수 영역은 DOM 에 아예 없다.** `count()` 는 0, `isVisible()` 은 `false`.
  **「보이지 않는다」를 확인할 때는 `isVisible()` 을 쓴다** — `count()` 는 「없다」를 보는 것이라
  문장과 뜻이 어긋나고 재시도도 하지 않는다
- **완료 표시를 누른 뒤 남은 개수를 읽기 전에 기다려야 한다.** 앵커는 `Clear completed` 버튼이다 —
  완료된 것이 생겨야 나타난다(0 → 1). 기대값과 무관한 앵커라 진단을 흐리지 않는다
- **입력 직후 목록을 읽기 전에** `getByTestId('todo-item')` 이 보일 때까지 기다린다

## 요구 4 가 보류로 남은 이유

기획서 §3 은 마감일을 요구하는데 **화면에 그 요소가 없다.** 탐침 결과다.

```
마감일 낱말 적중: []          ← 본문에 마감·due·date·deadline 이 없다
date 입력칸: 0
input type 전부: [text, checkbox, checkbox, text]
```

여기서 그럴듯한 selector 를 지어내면 케이스가 5건이 되고 숫자는 좋아 보이지만,
그중 하나는 **아무것도 확인하지 않는 초록불**이 된다. **기대값은 사람이 판정한 것에서만 온다** (규칙 R10).

**기획자에게 물어야 할 것** — 마감일이 아직 안 만들어진 것인가, 이번 범위가 아닌가.
