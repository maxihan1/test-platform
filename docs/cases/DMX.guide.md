# DMX 서비스 가이드 요약

## 배운 것
- 요령 · 기다리기 — 홈은 공지 팝업과 조금 늦게 뜨는 만족도 설문이 앞을 가려 머리글 버튼이 안 눌린다 — 홈에서 다른 것을 누르기 전에 둘을 먼저 닫거나 닫은 기록을 넣고 연다
- 요령 · 데이터 — 쿠키 안내 띠 · 공지 팝업 · 만족도 설문은 브라우저 저장 값(동의 · 오늘 하루 안 보기 · 설문 닫음)으로 뜰지가 갈린다 — 처음 상태를 보는 케이스는 저장 값이 빈 새 창으로 연다
- 요령 · 공용 서버 — 장바구니는 서버에 저장되어 같은 계정을 쓰는 다른 실행이 수량을 바꾼다 — 장바구니 금액을 미리 적은 값으로 보지 말고 케이스 안에서 비우고 담은 뒤 본다
- 요령 · 데이터 — 주문서는 장바구니에서 주문 버튼으로 들어와야 상품이 실린다(주소에 고른 줄 번호가 붙는다) — 주문서 주소만 열면 빈 주문서가 뜬다
