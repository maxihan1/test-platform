# CGP 서비스 가이드 요약

## 서비스
〈캣츠고!〉(Cats Go!)는 한 PC 에서 1~4인이 하는 액션 디펜스 게임이다. 고양이로 식물을 심고 고기로 키우며 몰려오는 악마에게서 세계수(기지 `/Lumikantle`)를 지킨다.
Windows x64 Unity 빌드(v2.1.3 · Input System · uGUI + TextMesh Pro)이고 게임 서버 · 로그인 · 계정이 없다. Steam 없이 켜서 리더보드 · 업적은 동작하지 않는다(랭킹 패널 「사용할 수 없음」).

## 테스트할 때 지킬 것
- 창 훑기는 메인 메뉴에서 시작하는 한 상태로만 한다 — 로그인 상태가 없다
- 메인 메뉴 「게임종료」(`/MainMenu UI Canvas/Buttons/ExitBtn`)는 누르지 않는다 — 게임이 꺼진다
- 메인 메뉴 버튼마다 자식 `Btn_Hover` 가 따로 버튼으로 잡힌다 — 훑을 때 `--exclude Btn_Hover` 를 주고 부모 버튼을 누른다
- 환경설정 닫기 버튼 `SettingExitBtn` 은 창 훑기가 위험 버튼으로 보고 안 누른다
- 리더보드 · 업적은 이 환경에서 볼 수 없다
- 이 QA 빌드는 패드를 Switch 패드로 강제 인식한다
- 스테이지 들어가는 키 차례: 메인 메뉴 Enter(빠른 시작) → 1P Enter → 캐릭터 Enter → 칸마다 Enter · 방향키로 식물 · Enter, → 로 다음 칸 → 세 칸이 차면 ↓ · Enter(준비) → 맵 Enter → 장면 BossRoom3
- 원격 조작은 명령마다 몇 초씩 걸린다 — 스테이지에서는 `timescale-set 0.25` 로 늦추고 끝에 1 로 되돌린다
- 기지 무적(`call /Lumikantle Lumikantle.SetInvincible true`)은 조작을 익힐 때만 쓰고 판정 동작에는 안 쓴다. 끝에 false 로 되돌린다
- 기지 체력은 `Lumikantle.LumikantleHP.Value` 로 읽는다 — HUD 체력 막대 `fillAmount` 는 늘 1 이라 쓰지 않는다
- 식물 옆에서 F 는 회수다 — 카드를 닫을 때 말고는 누르지 않는다

## 배운 것
- 요령 · 데이터 — PC 를 놓았다 다시 잡으면 저장 값이 지워져 캐릭터 선택의 식물 칸이 빈다 — 칸이 비면 스테이지로 도우미가 못 들어가니 칸 셋을 먼저 채운다
- 요령 · 되돌리기 — 환경설정 언어를 바꾼 케이스는 정리 단계에서 처음 언어로 되돌린다 — 다른 케이스가 한국어 화면 글로 찾는다
- 요령 · 기다리기 — 로딩 화면 /LoadingScreen 은 꺼지지 않고 CanvasGroup.alpha 로 숨는다 — 로딩이 끝났나는 alpha 가 0 인지로 보고 Logo 가 있나로 보지 않는다
- 요령 · 기다리기 — 캐릭터 선택의 식물 칸 판은 고양이를 고르기 전에도 화면 밖에 켜져 있다 — 떴나는 find 의 y 가 화면 안인지로 본다
- 요령 · 기다리기 — 고르기 창을 닫은 직후 누른 방향키는 먹히지 않는다 — 칸 · 고르기 커서(Select_Arrow)가 옮겨진 것을 본 뒤 다음 키를 누른다
- 요령 · 되돌리기 — 환경설정 언어 좌우 버튼은 바뀐 글이 늦게 뜨고 한국어로 돌아오기까지 여러 번 걸린다 — 바뀐 것을 본 뒤 다음 버튼을 누른다
- 요령 · 데이터 — 판이 열리자마자 시작 자리에 심으면 될 때와 안 될 때가 있다 — (18.2, 27.0) 처럼 심긴 적 있는 자리로 걸어가 심는다
- 요령 · 기다리기 — 남은 악마 수는 30 에 닿은 뒤 악마가 세계수에 닿으면 준다 — 1웨이브 수는 들어가자마자 가장 큰 값으로 잰다
