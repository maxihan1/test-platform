# BRM 서비스 가이드 요약

## 서비스
Unity 「Boss Room」(4인 협동 액션 RPG 샘플)을 Android 로 빌드한 온라인 게임이다(패키지 com.maxihan.bossroom).
로그인 → 로비에서 영웅 8자리 중 하나를 골라 「준비!」 → 던전에서 임프 떼와 보스를 잡는다. 레벨 · 골드 · 가방 · 장비 · 상점 · 일일 퀘스트 · 우편 · 채팅 · 친구 · 파티 · 길드가 있다.
게임 서버는 bossroom.maxihan.com(443 · WebSocket), 계정 · 데이터는 API 서버(bossroom-api.maxihan.com)가 맡는다.

## 테스트할 때 지킬 것
- 계정은 역할로만 쓴다 — 일반 회원 · 두 번째 플레이어(봇) · 세 번째 · 네 번째 플레이어(봇, 4명 파티용) · 새 계정(「처음 들어온 캐릭터」 케이스만, 시작에서 시험 주소 reset mode new)
- 봇 계정을 쓴 케이스는 시작과 끝에 시험 주소 reset(mode base)로 되돌린다. 실행마다 일반 회원 · 두 번째 플레이어는 기준 상태(레벨 1 · 골드 200 · 체력 물약 3 · 친구 · 길드 · 우편 없음)로 돌아가고 봇 · 걸어 둔 실패 · 전리품 고정이 치워진다
- 계정 없는 손님 봇은 파티 · 길드 · 친구 초대를 못 받는다 — 서버 인원 · 로비 자리 채우기에만 쓴다
- 게임 서버 · API 서버 · 운영툴은 한 서버를 같이 쓴다. 게임 케이스는 동시에 돌리지 않는다(로비에서 다른 접속자까지 준비해야 던전이 열린다)
- 혼자 던전에 들어가면 적이 주는 피해가 절반(둘이면 75%)이다
- 점검을 켠 케이스는 끝에서 반드시 끈다 · 제재는 두 번째 플레이어에만 걸고 끝에서 푼다 · 테스트 공지는 제목을 [QA] 로 시작하고 끝에서 지운다 · 지급 · 회수 시험은 두 번째 플레이어로, 재화는 Gold
- 운영 기능(우편 지급 · 제재 · 점검 · 공지)은 어드민 키로 bossroom-api.maxihan.com/opsapi 를 부른다. 봇 · 실패시키기 · 계정 되돌리기 · 접속 끊기는 bossroom.maxihan.com/test 다(같은 키)
- 상태 만드는 길: 폰 접속 전에 있어야 하는 것(다른 접속자 · 인원 가득 · 같은 계정 접속 · 로그인 실패 · 새 계정)은 시험 주소, 접속 뒤 내 캐릭터 상태(레벨 · 골드 · 체력 · 자리 · 적 · 전리품 · 퀘스트)는 채팅 칸 /gm, 우편 · 제재 · 점검 · 공지는 운영 API
- 화면에 없는 서버 값(배율 · 준 피해 · 처치 수 · 표 값)은 /gm stat · /gm data 로 읽는다(채팅 창 「[알림] [GM] …」 줄). GM 은 읽어 주기만 하고 기대값은 기획서에서 온다
- /gm hp · tp · spawn · killall · killboss · heal · faint 는 던전 안에서만 된다. /gm killall 은 처치 보상을 그대로 준다 — 값을 보는 케이스는 치운 뒤 /gm level · /gm gold 로 다시 맞춘다
- /gm loot 고정 · 레벨 · 골드를 바꾼 케이스는 끝에서 처음 값으로 되돌린다(/gm loot off)
- 화면에 버튼이 없어 폰으로 못 보내는 요청(상점에 없는 아이템 구매 · 장착 중 아이템 판매 · 물약 장착 · 길드가 있는데 만들기)은 봇에게 시키고 봇 log 의 오류 알림을 본다
- 봇을 켠 케이스는 끝에서 반드시 끈다. 켜 둔 봇이 로비에 남으면 뒤 케이스가 던전에 못 들어간다
- 다음 게임 API 요청 실패시키기(/test/fail)는 건 바로 뒤에 그 요청을 일으킨다 — 남으면 다음 케이스를 실패시킨다
- 화면 좌표를 누르는 길 · 엔터 키를 보내는 길 · 레벨 곡선과 퀘스트 표를 돌려주는 API 는 없다
- 손가락을 올려 둔 동안만 보이는 말풍선은 touchDown 으로 눌러 둔 채 보고 finally 에서 뗀다
- 가이드는 판매가 최소 1 골드를 상점의 「조약돌」을 사서 팔아 보라고 적었다(기획서 상점 8종에는 없다) · 받는 피해 최솟값은 /gm level 30 · 「사슬 갑옷」 장착 · 혼자 던전 · /gm killall 뒤 /gm spawn imp 로 만든다
- 머리 위 숫자는 DamageNumberEnemy · DamageNumberMine · HealNumber 아래 Text, 결과 화면 조명은 PostGame 장면 「Directional Light」의 Light.color 로 읽는다

## 배운 것
- 요령 · 데이터 — 창 훑기 · 탐색은 상점 구매 · 판매 · 보상 받기까지 눌러 계정의 골드 · 가방 · 퀘스트가 바뀐다 — 값을 보는 케이스는 시작에서 시험 주소 reset(mode base)로 되돌린 뒤 쓴다
- 요령 · 공용 서버 — 길드 이름은 서버 전체에서 겹치면 안 된다 — 케이스가 만드는 길드는 qa 로 시작하는 케이스마다 다른 이름을 쓰고 끝에서 「길드 탈퇴」로 지운다
- 요령 · 기다리기 — 혼자 던전에서 쓰러지면 2.5초 뒤 결과 화면으로 넘어간다 — 쓰러진 뒤 값을 읽는 케이스는 두 번째 플레이어 봇을 살려 둔 채 같이 들어간다
- 요령 · 기다리기 — GM 결과는 채팅 창 줄 「[알림] [GM] stat 키=값」으로 오고 알림 칸에도 「[GM] …」가 뜬다 — 알림 수를 세기 전에 앞 알림이 사라지기를 기다린다
- 요령 · 기다리기 — 조작 안내 창 「확인」은 창이 막 뜬 직후 누르면 안 먹을 때가 있다 — 창이 닫힐 때까지 세 번까지 다시 누른다
- 요령 · 기다리기 — 접속 중 점검 · 정지로 내보내기는 30초 주기라 35초까지 기다린다
- 요령 · 데이터 — 우편 제목 · 찾을 글에 대괄호를 넣지 않는다 — 오브젝트 선택자 값이 대괄호에서 끊긴다
- 요령 · 되돌리기 — 우편 저장 실패 걸기(/api/savemailmessage)는 걸고 바로 「받기」를 눌러 소진한다 — 남으면 뒤 케이스의 우편 받기가 실패한다
- 요령 · 데이터 — 봇은 우편을 못 받는다 — 봇에게 아이템을 갖게 하려면 폰이 그 계정으로 우편을 받아 장착한 뒤 접속을 끊고 봇을 켠다
