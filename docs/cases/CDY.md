#### 이 화면에서 걸린 것
- 회원가입 팝업: `?modal=signup` 을 바로 열면 팝업이 안 뜬다. 지역 단계(`?modal=signup-region`)를 열고 「서울」을 골라 「다음」을 눌러야 약관 단계가 열린다.
- 회원가입 팝업 지역 단계: 「다음」 버튼은 지역을 고르기 전에는 이름이 「지역을 선택해 주세요」이고 꺼져 있다. 지역을 고른 뒤에야 이름이 「다음」으로 바뀐다. 그래서 이름 「다음」으로 잡는 locator 는 지역을 고른 뒤에만 맞는다.
- 회원가입 팝업 약관 단계: 체크박스에 접근 이름이 없고 감싼 라벨 글자로만 잡힌다. 역할 checkbox 에 이름을 줘서는 못 잡는다.
- 회원가입 팝업 약관 단계: 셋째 체크 직후에 「다음」을 읽어도 켜져 있었다. 3회 연속 기다림 없이 통과했다.
- 로그인 화면: 지역 목록 링크의 접근 이름이 「대전 대전 캠퍼스」처럼 지역 이름과 캠퍼스 이름이 이어진 글자다. 이름 전체 일치로 잡으면 못 찾는다.
- 로그인 화면: 「비밀번호 보기」를 누르면 같은 자리 버튼의 이름이 「비밀번호 숨기기」로 바뀐다.
- 로그아웃 상태 홈 `/`: 열자마자 `role="dialog"` 팝업 둘이 겹쳐 뜬다. 보임 판정은 가려져도 보이는 것으로 읽혀 통과한다. 이 홈에서 무언가를 누르는 케이스를 쓸 때는 팝업을 먼저 닫아야 한다.
- 로그인 뒤 홈: 「Journey Start!」는 로그인 직후 10초 안에 떴다(3회 연속).

#### 이 화면에서 걸린 것
- 전체메뉴 패널은 닫힌 때에도 `display: flex`, `visibility: visible` 이고 화면 오른쪽 밖(`x=457`)에 있어서 Playwright 가 「보임」으로 센다. 「보임」을 기다리기만 하면 누르기 전에 통과하므로 `전체메뉴패널.화면안에_보이는가` 가 버튼 상자가 화면 폭 안에 들어올 때까지 기다린다.
- 「전체메뉴」 버튼은 폭 1025 이상에서 `display: none` 이다. 케이스가 폭 390 으로 줄인 뒤 홈을 다시 열고 버튼이 보이는 것부터 확인한다.
- 닫힌 사용자 메뉴의 목록은 `visibility: hidden` 이라 「내 정보」 · 「로그아웃」이 보이지 않는 것으로 잡힌다. 누른 뒤에 보이는 것을 기다리면 된다.
- 사진 안내 말풍선은 DOM 에 늘 있고 눌러야 보인다. 「보임」을 기다려서 가른다.
- 비밀번호 변경 창은 「취소하기」를 누르면 제목이 DOM 에서 사라진다. 「안 보임」을 `hidden` 상태로 기다리면 된다.
- 「내 정보」로 가는 길이 둘이다. 사용자 메뉴의 버튼은 `/main/myinfo/ams/list`, 주소를 직접 열면 `/myinfo/ams/list` 다. 화면은 같아서 케이스는 주소가 아니라 제목으로 확인한다.
- 같은 계정으로 다른 곳에서 새로 로그인하면 먼저 연 탐침 세션이 로그인 화면으로 돌아갔다(스냅샷 해시가 로그인 화면 값과 같아졌다). 같은 계정을 여러 묶음이 쓸 때 일시 빨강이 날 수 있다.

#### 이 화면에서 걸린 것
- 세계관: 스토리 카드 번호가 열 단위로 놓여(#1 #5 #9 …) 화면 읽는 순서와 다르다. 순서는 안 보고 보이는 카드 수만 센다. 영상 플레이어 아래에 눈에 안 보이는 안내 문단(`sr-only`)이 있어 글자로 집으면 겹칠 수 있으므로 이름이 붙은 요소로 잡는다.
- 소개: 구역 제목의 단계가 h2 와 h3 로 섞여 있어 이름만 정확히 맞춰 집는다.
- 캠퍼스: 처음에는 서울 카드가 선택돼 있다. 경남 점을 누르면 서울이 풀리고 경남이 선택되는데 둘이 한 번에 바뀌므로 서울이 풀리기를 기다린 뒤 경남을 읽는다. 대전 점은 카드 목록에 가려 눌리지 않아(화면 기록) 쓰지 않았다.
- 교육과정: 「자세히 보기」는 새 창을 연다. 누르는 쪽에서 `page.context().waitForEvent('page')` 로 새 창을 받아 그 창에서 제목을 찾는다. 새 창에는 머리 메뉴와 버튼이 없고 제목 h2 하나뿐이다.
- 교육 콘텐츠 알아보기: 영상 플레이어 아래 안내 문단도 눈에 안 보이는 글자(`sr-only`)다. 이름이 붙은 영상 요소로 잡는다.
- 연간 교육일정: 표 위 떠 있는 라벨 넷과 표 왼쪽 칸에 같은 글자(「AI 올인원 1기」 등)가 둘씩 있다. 표 안의 칸으로 좁혀 집는다.
- 지원혜택: 영상 슬라이더 안은 유튜브(다른 출처)라 건드리지 않는다. 틀 안 구독자 수가 바뀌면 이 화면의 해시도 달라질 수 있다.
- 교육 콘텐츠 체험: 머리 메뉴와 바닥글이 없다. 틀 안의 막(overlay)이 다른 곳 클릭을 막아 「체험 시작하기 →」 말고는 누르지 않았다. 「STEP 1 / 6」은 시작 화면에서 보이지 않고 시작 버튼을 눌러야 나타난다.
- 머리 메뉴(비회원): 마우스를 올리기 전에는 하위 링크가 화면 읽기 트리에 없다. 올리고 나서 집는다.

#### 이 화면에서 걸린 것
- 공지사항 검색 뒤: 검색 직전 전체 목록(9건)이 한동안 화면에 남아 있어서, 줄이 바뀌기 전에 읽으면 「모집」이 없는 제목이 보인다. 「모든 제목에 「모집」이 들어 있고 목록이 비어 있지 않다」가 참이 될 때까지 기다린 뒤 읽는다 (`공지사항화면.모든제목에_들어_있는가`).
- 공지사항·FAQ 목록 줄은 줄 전체를 누르는 방식이다. 공지사항 줄에는 「첨부파일」 링크가 같이 있어서 줄 한가운데가 아니라 줄 안의 3단계 제목(heading)을 눌러 링크를 피한다.
- FAQ 「이전」 버튼은 「다음」을 누른 뒤 켜지기까지 시간이 걸릴 수 있고 `isEnabled()` 는 기다리지 않는다. 시험 클릭(`click({ trial: true })`)이 켜질 때까지 기다려 주므로 그것으로 기다린 뒤 읽는다. 시험 클릭은 실제로 누르지 않는다.
- FAQ 답변 영역(`.post-content`)은 닫혀 있을 때 DOM 에 아예 없고 줄을 누르면 줄 안에 붙는다. `isVisible()` 은 없는 요소에도 거짓을 돌려주므로 「닫혀 있다」 확인은 줄이 먼저 보인 뒤에 읽는다.
- FAQ 카테고리 선택지(option)는 보이는 요소로 치지 않는다. 탭 전환이 반영됐는지는 `waitFor({ state: 'attached' })` 로 기다린다.
- 모집안내 올인원 화면에는 1단계 제목 「AI 올인원」 말고도 2단계 제목 「「코디세이 AI 올인원 과정」」 이 있다. 제목 locator 는 1단계 · 이름 정확히 일치로 가른다.
- 세 목록과 모집안내 화면 모두 콘솔에 React 오류 #418(서버가 그린 글과 화면 글이 어긋남)이 한 건 뜬다. 화면 동작에는 영향이 없고 케이스는 보지 않는다.
- 운영 서버의 글 제목 · 번호 · 건수 · 날짜는 바뀐다. 기대값으로 박지 않았고 「첫 글」 「첫 질문 줄」 같은 위치로만 집는다.
