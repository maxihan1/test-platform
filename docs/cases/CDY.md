# CDY — 코디세이 요구사항 표

**덮는 범위** — 기획서가 없다. 운영 화면(https://codyssey.kr)의 시작 주소와 그 메뉴 1단계를 훑어 본 화면만 덮는다.
홈(공지 팝업 · 머리글 · 지역 목록 · 알림신청 창) · 코디세이란 셋 · 과정소개 넷 · 모집안내 둘 · 알림마당 셋(공지사항 · 코디세이 사람들 · FAQ) ·
바닥글 · 이용약관 · 개인정보처리방침 · 길 잃음 · 로그인 · 로그인한 뒤 홈과 내 정보.
**모든 케이스가 미확정이다** — 기대값을 화면에서 읽어 적었다. 기획자가 확인하기 전에는 정식 초록이 아니다.

**안 덮는 것** — 아래는 이번 표에 줄이 없다. 덮은 척하지 않으려고 적는다.

| 안 덮은 것 | 왜 |
|---|---|
| 「교육과정 알림신청 완료」 제출 | 실제 알림 신청이 접수된다. 창을 열고 칸을 채워 버튼이 눌리는지까지만 본다(CDY-009) |
| 회원가입(지역 선택 모달 이후) · 비밀번호 찾기 | 계정을 새로 만들거나 메일을 보낸다 |
| 「내정보 변경하기」 · 「비밀번호 변경」 · 「회원탈퇴」 · 「로그아웃」 | 저장 · 삭제 · 로그아웃이다. 내 정보 화면은 단추가 보이는 것까지만 본다(CDY-033) |
| 내 정보 화면의 성명 · 이메일 · 기관명 같은 값 | 테스트 회원의 개인정보다. 값을 기대값으로 적지 않는다 |
| 「공고문 다운로드」 · 공지 상세의 「미리보기」·「다운로드」 · 공지 「첨부파일」 | 파일을 내려받는다 |
| 대전 · 경남 캠퍼스 화면(`/daejeon/...` · `/gyeongnam/...`) | 같은 화면 틀의 다른 지역 사이트다. 링크 주소만 본다(CDY-013 · CDY-032) |
| 「Family Site」 · 「한국어」 단추 | 다른 출처로 나가거나 언어를 바꾼다. 훑기 허용 목록 밖이다 |
| FAQ 분류 고르기 | 분류를 골라도 목록이 걸러지지 않아 기대값을 정할 수 없다. 아래 「확인 필요」 |
| 「교육 콘텐츠 체험」 화면 | 「×」 하나만 보이는 빈 화면이다. 판정할 것이 없다. 아래 「확인 필요」 |
| 공지 · FAQ · 코디세이 사람들의 목록 내용(제목 · 건수) | 운영자가 글을 올리면 바뀐다. 구조(제목이 보인다 · 열 건 · 검색이 걸러낸다)만 본다 |

**역방향 대조** — 이 표는 **화면만** 보고 적었다(작성 요청 10779). 대조할 문서가 없으므로 `diffs.json` 은 `[]` 이고,
케이스는 전부 `unconfirmed` 꼬리표가 붙는다. 기획자가 볼 원고는 산출물 폴더의 `reverse-spec.md` 다.

## 이 화면에서 걸린 것

- **접근성 이름이 없는 것이 많다.** 로그인 칸은 label 이 없고 알림신청 창 · 로그인한 프로필 단추도 이름이 없다.
  `getByLabel` 대신 `getByPlaceholder` · 부모 `banner`/`dialog` 로 좁힌 `getByRole` 을 썼다
- **사용자 지정 체크박스는 `check()` 가 안 된다.** 진짜 `input` 을 가리는 글자 요소가 클릭을 받는다.
  `getByLabel('전체 동의하기').check()` 는 시간 초과로 죽었다 — 글자를 눌러야 한다
- **홈은 팝업이 클릭을 가로챈다.** 홈에서 무언가를 누르기 전에 공지 팝업을 모두 닫는다. 안 닫으면 로그인 링크 누르기가 시간 초과로 죽는다.
  로그인 화면(`/loginForm`)에는 팝업이 없다
- **검색하면 목록이 비었다가 다시 채워진다.** CDY-025 는 처음에 결과 수가 바뀌는 순간(0건)을 잡아 「결과 없음」으로 읽고 빨개졌다.
  `수 > 0 && 수 !== 전체수` 가 될 때까지 기다린 뒤 읽는다
- **공지 · FAQ 는 건수가 바뀐다.** 「9건」 같은 값을 기대값으로 적지 않고 「한 건 이상」 · 「열 건(FAQ 한 쪽)」 · 「모두 검색어를 포함」 같은 구조로 적었다
- **`npx playwright cli open` 은 `--browser=chromium` 을 줘야 뜬다.** 기본은 상표 붙은 Chrome 을 찾는데 이 컨테이너에 없다
- **테스트 계정이 하나뿐이라 로그인은 한 케이스에서만 한다.** 운영 서버라 계정을 늘릴 수 없고, 같은 계정으로 연속 로그인하면 두 번째 케이스가 홈 머리글의 프로필 단추를 못 띄우고 30초 시간 초과로 죽었다(RUN 20390 · 20393). 로그인이 필요한 화면은 CDY-033 안에서 이어 본다
