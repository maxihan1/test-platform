# DMA 서비스 가이드 요약

## 서비스
데모마켓은 테스트 자동화 플랫폼의 정확도를 재려고 만든 가상 서비스예요. 커뮤니티와 쇼핑몰이 한 사이트에 있고, 자동화가 까다로운 요소를 일부러 넣었어요.
플랫폼의 runner · author 는 http://demo:3002 로 열어요.

## 테스트할 때 지킬 것
- 데이터는 서버 메모리에만 있어서 서버를 다시 켜거나 POST /api/reset 을 부르면 처음 상태로 돌아가요
- reset 은 서버 전체를 되돌려요 — 케이스 안에서 부르면 같이 도는 다른 케이스의 데이터도 지워지니 부르지 않아요
- 흔들림 모드(기본 켜짐)에서는 응답이 늦고 리뷰 조회가 가끔 500 으로 실패해요. 켜졌는지는 GET /api/settings 의 unstable 칸으로 봐요
- 테스트 계정은 서비스 설정의 역할별 계정에 있어요. 비밀번호는 어디에도 적지 않아요

## 배운 것
- 요령 · 데이터 — 로그인 실패를 내는 케이스는 기본 계정 대신 기획서 테스트 계정 아이디 「user2」로 한다 — 기본 계정이 잠기면 그 계정을 쓰는 케이스가 다 깨진다
- 요령 · 데이터 — 주문서 오류 케이스는 결제 수단처럼 뒤 칸을 비워 실제 주문이 생기지 않게 한다
- 요령 · 되돌리기 — 장바구니 기본 줄의 수량을 바꾼 케이스는 끝(finally)에 원래 수량으로 돌리고, 케이스가 담은 상품 줄은 처음과 끝에 지운다
- 요령 · 되돌리기 — server 값으로 앱을 켠 케이스는 끝에 기본 서버 주소로 다시 켠다 — 한 번 받은 주소가 다음 실행에도 남는다
- 요령 · 공용 서버 — 「결제완료」 주문이 필요한 케이스는 새 주문을 만들어 쓴다 — 남이 만든 주문을 취소하면 그 케이스가 깨진다
- 요령 · 기다리기 — 토스트를 연달아 읽는 케이스는 앞 토스트가 사라지거나 글이 바뀐 뒤 읽는다 — 확인 창이 떠 있는 동안 토스트는 화면 글에 안 잡힐 수 있다
