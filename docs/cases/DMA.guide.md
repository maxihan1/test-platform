# DMA 서비스 가이드 요약

## 서비스
데모마켓은 테스트 자동화 플랫폼의 정확도를 재려고 만든 가상 서비스다. 커뮤니티와 쇼핑몰이 한 사이트에 있고, 자동화가 까다로운 요소를 일부러 넣었다.
작성 · 실행 쪽은 http://demo:3002 로 연다.

## 테스트할 때 지킬 것
- 데이터는 서버 메모리에만 있다 — 서버를 다시 켜거나 POST /api/reset 을 부르면 처음 상태로 돌아간다
- 케이스 안에서 POST /api/reset 을 부르지 않는다 — 같이 도는 다른 케이스의 데이터까지 지운다
- 흔들림 모드(기본 켜짐)에서는 응답이 늦게 오고 리뷰 조회가 가끔 500 으로 실패한다. 켜졌는지는 GET /api/settings 의 unstable 칸에 있다
- 테스트 계정은 서비스 설정의 역할별 계정에서 온다. 계정 값을 파일에 적지 않는다

## 배운 것
- 요령 · 공용 서버 — 팜 폰은 adb reverse 가 걸려 있어야 앱 기본 서버 주소(localhost:3002)에 닿는다 — 로그인 화면에 서버 연결 안내가 뜨면 로그인 뒤 화면은 못 본다
- 요령 · 데이터 — 앱에 다른 서버 주소를 줄 때는 intent 추가값 server 로 넘긴다(mobile: startActivity extras) — 받은 주소는 앱이 기억하니 새로 깐 앱에서만 쓴다
- 요령 · 데이터 — 로그인 실패 케이스는 없는 아이디로 쓴다 — 기본 계정 비밀번호를 틀리면 5회에 잠긴다
