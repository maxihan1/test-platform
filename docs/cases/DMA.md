### 이 화면에서 걸린 것

- 입력칸에 `setValue` 만 쓰면 앞 글에 덧붙는다 — 지우고 적는다(`칸에적기`)
- 연락처 칸은 숫자만 남기고 글자 수는 막지 않는다 — 12자도 그대로 들어간다(2026-10-25 탐침)
- 확인 창 · 주소 검색 창이 떠 있는 동안 토스트는 화면 글에 잡히지 않았다 — 창 위 토스트를 보는 케이스(DMA-FN-260 · 357 · 360)는 실패할 수 있다
- 결제 수단 · 쿠폰 라디오의 골라짐 상태는 화면 글에 드러나지 않는다 — 쿠폰 기본값은 「쿠폰 할인 -0원」으로 본다
