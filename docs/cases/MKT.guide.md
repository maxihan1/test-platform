# MKT 서비스 가이드 요약

## 서비스
데모마켓은 테스트 자동화 플랫폼의 정확도를 재려고 만든 가상 서비스예요. 커뮤니티(게시판 · 글쓰기 · 댓글)와 쇼핑몰(상품 · 장바구니 · 주문 · 리뷰)이 한 사이트에 있어요.
로그인 · 모달 · 자동 슬라이드 · 무한 스크롤 · 새 창 · iframe · Shadow DOM · 드래그 앤 드롭 · 가상 스크롤처럼 자동화가 까다로운 요소를 일부러 넣었어요.

## 테스트할 때 지킬 것
- 데이터는 서버 메모리에만 있어요. 서버를 다시 켜거나 `POST /api/reset` 을 부르면 처음 상태로 돌아가요
- `POST /api/reset` 은 서버 전체 데이터를 되돌려요. 케이스 안에서 부르면 같이 도는 다른 케이스의 데이터도 지워지니 케이스 안에서 부르지 않아요
- 흔들림 모드(기본 켜짐)에서는 API 응답이 늦고 리뷰 조회가 가끔 `500 UNAVAILABLE` 로 실패해요. 켜졌는지는 `GET /api/settings` 의 `unstable` 칸으로 알 수 있어요
- 테스트 계정은 서비스 설정의 역할별 계정에서 와요. 케이스와 문서에 비밀번호를 적지 않아요
