# ASO 서비스 가이드 요약

## 서비스
Ashveil 게임의 QA 전용 백오피스(운영툴)다. 탭은 캐릭터 · 확률·결과 고정 · 스폰 · 정리 넷이다.
캐릭터 탭에서 찾기 · 값 바꾸기 · 인벤토리를 다룬다. 화면은 게임 서버의 어드민 API(`/admin/*`)를 부른다.

## 테스트할 때 지킬 것
- 로그인 화면은 아이디 칸 없이 「X-Admin-Key」 칸 하나와 「키 저장」 버튼뿐이다. 대상 서버 테스트 비밀번호가 그 키다(아이디는 쓰지 않는다)
- 같은 게임 서버를 Ashveil 게임 테스트(ASH)가 같이 쓴다 — 「정리」 탭 · 스폰 초기화 · 「새 캐릭터 상태로 초기화」는 남의 데이터를 지울 수 있다
- 케이스는 자기가 만든 캐릭터에만 값을 바꾸거나 초기화한다
- 「확률·결과 고정」을 걸었으면 케이스 끝에 푼다

## 배운 것
- 요령 · 데이터 — 키는 탭 저장소(sessionStorage)에만 남아 로그인 상태 파일로 못 옮긴다 — 케이스마다 키 칸에 비밀값 칸의 키를 넣고 「키 저장」으로 시작한다
- 요령 · 기다리기 — 탭 열기 · 검색 · 저장은 그 조작이 부르는 `/admin/*` 응답이 끝난 뒤 두 프레임 지나 읽는다 — 표와 알림은 응답 본문을 읽은 다음에 그려진다
- 요령 · 공용 서버 — 스폰은 ASO 로 시작하는 임의 ID 로 만들고, 목록에서 줄 하나를 고를 때는 ASO 줄을 뺀다 — 같이 도는 회차가 자기 줄을 지운다
- 요령 · 되돌리기 — 만든 스폰 · 결과 고정은 정리 단계(finally)에서 어드민 API 로 지운다 — 결과 고정 대기열은 서버 공용이라 남이 그사이 비울 수 있어 다른 창에서 볼 때는 다시 넣어 본다
