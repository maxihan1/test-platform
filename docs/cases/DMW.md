#### 이 화면에서 걸린 것

- 글쓰기 · 수정 화면은 다른 주소로 가면 브라우저 이탈 확인(`beforeunload`)이 뜬다 — 쓰다 만 폼에서 `goto` 하면 창이 뜬 채 멈춘다. 대화상자 처리기(`창기록하기`)를 먼저 건다
- 링크 복사는 보안 연결이 아닌 주소(`http://…`)에서 `navigator.clipboard` 가 없어 아무 일도 안 한다 — 케이스는 가짜 클립보드(`클립보드준비`)를 걸고 복사한 글을 읽는다
- 목록 「맨 위로」 버튼은 한 화면 이상 내려야 보이는데 목록이 짧아 화면 높이를 줄여야 한다(`setViewportSize`)
- 입력칸 id 는 그릴 때마다 바뀐다 — 이름표(label)와 역할로 집는다

## 이 화면에서 걸린 것

- 홈 — 공지 팝업 · 쿠키 띠 · 만족도 설문이 화면을 덮어 누르기가 막혔다. 그 창을 안 보는 케이스는 `안내창막기` 를 먼저 부른다
- 모든 화면 — 「머리글 그려짐」이 앞 화면에도 참이라 화면을 옮긴 직후 읽은 값이 앞 화면 것이었다(UI-047). 새 문서가 열린 뒤 머리글을 기다린다
- 게시판 목록 — 보이는 쪽 버튼만 읽어 마지막 쪽을 잘못 골라 30초를 넘겼다(FN-118). 마지막 쪽은 목록 API 의 total 로 정한다
- 주문 취소 모달 — 사유를 바꿔 모달이 닫히면 오류 글을 끝없이 기다렸다(FN-541 부수기). 없으면 빈 글로 읽는다
- 상품 상세 — 로그인 확인 응답 전에 누른 「장바구니 담기」는 아무 일도 안 했다. 머리글이 그려진 뒤 누른다
- 회원 탈퇴 — 탈퇴 뒤 홈으로 가다 가끔(휴대폰 3번 중 1번) 로그인 화면으로 갔다(FN-294). 탈퇴 직후 나간 다른 API 가 401 을 받아 로그인 화면으로 보낸 것으로 보인다 — 케이스는 그대로 두었다
