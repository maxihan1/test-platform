# ARG 서비스 가이드 요약

## 서비스
Unity 「Boss Room」을 Android 로 빌드한 4인 협동 액션 RPG 다. 로그인하면 로비에서 영웅을 선택해 「준비!」를 누르고 던전에서 임프와 보스를 잡는다.
레벨 · 골드 · 가방 · 장비 · 상점 · 일일 퀘스트 · 우편 · 채팅 · 친구 · 파티 · 길드가 있다. 게임 서버는 bossroom.maxihan.com, 계정 · 데이터는 게임 API 서버가 맡는다.

## 테스트할 때 지킬 것
- 게임 케이스는 control_cli SDK 를 넣은 QA 빌드로 실행한다
- 운영 기능(우편 지급 · 제재 · 점검)은 어드민 키로 운영 API(bossroom-api.maxihan.com/opsapi)를 부른다 — 게임 주소가 아니다. 가이드에 경로는 아직 없다
- 게임 서버 · API 서버 · 운영툴이 한 서버를 같이 쓴다. 한 쪽 테스트가 바꾼 상태가 다른 쪽에 그대로 보인다
- 같은 게임 서버에 다른 접속자가 있으면 그 사람까지 준비해야 던전이 열린다. 게임 케이스는 동시에 실행하지 않는다
- 혼자 들어가면 적이 주는 피해가 절반이다
- 점검을 켠 케이스는 끝에서 반드시 끈다
- 제재(정지 · 채팅 금지)는 두 번째 플레이어 계정에만 걸고 끝에서 해제한다. 일반 회원 계정은 건드리지 않는다
- 테스트가 쓴 공지는 제목을 [QA] 로 시작하고 끝에서 삭제한다. 지급 · 회수 시험은 두 번째 플레이어 계정으로 하고 재화는 골드다
- 계정마다 캐릭터는 하나이고 처음 로그인하면 아이디와 같은 이름으로 생긴다

## 배운 것
- 요령 · 데이터 — 구매 케이스는 골드를 쓰고 다시 채울 운영 지급 경로가 없다 — 「체력 물약」처럼 싼 상품을 쓰고 산 것은 끝에 판다
- 요령 · 기다리기 — 상점 목록 아래쪽 줄(「체력 물약」)은 창 아래로 잘려 그대로 누르면 사지지 않는다 — 목록을 끌어 올려 화면 안에 들어온 뒤 누른다
- 요령 · 공용 서버 — 다른 접속자가 로비에 있으면 「준비!」를 눌러도 던전이 안 열린다 — 던전 케이스는 접속 인원 「1명 접속 중」을 먼저 확인한다
- 요령 · 기다리기 — 채팅 줄은 같은 글이 여러 번 쌓여 글자로 찾으면 둘 이상이 걸린다 — 새 줄은 줄 번호(Row[i])로 기다리고 읽은 글자로 견준다. 「[알림]」 · 「[전체]」의 대괄호는 주소 글자에 넣지 않는다
- 요령 · 되돌리기 — 우편 삭제는 되돌릴 수 없다 — 첨부 없는 우편을 지우는 케이스는 우편이 있어야 하는 케이스보다 뒤에 실행되게 둔다
- 요령 · 공용 서버 — 로그인한 채 게임이 꺼지거나(실행 끝 · 강제 종료 · 와이파이 끊김) 접속 중에 같은 계정으로 또 「게임 시작」을 누르면 그 계정이 「같은 계정으로 이미 접속 중」으로 40분 넘게 막힌다(로비 접속 인원에는 없다) — 케이스는 접속이 끝난 뒤 다음 조작을 하고, 실행을 마칠 때는 메인 메뉴로 나가 둔다
