# MTW 서비스 가이드 요약

## 서비스
Mastodon v4.7.5 웹을 포크해 https://mastodon.maxihan.com 에 띄운 단독 서버다. 다른 서버와 연합하지 않는다.
글 쓰기 · 부스트 · 좋아요 · 팔로우 · 알림 · 검색 · 리스트 · 설정을 브라우저에서 쓴다.

## 테스트할 때 지킬 것
- 계정 — 일반 회원 qa_user1 · 두 번째 사용자 qa_user2 · 관리자 qa_admin(Owner). 로그인 아이디는 이메일이다
- 서버 메일(가입 확인 · 암호 재설정)은 서버 안 Mailpit 에만 쌓인다. 메일 링크를 눌러야 하는 흐름은 막힐 수 있다
- 테스트가 만든 글 · 미디어 · 리스트 · 필터는 케이스 끝에서 지운다. 웹 · 앱 · 운영툴 · API 테스트가 같은 서버를 쓴다
- 계정 상태를 바꾸는 일(정지 · 침묵 · 역할 변경 · 삭제)은 qa_user2 에게만 하고 끝에서 되돌린다. qa_admin · qa_mod · qa_user1 은 건드리지 않는다
- 시드는 이름(계정 이름 · 글 내용 · 리스트 이름)으로 찾는다. 글 번호 · 계정 번호 같은 숫자 ID 를 케이스에 넣지 않는다
- 개수는 「n개 이상」으로 확인한다. 같은 실행의 다른 케이스가 글 · 알림 · 리스트를 더한다
- 시드는 바꾸지 않는다(신고 해결 · 승인 · 정지 · 삭제). 바꾸는 요구는 같은 꼴의 데이터를 직접 만들어 확인하고 끝에서 지운다
- 일회용 계정 하나는 케이스 하나만 쓰고 끝(finally)에서 바꾼 것을 되돌린다
- 가입 케이스의 사용자명은 tc_signup 으로 시작한다. 준비 때 그 계정을 모두 지운다

## 배운 것
- 요령 · 데이터 — 테스트 계정은 화면 언어 설정이 비어 있어 브라우저 언어(영어)로 뜬다 — 케이스 첫 절차에서 helpers/page-setup.helper.ts 의 한국어로(page) 를 부른다
- 요령 · 공용 서버 — qa_user1 의 홈 · 필터 · 표시 이름에는 다른 앱 테스트가 남긴 글과 값이 섞여 있다 — 목록 첫 줄을 집지 말고 케이스가 단 표식 글자나 시드 이름으로 찾는다
- 요령 · 데이터 — 새 계정이 필요하면 tc_signup 으로 가입한 뒤 관리자 화면 「신원 확인」으로 이메일 확인을 마친다(helpers/signup.helper.ts 확인된새계정만들기)
- 요령 · 기다리기 — 가입 양식은 연 지 3초가 지나야 받는다 — 제출 전에 연 시각부터 3초를 넘겼는지 기다린다
- 요령 · 기다리기 — 웹 앱 목록은 화면 밖 글을 빈 자리로만 그린다 — 시드 글은 API 로 주소를 찾아 상세 화면으로 연다
- 요령 · 되돌리기 — 30초에 끊긴 케이스는 finally 가 안 돌아 바꾼 값(관계 · 설정 · 리디렉션 · 가져오기 대기)이 남는다 — 바꾸는 케이스는 첫 절차에서 지난 실행의 흔적부터 풀고 시작한다
- 요령 · 기다리기 — 글 수정 화면은 원문(/api/v1/statuses/:id/source) 응답이 온 뒤 본문을 채운다 — 그 응답을 기다린 뒤 고친다
- 요령 · 기다리기 — 좋아요 · 북마크 · 고정 · 부스트는 그 요청의 응답을 기다린 뒤 화면을 옮긴다 — 바로 옮기면 느린 망에서 요청이 끊긴다
- 요령 · 데이터 — 영상 첨부는 helpers/status-api.helper.ts 의 작은영상() 을 쓴다 — 짧은 가짜 바이트는 서버가 500 을 낸다
- 요령 · 기다리기 — 「수신함 확인하기」의 「확인 링크 다시 보내기」는 화면을 연 뒤 30초 꺼져 있다 — page.clock 으로 앞당긴다
- 요령 · 데이터 — 가입을 마친 창에는 가입 세션이 남아 로그인 화면이 /auth/setup 으로 간다 — 가입은 새창열기 로 연 창에서 한다
- 요령 · 되돌리기 — 관리자 이메일 도메인 차단은 메일 서버(MX)가 있는 도메인이어야 가입에서 막힌다 — 끝에 목록에서 지우고 확인 창을 수락한다
- 요령 · 공용 서버 — 암호 변경은 계정당 10분 10회 한도다 — 한 회차에 바꾸는 횟수를 줄이고 돌려 보기를 몰아서 돌리지 않는다
- 요령 · 데이터 — 비회원이 없는 태그 주소를 열면 서버 404 다 — 빈 태그 안내는 일반 회원이 그 태그를 팔로우해 만든 뒤 비회원 창에서 연다(끝에 팔로우 해제)
- 요령 · 기다리기 — 로그인 화면이 오가는 동안에는 초기상태바꾸기 를 걸지 않는다 — 로그인 응답 문서를 가짜 응답이 가로챈다
- 요령 · 기다리기 — 리스트 「만들기」는 양식 이동을 시도해 뒤 기다림이 멈춘다 — click({ noWaitAfter: true }) 로 누른다
- 요령 · 데이터 — 큰 CSV 가져오기는 화면 양식 대신 계정설정화면.가져오기양식보내기 로 보내고, 확인 화면에서 「취소」로 남기지 않는다
- 요령 · 되돌리기 — 일회용 계정 이동 계정의 리디렉션은 /settings/migration 「리디렉트 취소하기」로 푼다
- 요령 · 공용 서버 — 같은 계정으로 여러 곳에서 로그인하면 오래된 로그인이 몇 분 안에 풀린다 — 둘째 계정 창은 필요할 때 새로 로그인한다
