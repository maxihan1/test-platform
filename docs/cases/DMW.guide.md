# DMW 서비스 가이드 요약

## 서비스
데모마켓은 커뮤니티(게시판 · 글쓰기 · 댓글)와 쇼핑몰(상품 · 장바구니 · 주문 · 리뷰)이 한 사이트에 있는 시험용 가상 서비스다.
로그인 · 모달 · 자동 슬라이드 · 무한 스크롤 · 새 창 · iframe · Shadow DOM · 끌어다 놓기 · 가상 스크롤처럼 자동화가 까다로운 요소를 일부러 넣었다.

## 테스트할 때 지킬 것
- 자료는 서버 메모리에만 있다 — 서버를 다시 켜거나 POST /api/reset 을 부르면 처음 상태로 돌아간다
- POST /api/reset 은 서버 전체를 되돌려 같이 도는 케이스의 자료까지 지운다 — 케이스 안에서 부르지 않는다
- 흔들림 모드가 기본으로 켜져 있다 — API 응답이 늦게 오고 리뷰 조회가 가끔 500 UNAVAILABLE 로 실패한다(GET /api/settings 의 unstable 칸)
- 테스트 계정은 서비스 설정의 역할별 계정(일반 회원 · 관리자)을 쓴다 — 비밀번호는 어디에도 적지 않는다

## 배운 것
- 요령 · 데이터 — 장바구니 · 주문 · 글 · 댓글 · 문의 · 회원 정보를 바꾸는 케이스는 일회용 회원(`helpers/account.helper.ts`)으로 한다 — 기본 회원 자료를 바꾸면 같이 도는 케이스가 깨진다
- 요령 · 데이터 — 로그인 실패는 일회용 회원으로만 낸다 — 같은 아이디로 5번 틀리면 10분 잠겨 기본 계정을 쓰는 케이스가 다 막힌다
- 요령 · 데이터 — 입력칸 id 는 화면을 그릴 때마다 무작위로 바뀐다 — `#id` 로 집지 않고 이름표 · 역할로 집는다
- 요령 · 기다리기 — 홈 공지 팝업 · 쿠키 띠 · 만족도 설문이 화면을 덮는다 — 그 창을 보지 않는 케이스는 화면을 열기 전에 `안내창막기(page)` 를 부른다
- 요령 · 기다리기 — 머리글은 로그인 확인 응답 뒤에 그려지고 그 전에 누른 「장바구니 담기」는 아무 일도 안 한다 — `머리글.그려질때까지()` 뒤에 누르고, 좁은 화면은 `메뉴열기()` 로 햄버거부터 연다
- 요령 · 기다리기 — 「머리글 그려짐」은 앞 화면에도 참이다 — 화면을 옮긴 직후에는 새 화면에만 있는 요소부터 기다린다
- 요령 · 기다리기 — 게시판 목록 · 글 상세 · 글쓰기는 불러오는 동안 `aria-busy` 가 붙는다 — 그 속성이 사라질 때까지 기다린다
- 요령 · 기다리기 — 글쓰기에 쓰다 만 내용이 있으면 다른 주소로 갈 때 이탈 확인 창이 떠 멈춘다 — 대화상자 처리기를 먼저 건다
- 요령 · 기다리기 — 상품 목록을 맨 아래까지 내린 채 필터 · 정렬을 바꾸면 다음 12개를 또 불러온다 — 위로 올린 뒤 바꾼다
- 요령 · 기다리기 — 주소 검색 새 창은 결과를 고르면 스스로 닫혀 그 누르기가 「창이 닫혔다」 오류로 끝날 수 있다 — 창이 닫혔으면 고른 것으로 본다
- 요령 · 기다리기 — 관리자 회원 표는 가상 스크롤이라 줄을 다시 그린다 — 아이디 검색 뒤 그 줄이 보일 때까지 기다리고, 휴대폰에서는 줄 안 버튼을 `dispatchEvent('click')` 로 누른다
- 요령 · 기다리기 — 모달이 열리면 뒤 화면이 잠긴다 — 스크롤 잠금은 맨 위로 올린 뒤 PageDown 키로 본다(휴대폰은 마우스 휠이 안 된다)
- 요령 · 데이터 — 같이 도는 케이스가 글을 계속 올린다 — 내 글 제목에 겹치지 않는 낱말을 넣고 검색 주소(`/board?field=title&q=…`)로 찾는다
- 요령 · 데이터 — 알림은 화면을 열 때와 10초마다만 받아 온다 — 댓글을 단 뒤 알림을 보려면 화면을 새로 연다
- 요령 · 데이터 — 주문서는 장바구니 「주문하기」(`/checkout?items=<줄 번호>`)나 「바로 구매」로 들어가야 상품이 있다 — 주소만 열면 「주문할 상품이 없습니다」다
- 요령 · 데이터 — 배송 희망일 2일 뒤 · 14일 뒤가 일요일과 겹치는 날이 있다 — 날짜 경계 케이스는 `page.clock` 으로 오늘을 평일로 옮긴 뒤 쓴다
- 요령 · 되돌리기 — 주문을 만드는 케이스는 재고 10 이상 상품을 무작위로 고르고 끝에 취소 API 로 주문을 취소한다 — 재고 1개 상품(12번)을 사거나 같은 상품 재고를 넓게 재면 같이 도는 케이스가 깨진다
- 요령 · 되돌리기 — 배너 순서 · 노출과 홈 공지 팝업 설정을 바꾸는 관리자 케이스는 원래 값을 먼저 읽어 두고 `finally` 에서 돌려놓는다 — 홈을 보는 다른 케이스가 그 값에 기댄다
- 요령 · 공용 서버 — `/api/settings` 의 `unstable` 이 꺼져 있으면 추천 상품이 섞이지 않고 설문이 8초쯤에 뜬다 — 그 둘을 보는 케이스는 그 설정에 기댄다
- 요령 · 공용 서버 — 대상 주소가 https 가 아니라 `navigator.clipboard` 가 없다 — 링크 복사는 가짜 클립보드를 걸어 읽는다
