### 이 화면에서 걸린 것

- 운영 화면은 `#ops-main` 의 aria-busy 가 빠진 뒤에 읽는다 — 틀 부품 `다그려질때까지()`
- 토스트는 3초 뒤 사라지고 같은 글이 쌓인다 — 앞 조작의 토스트가 남아 있을 수 있으니 판정 전에 사라질 때까지 기다리거나(`detached`) 글자 수 「0 / 100」 되돌아오기처럼 다른 앵커를 쓴다
- 장바구니는 `.or()` 로 「표 또는 빈 안내」를 기다리면 안 된다 — 둘 다 HTML 에 있어 한 요소로 안 잡힌다. 「불러오는 중」이 사라질 때까지 기다린다
- 쿠폰 「주기」를 빠르게 두 번 누르면 쿠폰이 두 장 생긴다(막는 장치가 없다)

### 이 화면에서 걸린 것 — 합친 뒤 마지막 돌려 보기

- 환경 화면 배너 스위치는 저장할 때 배너 목록 전체를 그 화면이 처음 읽은 값으로 다시 쓴다 — PC 와 휴대폰이 나란히 돌면 서로의 배너를 되돌려 DMO-FN-163 이 3번 중 1번 빨갰다. PC 는 배너, 휴대폰은 「홈 공지 팝업」 스위치를 쓰게 나눴다
- 주문서 「주소 검색」 팝업은 결과를 누르면 스스로 닫힌다 — 마우스 누르기가 끝나기 전에 창이 닫혀 「Target page, context or browser has been closed」가 났다(DMO-FN-291). 결과 단추에 누르기 이벤트를 보내고 팝업이 닫히기를 기다린다
