# ARI 서비스 가이드 요약

## 서비스
Boss Room 게임의 계정 · 데이터 API 서버(anymmo-webserver 포크)다. /api 는 게임이 쓰는 계정 · 캐릭터 · 아이템 · 우편 API, /opsapi 는 운영툴이 쓰는 운영자 API(유저 조회 · 제재 · 지급 · 회수 · 공지 · 점검 · 기록)다.

## 테스트할 때 지킬 것
- 인증 넷은 서로 바꿔 쓸 수 없다. 게임 계정 토큰은 /api/login, 운영자 토큰은 /opsapi/login 으로 받는다
- 고정 운영 키는 몸통 `admin` 으로만 쓴다. 만료가 없어 정기 실행에 맞고, 기록에는 운영자 qa-admin-key 로 남는다. /api 에는 안 통한다
- 게임 서버 토큰은 게임 서버 전용이라 케이스에서 쓰지 않는다
- 계정 역할은 「일반 회원」 · 「두 번째 플레이어」 · 「운영자」 셋이다
- 게임 서버 · API 서버 · 운영툴이 한 서버를 같이 쓴다. 한쪽 테스트가 바꾼 상태가 다른 쪽에 그대로 보인다
- 점검을 켠 케이스는 끝에서 반드시 끈다. 켜 둔 채 끝나면 그 뒤 게임 로그인이 모두 막힌다
- 제재(정지 · 채팅 금지)는 「두 번째 플레이어」에만 걸고 끝에서 해제한다. 「일반 회원」은 건드리지 않는다
- 테스트가 쓴 공지는 제목을 [QA] 로 시작하고 끝에서 삭제한다
- 지급 · 회수 시험은 「두 번째 플레이어」 캐릭터로 하고 재화는 골드(Gold)다. 아이템 이름은 게임 안 이름(체력 물약 · 사슬 갑옷)을 그대로 쓴다

## 배운 것
- 요령 · 데이터 — 틀린 비밀번호 · 계정 설정 변경 시험은 웹 가입(/Account/Create)으로 만든 일회용 회원으로 한다. 가입 바로 뒤 /api/login 과 웹 로그인이 된다
- 요령 · 데이터 — 웹 화면 폼은 위조 방지 토큰이 있어야 제출된다. 같은 요청 도구로 폼을 먼저 열어 토큰과 쿠키를 받은 뒤 보낸다
- 요령 · 데이터 — 가입 케이스는 qa_tmp_ 로 시작하는 계정을 서버에 남긴다. 계정 삭제 기능이 없다
- 요령 · 데이터 — 지급 · 작업 기록 · 아이템 흐름 이력은 지워지지 않아 size 한도를 볼 만큼 쌓여 있다. 계정 · 캐릭터는 몇 개뿐이라 그 목록의 100 · 50 한도는 개수로 못 가른다
- 요령 · 공용 서버 — 운영툴 시험도 같은 서버의 점검 · 제재 · 지급을 바꾼다. 개수는 자기가 만든 것과 한도 관계로만 본다
- 요령 · 공용 서버 — 「두 번째 플레이어」 제재는 여러 케이스가 걸고 푼다. 걸 때 409 면 남은 같은 종류를 풀고 다시 걸고, 정리할 때는 건 종류만 푼다
- 요령 · 되돌리기 — 점검은 바꾸기 전에 읽어 둔 설정으로 finally 에서 되돌린다. 공지는 만든 번호를 모아 finally 에서 삭제하고, 지급은 응답이 200 이면 회수한다
- 요령 · 기다리기 — 작업 기록 · 아이템 흐름은 기록 번호 차례로 오고, 나란히 쓴 기록은 at 이 1밀리초 안쪽에서 뒤섞인다. 최신순은 1초 여유를 두고 본다
- 요령 · 데이터 — 데이터 API 시험 캐릭터는 없는 계정 번호로 만들고 finally 에서 지운다. 캐릭터 이름은 서버 전체에서 겹치면 400 이라 고유값을 붙인다
- 요령 · 데이터 — 친구 목록은 캐릭터를 만들 때 서버가 같이 만들고 지울 때 같이 지운다. 친구 목록 시험은 시험용 캐릭터로 한다
- 요령 · 데이터 — 지급 우편 첨부와 아이템 인스턴스 번호는 2^53 을 넘어 JSON 숫자로 읽으면 깨진다. 응답 글자에서 번호를 글자째 꺼내 다룬다
- 요령 · 되돌리기 — 일부를 가져간 지급 우편은 회수해도 남는다. finally 에서 우편 번호로 따로 지운다
