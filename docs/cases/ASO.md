| 값 바꾸기 칸 | 골드 · 레벨 · 성향 · 위치 x · z 숫자 칸 | `골드칸` … `위치z칸` — 까닭: 칸에 라벨이 이어져 있지 않아 CSS(`#e-gold` 등)로 집는다 |
| 결과 고정 · 대기 중 | 강화 결과 고르기 · 「추가」 · 「대기 중」 글자 | `강화고정고르기` · `강화고정추가` · `대기중` — 까닭: 선택 상자 · 글자에 이름이 없어 CSS(`#f-enh` · `#f-queue`)로 집는다 |
| 강화 확률 · 드랍 확률 | 목표 칸 · 봇 전리품 · 악명 봇 칸 | `강화확률목표칸들` · `봇전리품칸` · `악명봇칸` — 까닭: 이름 없는 칸이라 CSS 로 집는다 |
| 스폰 칸 · 스폰 줄 | 「스폰 추가·수정」 칸들과 스폰 목록 줄 | `스폰ID칸` · `스폰구역` · `스폰몬스터` · `스폰x칸` · `스폰z칸` · `스폰줄(ID)` — 까닭: 구역 · 몬스터 · 좌표 칸에 이름이 없어 CSS 로 집는다 |
| 정리 버튼 | 「삭제」 · 「바닥 아이템·봇 초기화」 | `계정삭제버튼` · `월드초기화버튼` — 누르면 확인 창이 뜨고 케이스는 늘 취소한다 |

## 이 화면에서 걸린 것

- 키가 탭 저장소에만 남아 상태 파일로 로그인을 옮길 수 없다 — 케이스마다 키를 다시 넣는다
- 표 · 알림은 `/admin/*` 응답 본문을 읽은 뒤 그려진다 — 응답이 끝나고 두 프레임 뒤에 읽는다
