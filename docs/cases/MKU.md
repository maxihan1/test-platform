## 이 화면에서 걸린 것

- 칸 아래 오류 글자는 칸을 적은 뒤 다른 칸으로 옮겨야 뜬다. 케이스는 `적고옮기기` 로 적고 blur 한다
- 글자 수 한도를 넘는 글자는 입력칸이 버린다. 길이는 `inputValue().length` 로 읽는다
- 휴대폰 칸은 숫자가 아닌 글자를 버린다 (`abc12` 는 `12`)
- 관심 분야 4번째를 누르면 체크가 안 되고 토스트가 뜬다. 켜진 개수는 `켜진관심분야수` 로 센다
- 홈 추천 상품은 `/api/products?size=8` 로 받아 다시 열어도 순서가 같다 (MKU-FN-042 가 이 차이로 빨갛다)
- 공유 계정(`TARGET_LOGIN_ID`)은 쓰지 않는다. 로그인이 필요한 케이스는 `새회원정보` · `회원가입` 으로 새 회원을 만들고 끝에 `가입자정리하기` 로 지운다
- 주문 내역 화면은 목록이 500 이어도 표 자리를 비워 둘 뿐 글을 넣지 않고 토스트로만 알린다. 토스트가 3초쯤 뒤 사라지므로 응답을 받은 뒤 바로 읽는다
- 지도는 iframe 안이라 `frameLocator` 로 잡는다
- 실행할 때 `PLATFORM_BASE_URL` 에 대상 서버 주소를 준다 — `playwright.config.ts` 가 그 값을 baseURL 로 읽는다
- 공유 테스트 계정(김데모)은 주문 · 장바구니가 들어 있어 케이스가 쓰지 않는다 — 새 회원을 만들고 끝에 탈퇴한다
- 장바구니 「선택 삭제」 확인 창에서 「확인」을 눌러도 삭제 요청이 나가지 않는다(차이 목록)
- 머리글은 80px 이 아니라 81px 부터 붙고 48px 로 줄어든다(차이 목록)
- MKU-FN-292(POST /api/reset)는 서버 자료를 초기 상태로 되돌린다 — 다른 케이스와 동시에 돌리지 않는다
