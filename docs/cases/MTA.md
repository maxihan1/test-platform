### 이 화면에서 걸린 것

- 목록 안 요소를 셀 때 부모 꼴(`childSelector`)을 쓰면 UiAutomator 가 첫 요소 하나만 준다 — 조각 · 항목 · 줄 수를 늘 1로 세어 경계 케이스가 끝없이 더했다. 세는 주소는 id 만 쓴다
- 대체 텍스트 1만 자를 한 번에 넣으면 팜이 요청 크기로 막는다(HTTP 413) — 1000자씩 나눠 넣는다
- 맞춤 탭 · 앱 안 웹 화면은 주소 줄에 호스트만 보이고 팜에 Chromedriver 가 없어 경로를 못 읽는다
