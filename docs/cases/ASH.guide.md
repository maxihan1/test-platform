# ASH 서비스 가이드 요약

## 서비스
Ashveil(애쉬베일)은 Unity 로 만든 안드로이드 MMORPG 다. 클라이언트와 .NET 서버가 같은 shared 규칙 · 카탈로그를 쓰고, 골드 · 아이템 · 강화 · 드랍 판정은 서버가 한다.
QA 빌드에는 게임 안을 읽는 SDK 와 GM 콘솔이 들어 있고, QA 서버에는 어드민 API(`/admin/*`)와 GM API(`/gm/*`)가 열려 있다.

## 테스트할 때 지킬 것
- 케이스 준비(캐릭터 · 골드 · 아이템 · 위치 · 결과 고정 · 확률 설정 · 정리)는 어드민 API 로 한다 — 걸어가거나 사냥해서 만들지 않는다
- 작성용 로그인 계정은 지우지 않는다 — 정리(`/admin/cleanup`) 앞머리에 `qh` 를 쓰지 않는다
- 결과 고정 큐 · 확률표는 서버 전체 공용이고 서버 메모리에만 있다 — 바꾼 케이스는 끝에 되돌리고, 나란히 돌리면 서로 가져갈 수 있다
- 골드 변동은 늘 원장에 남는다(원장 합계 = 현재 골드)

## 배운 것
- 요령 · 데이터 — 케이스마다 일회용 계정 · 캐릭터를 어드민 API 로 만들고 `finally` 에서 그 아이디로 정리한다 — 앞머리는 `zqa<번호>` 로 짓고 `qh` 는 쓰지 않는다
- 요령 · 데이터 — 새 캐릭터 가방에는 시작 아이템이 이미 있어 수량 · 칸을 따지는 케이스는 `장비빼고비우기` 뒤 필요한 것을 직접 준다
- 요령 · 데이터 — 서버가 주는 스탯에는 장착 장비가 섞여 있다 — 직업 표와 견줄 때는 장비를 모두 푼 뒤 읽는다
- 요령 · 데이터 — 캐릭터 이름은 서버 전체에서 하나뿐이라 짧은 이름은 한글 음절로 지어 다른 케이스와 부딪히지 않게 한다
- 요령 · 데이터 — 400 오류는 본문이 빈 때가 있다 — 오류 코드는 `오류코드()` 로 읽고 본문을 곧장 JSON 으로 풀지 않는다
- 요령 · 공용 서버 — 결과 고정 큐 · 확률표 · 드랍 설정 · 스폰 표는 서버 전체 공용이다 — 시작할 때 고정을 비우고 `finally` 에서 되돌린다
- 요령 · 공용 서버 — 월드 다시 두기 · GM 봇 다시 두기는 봇 · 바닥 아이템을 통째로 바꾼다 — 봇을 쓰는 케이스와 나란히 돌리지 않는다
- 요령 · 공용 서버 — 정리(`/admin/cleanup`)는 앞머리로 지운다 — 짧은 아이디 · 짧은 앞머리는 다른 케이스 계정까지 지울 수 있어 그 케이스만 쓰는 앞머리로 짓는다
- 요령 · 공용 서버 — 디바이스 팜 폰의 게임이 qa 서버 주소에 닿지 못했다(로그인 「서버에 연결할 수 없습니다」) — 로그인 뒤 창이 필요한 케이스는 보류로 두고 서버 규칙은 API 로 본다
- 요령 · 기다리기 — 같은 스폰 다시 처치 · 봇 부활처럼 시간이 걸리는 규칙은 `될때까지` 로 다시 보고하며 걸린 시간을 견준다 — 봇 부활 케이스는 한 건이 90초 가까이 걸린다
