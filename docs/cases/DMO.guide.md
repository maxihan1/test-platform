# DMO 서비스 가이드 요약

## 서비스
데모마켓은 플랫폼 정확도를 재려고 만든 가상 서비스다. 커뮤니티(게시판 · 글쓰기 · 댓글)와 쇼핑몰(상품 · 장바구니 · 주문 · 리뷰)이 한 사이트에 있다.
모달 · 자동 슬라이드 · 무한 스크롤 · 새 창 · iframe · Shadow DOM · 드래그 앤 드롭 · 가상 스크롤처럼 자동화가 까다로운 요소를 일부러 넣었다.

## 테스트할 때 지킬 것
- 플랫폼 실행기 · 작성기는 http://demo:3002 로 연다
- 데이터는 서버 메모리에만 있다 — 서버를 다시 켜거나 POST /api/reset 을 부르면 처음 상태로 돌아간다
- 케이스 안에서 POST /api/reset 을 부르지 않는다 — 서버 전체를 되돌려 같이 도는 다른 케이스의 데이터도 지운다
- 흔들림 모드(기본 켜짐)에서는 API 응답이 늦고 리뷰 조회가 가끔 500 으로 실패한다 — 켜졌는지는 GET /api/settings 의 unstable 칸에 있다
- 테스트 계정은 서비스 설정의 역할별 계정에서 받는다 — 비밀번호를 케이스 · 문서에 적지 않는다

## 배운 것
- 요령 · 데이터 — 회원 상태 · 알림 · 쿠폰 · 시험 데이터를 바꾸는 케이스는 가입 API 로 만든 일회용 회원에게 한다 — 기본 계정을 바꾸면 같이 도는 케이스가 깨진다
- 요령 · 데이터 — 화면 입력칸의 id 는 그릴 때마다 무작위로 바뀐다 — 라벨 · 역할 · 이름으로 고른다
- 요령 · 기다리기 — 운영 화면은 본문(#ops-main)의 aria-busy 가 빠진 뒤에 읽는다 — 그 전에는 표가 비어 있다
- 요령 · 기다리기 — 토스트는 곧 사라진다 — 누른 직후 그 글자의 토스트를 기다려 읽는다
- 요령 · 데이터 — 시험 데이터로 만든 주문은 재고가 있는 앞 번호 상품을 같이 쓴다 — 재고 증감을 보는 케이스는 쇼핑몰 주문 API 로 뒤쪽 상품에 주문을 따로 만든다
- 요령 · 공용 서버 — PC 와 휴대폰이 나란히 돈다 — 상품 · 배너처럼 공용 자료를 바꾸는 케이스는 기기마다 다른 대상을 고른다
- 요령 · 공용 서버 — 재고 · 답변 대기 건수 · 맨 위 공지는 같이 도는 케이스가 바꾼다 — 조작 직전 · 직후에 바로 읽고, 「맨 위」는 내 것 위에 더 늦은 것만 있는지로 본다
- 요령 · 기다리기 — 운영 창(문의 답변 · 공지 쓰기)은 뜬 직후 초점이 아래 버튼으로 옮겨 간다 — 초점이 창 안에 잡힌 뒤 칸을 채운다
- 요령 · 기다리기 — 확인 창은 닫힌 뒤에도 잠깐 남는다 — 다음 창을 열기 전에 앞 창이 떨어질 때까지 기다린다
- 요령 · 기다리기 — 운영 표는 거르기 · 저장 뒤 통째로 다시 그려진다 — 그 요청의 응답을 기다린 뒤 다시 읽는다
- 요령 · 기다리기 — 쇼핑몰 종 목록은 화면을 연 때 받은 알림만 보인다 — 알림을 먼저 보내고 화면을 연다
- 요령 · 되돌리기 — 문의와 공지는 지우는 길이 없다 — 문의는 끝에 답변을 달아 「답변 대기」에서 빼고, 공지는 숨긴다
- 요령 · 되돌리기 — 시험 데이터로 만든 결제완료 주문은 끝에 운영자 취소로 바꿔 재고를 돌려놓는다
- 요령 · 데이터 — 회원 목록은 가입 순이라 새 일회용 회원은 마지막 쪽에 있다 — 아이디로 검색해 한 줄로 줄인 뒤 다룬다
