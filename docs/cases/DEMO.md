# DEMO — 완료한 할 일 지우기 요구사항 표

자료 셋을 한 표로 합쳤다.

- `기획서-완료지우기.pdf` — 요구 R1 · R2
- `정책-완료지우기.txt` · `정책-완료지우기.docx` — P1. **두 파일의 글자가 같다.** 어긋남 없음

대상 주소: `https://demo.playwright.dev/todomvc`

**덮는 범위** — 「Clear completed」 버튼이 나타나는 조건 · 사라지는 조건 · 눌렀을 때 무엇이 지워지고 무엇이 남는가.
**안 덮는 것** — 버튼의 **위치**(「목록 아래에」)는 판정하지 않는다. 자료에 위치 기준(순서·간격)이 없다 ·
완료를 되돌려 버튼이 사라지는 것 · 전부 완료한 뒤 지우기 · 모바일 화면 (자료가 모바일을 명시하지 않았다).

**합친 줄 (규칙 R15)** — 요구 2 · 3 · 4경계는 전제와 조작이 같고 조작이 **삭제**라 한 케이스로 합친다.
합친 이름: 「Clear completed」 를 누르면 완료한 할 일만 사라지고 완료하지 않은 할 일은 남으며 버튼도 사라진다.
새로 만드는 케이스라 **저장된 입력값 묶음이 없다** — 기대값 칸이 늘어나 다시 볼 묶음이 없다.

**요구 4 정상의 조작이 「할 일 추가」인 이유** — 빈 목록에서는 목록 아래 영역이 통째로 안 그려져
버튼이 **언제나** 안 보인다. 할 일이 한 건 있어 그 영역이 그려진 상태에서 버튼이 없어야 P1 을 확인한 것이다.
