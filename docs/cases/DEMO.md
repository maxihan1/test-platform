## 이 화면에서 걸린 것

- **「Clear completed」를 누른 뒤 남은 개수 문구는 안 바뀐다.** 안 끝낸 수는 누르기 전에도 뒤에도 「1 item left」다.
  그래서 **누른 뒤의 앵커로 `todo-count` 를 못 쓴다** — 묵은 화면에서 바로 통과한다.
  **버튼이 사라지는 것**을 앵커로 쓴다 — `getByRole('button', { name: 'Clear completed' }).waitFor({ state: 'hidden' })`.
  탐침에서 누른 뒤 버튼이 DOM 에서 빠지는 것(0개)을 확인했다
- **할 일이 둘이면 완료 표시가 둘이다.** 도구는 `getByRole('listitem').filter(...)` 를 뱉는데,
  사전의 `todo-item` 으로 줄을 고르고 그 안의 완료 표시를 잡는다
- **탐침은 `--browser=chromium` 을 붙여 연다** (2026-09-25 · 작성 에이전트 컨테이너).
  `npx playwright cli -s=probe open '<주소>'` 는 기본값이 **크롬 채널**이라
  `Chromium distribution 'chrome' is not found at /opt/google/chrome/chrome` 으로 죽는다.
  컨테이너에는 **번들 크로미움만** 깔려 있다. `--browser` 가 받는 값 목록에 `chromium` 은 안 적혀 있지만 **받는다.**
  케이스 실행(관문 3)은 영향이 없다 — `playwright.config.ts` 의 `desktop` 이 `devices['Desktop Chrome']` 이라
  같은 번들 크로미움을 탄다. **화면 문제가 아니라 환경 문제라 `docs/LEARNINGS.md` 로 옮길 것을 제안한다** —
  이 체인은 `tests/demo` 와 이 파일 밖을 못 고친다
- **관문 3 은 `tests/demo` 통째로 돌리지 않는다** (§6 ★). 이 폴더에는 **일부러 실패하는 `DEMO-002`** 가 있어
  빨강이 정상값이 된다. 이 표의 세 파일만 이름으로 찍어 돌린다
