## 이 화면에서 걸린 것

- 월드에 들어간 직후 구역 이름 글(ZoneText)이 잠깐 비어 있다 — 월드 화면 객체가 채워질 때까지 기다린다
- 게임은 월드에 들어갈 때 가방 · 골드를 받아 온다 — 어드민 준비는 게임 입장 앞에 둔다
- 강화 창 장비 목록은 일곱 줄쯤 넘으면 화면 밖이라 눌리지 않는다 — 확률 ② 케이스는 칼 다섯 자루로 0% 를 먼저, 100% 를 뒤에 돈다
- 강화 창에서 이미 고른 장비 줄을 다시 눌러도 선택이 유지된다 — 장비 고르기는 고른 상태면 다시 누르지 않는다
- 봇 이름표는 화면 가까이 있는 봇만 뜬다 — 이름표가 보이는 봇을 골라 쓴다
- 상점 판매 줄의 「모두 판매」는 겹치는 아이템(물약) 줄에만 있다
- GM 콘솔 목록 아래쪽 「조회」는 화면 밖이라 눌러도 반응이 없다 — 그 줄은 「보이고 누를 수 있다」로 둔다
- 캐릭터끼리 pk-attack 은 서버가 「INVALID_TARGET」으로 막는다 — PK 대상은 봇이다
- 꽉 찬 가방 케이스는 같은 템플릿 스택이 남아 있으면 전리품 · 바닥 아이템이 그 스택에 합쳐진다 — 채우기 전에 겹칠 아이템을 지운다
