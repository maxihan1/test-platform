# ASA 서비스 가이드 요약

## 배운 것
- 요령 · 데이터 — 가입 · 로그인 · 갱신 케이스는 케이스 안에서 무작위 아이디(앞머리 `asat`)로 일회용 계정을 만들어 쓴다 — 대상 서버에 등록된 계정이 없고, 만든 계정은 어드민 정리(`/admin/cleanup` 앞머리 `asat`)로만 지운다
- 요령 · 데이터 — 4자 아이디 경계처럼 앞머리를 못 다는 길이는 무작위 글자로만 만든다 — 같은 아이디가 이미 있으면 409 로 빨개지므로 고정 아이디를 쓰지 않는다
- 요령 · 데이터 — 캐릭터가 필요한 케이스는 `helpers/game.helper.ts` 의 플레이어만들기로 일회용 계정과 캐릭터를 새로 만든다 — 캐릭터 이름은 서버 전체에서 겹치면 막혀 무작위 이름을 쓴다
- 요령 · 공용 서버 — 봇은 서버 전체가 같이 쓰고 처치하면 60초 동안 쓰러져 있다 — 살아 있는 봇 가운데 무작위로 골라 다른 케이스와 겹치지 않게 하고, 불꽃 군주의 폐허 봇은 봇 리셋 케이스만 쓴다
- 요령 · 되돌리기 — GM 강화 확률표 · 드랍 설정은 서버 전체 값이다 — 바꾼 케이스는 끝에 바꾼 줄만 기획서 기본값으로 되돌리고, 강화 실패 · 파괴는 확률표를 바꾸지 않고 +9 장비를 되풀이 강화해 만든다
- 요령 · 기다리기 — 같은 캐릭터가 강화를 0.5초 안에 다시 부르면 「COOLDOWN」으로 막힌다 — 강화 도우미가 0.6초 쉬고 다시 부른다
- 요령 · 데이터 — 한 계정에 캐릭터를 몇 개만 만들어도 막힌다 — 직업 셋을 한 계정에 만드는 데까지만 쓰고, 더 필요하면 계정을 나눈다
- 요령 · 데이터 — 가방이 다 찬 캐릭터를 만들 때는 시작 빨간 물약 묶음을 먼저 판다 — 남겨 두면 물약 전리품 · 바닥 물약이 그 묶음에 합쳐져 다 찬 가방에도 들어간다
- 요령 · 데이터 — 봇이 바닥 아이템을 줍게 할 때는 아이템과 같은 구역의 봇을 고른다 — 다른 구역 봇이면 막힌다
- 요령 · 데이터 — 강화를 여러 번 하는 케이스는 GM 골드를 먼저 준다 — 새 캐릭터 골드로는 +3 까지 강화 비용이 모자란다
- 요령 · 데이터 — 장비를 견주는 케이스는 가방에서 강화 수치까지 맞춰 아이템을 고른다 — 처음 받은 +0 장비와 GM 으로 받은 장비가 한 가방에 같이 있다
- 요령 · 데이터 — 경험치를 얻는 처치를 한 캐릭터로 되풀이하면 레벨이 올라 다음 줄 전제가 깨진다 — 「1레벨 캐릭터」 줄마다 일회용 캐릭터를 따로 만든다
- 요령 · 공용 서버 — 봇 처치를 되풀이하는 케이스는 이미 처치한 봇을 빼고 다음 봇으로 넘어간다 — 「BOT_DEAD」면 다른 케이스가 먼저 쓰러뜨린 것이다
- 요령 · 공용 서버 — 결과 고정(`/admin/forced`)은 서버 전체가 같이 쓰고 넣은 차례대로 뒤에 쌓인다 — 넣은 케이스가 바로 강화하고 끝에 남은 것을 비운다
- 요령 · 공용 서버 — 어드민 정리 · 스폰 · 설정 API 는 서버 전체 값을 바꾼다 — 정리는 계정이 하나도 없는 무작위 앞머리로만, 스폰은 `ASAT-` 임시 번호를 만들고 지우고, 설정 바꾸기는 빈 요청으로만 부른다
