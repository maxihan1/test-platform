# DMN 서비스 가이드 요약

## 배운 것
- 요령 · 데이터 — 케이스마다 새 회원 아이디(`dmn-` 앞머리 · 시각 · 난수)로 기기를 만들고 끝에 지운다 — 보내기 제한이 회원마다 세어져 다른 케이스 푸시와 섞이지 않는다
- 요령 · 공용 서버 — 대상 서버 자료가 처음 상태로 돌아가 번호가 `dev_000001` · `psh_000001` 부터 다시 매겨진다 — 번호를 박지 않고 없는 번호는 `<앞>_dmn_none_<시각>` 꼴로 짓는다
- 요령 · 기다리기 — 접수(202)한 푸시는 푸시 조회를 0.5초 사이로 다시 불러 QUEUED 가 아니게 될 때까지 기다린다 — 바로 읽으면 늘 QUEUED 다
- 요령 · 데이터 — Idempotency-Key 는 고객사마다 오래 남아 짧은 키는 실행끼리 겹친다 — 1자 키는 고정 회원 · 고정 내용으로 보내 겹쳐도 처음 푸시를 다시 받게 한다
- 요령 · 데이터 — 같은 키 · 같은 내용으로 다시 보낸 요청은 보내기 제한에 세지 않는다 — 제한 케이스는 키 없이 보낸다
- 요령 · 되돌리기 — 기기 지우기는 JSON 머리 없이 부른다(빈 JSON 본문이면 400) — 정리는 절차가 멈춰도 돌도록 끝 정리 자리에 둔다
