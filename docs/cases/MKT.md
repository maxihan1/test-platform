## 이 화면에서 걸린 것

- 모든 화면 — 입력칸 id 가 그릴 때마다 `f-xxxx` 로 바뀐다. `#id` 로 잡으면 다음 실행에서 깨진다 — 라벨 · `[data-k]` 로 잡는다
- 홈 — 공지 팝업 · 쿠키 띠 · 8초 뒤 만족도 설문 · 늦게 오는 이벤트 띠가 겹쳐 뜬다. 그 기능을 보지 않는 케이스는 `방해막기` 로 미리 막는다
- 홈 — 머리글 붙음은 `scrollY > 80` 이라 80px 에서는 안 붙는다(차이 D1). 추천 상품 순서는 서버 설정 `unstable` 이 꺼져 있으면 안 섞인다(차이 D4)
- 게시글 상세 — 대상 서버가 http 라 `navigator.clipboard` 가 없다. 링크 복사는 가짜 클립보드로만 확인한다(MKT-FN-154)
- 상품 목록 — 품절 카드의 「품절」 글자는 DOM 글자가 아니라 CSS `::after` 로 그린다 — 화면에서 읽을 때 `getComputedStyle(카드, '::after')` 를 본다
- 장바구니 — 「선택 삭제」 확인 뒤 화면 스크립트 오류(`e.currentTarget` 이 null)로 삭제 요청이 안 나간다(차이 D2 · MKT-FN-089 빨강)
- 첫 회원으로 비밀번호를 틀리지 않는다 — 5번이면 10분 잠겨 다른 케이스가 모두 깨진다. 틀리는 케이스는 두 번째 회원이나 새 계정으로 한다

#### 이 화면에서 걸린 것

- 클립보드: 대상 서버 주소가 `http://demo:3002` 라 보안 문맥이 아니다. `navigator.clipboard` 가 없어 「링크 복사」 가 아무 일도 안 한다. 케이스는 `클립보드준비()` 가 가짜 클립보드를 심어 둔다(`helpers/draft-board.helper.ts`)

- 좋아요 · 댓글 삭제 버튼은 요청 중 이름이 「처리 중」 으로 바뀐다. 「버튼이 사라질 때까지」를 앵커로 쓰면 바로 통과하니 댓글 개수 제목으로 기다린다
- 등록 응답은 이동 뒤에는 본문을 못 읽는다. 만든 글 번호는 이동한 상세 주소에서 읽는다

#### 이 화면에서 걸린 것

- 모달이 닫힐 때와 확대 보기가 닫힐 때는 0.3초 뒤에 요소가 지워진다. 닫힘을 앵커로 기다릴 때는 `body:not(.no-scroll)` 처럼 판정과 다른 신호를 쓴다 — 까닭: 본문 클래스가 닫힘과 같은 시각에 빠지는 신호뿐이다
- 읽기 전용인 우편번호 · 주소 칸은 `fill` 이 거절한다. 칸을 직접 채워야 하는 준비에서는 `evaluate` 로 값을 넣고, 주소 검색 창 자체를 보는 케이스만 새 창으로 고른다
- 가격 슬라이더는 `fill` 로 10,000 단위 값만 받는다. 500,001 처럼 단위에 안 맞는 값은 키보드(`End` · `→`)로 끝까지 밀어 본다
- 상품 목록의 「품절」 글자는 CSS 로 그린 것이라 DOM 글자에 없다. 덮개와 글자는 `getComputedStyle(카드, '::after')` 로 읽는다
- 「선택 삭제」 의 「확인」 은 눌러도 삭제 요청이 나가지 않는다 — 앱 쪽 결함이다(`MKT-FN-089` 가 빨간 채로 그 자리를 가리킨다)
