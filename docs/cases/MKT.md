### 이 화면에서 걸린 것

- 머리글은 자바스크립트가 늦게 그린다 — 머리글이 그려지기 전에 아래 요소의 위치를 읽으면 64px 어긋난다. 위치를 읽기 전에 머리글의 다른 요소를 앵커로 기다린다
- 입력칸 `id` 는 그릴 때마다 무작위(`f-xxxx`)라 `#id` 로 잡지 않고 `getByLabel` 로 잡는다
- 홈은 쿠키 띠 · 공지 팝업(처음 방문) · 이벤트 띠(늦게 끼어든다) · 설문 모달(5~15초 사이)이 겹친다. 케이스마다 주제가 아닌 것은 먼저 닫는다. 타이머는 `page.clock` 으로 당긴다
- 대상 서버는 `http://demo:3002` 비보안 주소라 `navigator.clipboard` 가 없다 — 「링크 복사」는 화면에서 복사도 토스트도 일어나지 않는다. `MKT-FN-050` 은 메모리 클립보드로 바꿔 돈다(모킹)
- 틀린 비밀번호로 5번 로그인하면 계정이 10분간 잠긴다. 공용 계정으로는 틀린 로그인을 하지 않고 임시 회원을 쓴다. `MKT-FN-023` 은 실행마다 잠긴 임시 회원이 하나 남는다
- 임시 회원 · 주문 · 문의를 만드는 케이스는 끝에 탈퇴 · 주문 취소로 치운다. 문의는 탈퇴로 같이 지워지는지 모른다
- `MKT-FN-089`(`POST /api/reset`)는 서버의 모든 데이터를 처음으로 되돌린다 — 다른 케이스와 동시에 돌리지 않는다
- 관리자 비밀번호를 받을 길이 없어 관리자 화면 · 관리자 API 케이스는 이번 판에서 뺐다(제외 표)
- 상품 상세의 리뷰 조회는 실제로도 네 번에 한 번쯤 500 으로 실패한다(REQ-API-005). 「다시 시도」 뒤 실제 응답을 받는 케이스는 200 이 올 때까지 다시 받는다 (`MKT-FN-110`)
- 홈 화면 스냅샷 해시는 읽을 때마다 달라진다. 타임세일 카운트다운 · 배너 · 늦게 끼어드는 이벤트 띠가 글자에 들어 있어서, 같은 화면을 연달아 두 번 떠도 다르다(2026-10-03 실측). 해시가 다르다고 화면이 바뀐 것은 아니다
