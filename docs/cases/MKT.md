### 이 화면에서 걸린 것

- 입력칸 id 는 그릴 때마다 `f-xxxx` 로 바뀐다. 이름표(label) · 역할 이름 · `data-k` 로 잡는다
- 공지 팝업 · 쿠키 띠 · 설문 모달이 뒤 화면의 클릭을 가린다. 그 요구를 보지 않는 케이스는 `localStorage` 를 미리 채우거나 닫고 시작한다
- 대상 서버가 http 주소라 `navigator.clipboard` 가 없다. 「링크 복사」 는 클립보드를 가짜로 바꿔야 토스트가 뜬다(MKT-FN-071)
- 글쓰기 중 다른 주소로 이동하면 `beforeunload` 확인 창이 떠 이동 명령이 멈춘다. 확인 창은 받은 자리에서 닫는다
- 아이디(12자) · 비밀번호(20자) · 연락처(11자) 칸은 입력 단계에서 글자 수를 막는다. 한도를 넘긴 값을 적는 경계 줄은 만들 수 없어 표에서 뺐다
- 작업자 여럿이 같은 서버에 동시에 요청하면 응답이 늦어져 「1.5초를 넘지 않는다」 판정이 한 번 빨개진다. 단독 실행에서는 통과한다
