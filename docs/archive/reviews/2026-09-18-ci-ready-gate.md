## G — TDD

**RED → GREEN 이 실제로 돌았다.**

```
판별식 추가 직후:  빨강  ← 「tpx-merge 에 gh pr checks --watch 가 없다」
```

단언은 **순서**를 본다 — `gh pr ready` < `gh pr checks --watch` < `gh pr merge`.

## 실측 — 이 PR 로 직접 쟀다

설계를 추측으로 두지 않았다. 같은 브랜치에서 세 실행이 나왔다.

```
08:07  초안 푸시     skipped   ← 일을 안 한다
08:08  Ready 전환    success   ← 진짜 돌았다
08:09  초안 복귀 뒤   skipped   ← 다시 일을 안 한다
```

요청한 네 줄이 그대로 성립한다.

**한 가지는 예상대로가 아니었다.** `skipped` 는 필수 체크를 **만족시킨다** —
보호를 건 뒤에도 `mergeStateStatus=CLEAN` 이었다. 그래도 그때는 초안이라 GitHub 이 막는다.

`gh pr ready` 직후 **5초 미만** 동안만 `CLEAN` 이고 그 뒤 `BLOCKED` 로 바뀐다.
그 창을 뚫으려면 「Ready」와 「병합」 버튼을 손으로 연달아 눌러야 한다.
체인은 `gh pr checks --watch` 로 그 구간을 지나가지 않는다.
