## 중대

### G6 — 화면을 브라우저로 한 번도 안 열었다
어디:   전 범위. 특히 `CaseListParts.tsx` 의 값 칩과 `Shell.tsx` 의 서비스 색 표시
무엇:   스킨을 통째로 바꿨는데 **실제로 렌더한 적이 없다.** 검사는 전부 jsdom 이고
        jsdom 에는 레이아웃 엔진이 없어 **폭·겹침·줄바꿈을 원리적으로 못 본다.**
왜 문제: 계획 5단계의 검증 ② 가 「375px 에서 한 번 연다」를 요구한다.
        LEARNINGS 2026-09-17 의 「케이스명이 한 글자씩 세로로 흐른다」가 2026-09-19 에 재발했고,
        그 항목이 **「창 리사이즈로는 확인할 수 없다. 375px iframe 을 띄워야 처음 보인다」**고
        방법까지 적어 뒀다. 이번 변경은 **바로 그 목록 행에 값 칩을 더한다** — 같은 함정이다.
무엇이 되어 있나: 구조적 방어는 넣었다 — `.title{min-width:0}`(기존) + `.chip-val{max-width:100%;min-width:0}`
        + `.chip-val i{overflow-wrap:anywhere}` + `.chips{flex-wrap:wrap}`.
        **그러나 눈으로 본 적이 없다.** 방어가 맞는지는 렌더해야 안다
고칠 곳: 병합 전에 `npm run dev` 로 띄우고 375px 로 연다. 같은 자리에서 G6 의 나머지도 본다 —
        새로고침 없이 서비스를 바꿨을 때 네모와 경계선 색이 따라 바뀌는가
