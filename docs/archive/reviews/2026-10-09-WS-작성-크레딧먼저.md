        작성 §3.6 은 여전히 「Claude 구독 토큰은 넘긴다」 · 「자식은 Claude 구독 토큰을 든다」만 말하고, §7 `LIMIT` 줄은 「Claude 구독 한도」와 그 문구(`limit reached` · `hit your limit`)만 든다.
        크레딧 바닥 문구(`credit balance` · `spend limit` · `workspace api usage limit`)로 `LIMIT` 이 되는 것은 §7 에 없다.
        §7 · 데이터모델 · 리포팅은 「구독으로 돌므로 청구는 0 · 환산 비용은 참고값」이라 적었는데, 크레딧으로 돈 건의 `cost_usd` 는 실제로 깎인 크레딧이다.
        맥 경로는 공통/6 §9 「★ 맥의 열쇠는 설정값으로 만들지 않는다 — 환경변수는 셸 기록 · 프로세스 목록에 샌다」인데 SETUP ④ 는 「맥도 같은 이름의 환경 변수」라고 적었다.
왜 문제: 도중에 크레딧이 떨어진 건이 화면에 「구독 한도」로 뜬다. 사용자는 구독 한도가 풀릴 때까지 기다리게 되는데, 실제로는 바로 「이어하기」를 누르면 구독으로 이어진다.
        다음 세션은 §7 `LIMIT` 줄을 정본으로 읽고 크레딧 문구를 모른 채 한도 판정을 고친다.
        토큰 대시보드의 「청구액 아님」 설명이 크레딧 건에서는 틀린 말이 된다.
        맥에서 비밀값을 환경 변수로 받을지는 명세가 이미 「안 받는다」로 정한 것과 부딪친다 — 정할 사람은 사용자다(CLAUDE.md §1.4).
