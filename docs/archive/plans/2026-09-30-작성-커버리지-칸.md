PR #119 가 원장 대조와 셈을 만들었지만 **셈은 PR 본문 글뿐**이다 — 요청마다 몇 % 를 덮었는지 화면에서도 대시보드에서도 못 본다.

게이트 1 에서 사용자가 「빠지면 멈추고 이어서 작성으로 채우는」 흐름 대신 **「멈추지 말고 기록만, 나중에 확인」**을 골랐다.
남은 요구는 ③ 「남은 요구로 이어 작성」이 맡는다 — 그래서 ③ 의 범위를 「다음 요청」에서 **「다음 요청 · 빠짐」**으로 넓힌다(③ 계약 블록 글만 고친다, 상태는 `대기` 그대로).

## 게이트 1 에서 정한 것 (2026-09-30 사용자 · 검토 지적 반영)

| 무엇 | 정한 것 |
|---|---|
| 빠졌을 때 | **올리기를 거절하지 않는다.** 빠짐 · 형식 오류가 있어도 PR 을 올리고 셈에 남긴다. 형식 오류 줄의 번호는 빠짐으로 센다. PR 본문 머리 = 셈 줄 + `⚠️ 빠짐 N — <앞 10개>` · `⚠️ 형식 오류 N — <앞 3개>`. 빠짐 목록 파일(`ledger-missing.json`) · 프롬프트의 「앞 실행이 빠뜨린 번호」 줄 · 그 이어하기 절차를 걷는다 |
| 셈 단위 | **실행 하나** · 그 실행이 뽑은 **전체 원장** 기준. 이어서 작성 · 다시 작성도 원장을 다시 뽑아 대조한다 |
| 보류와 케이스 | **`held` 는 `cased` 안에 든다** — `cased` 는 케이스 파일로 덮인 번호(보류 포함). `held` 는 **덮은 케이스가 전부 보류**인 번호. `total = cased + Σexcluded + missing` |
| 보류를 모를 때 | DONE 인데 `result.held` 키가 없으면 `held: 0` · `heldUnknown` 이거나 DONE 이 아니면(보류 스캔은 DONE 때만 돈다) `held: null` · 칸 NULL |
| 언제 싣나 | 원장 대조를 한 뒤의 **DONE 과 `STOPPED · REJECTED`**(대조 뒤 비밀번호 · push · PR 실패 같은 거절). FAILED · 대조 전 끝내기에는 안 싣는다 |
| 셈 모양 | 원장 있음 `{ total, cased, held, excluded: {종류: 수}, missing: [번호], later: [번호], unread?: [자료 이름] }` · 원장 없음 `{ none: '<까닭>' }`(칸은 전부 NULL). `later` = 「다음 요청」 제외 번호 · `unread` = 원장에 못 넣은 자료 |
| 서버 모양 검사 | 틀리면 `400 { error: 'BAD_COVERAGE' }`. 넷은 0 이상 정수 · `held` 는 정수나 null · `excluded` 는 종류 이름(1~20자) → 0 이상 정수, 10종까지 · 번호 · 자료 이름 글은 1~200자 · `cased + Σexcluded + missing 길이 = total` · `held ≤ cased` · `later 길이 ≤ Σexcluded` · `none` 은 1~500자이고 다른 키와 같이 오지 않는다. **개수 상한은 두지 않는다**(원장 크기에 상한이 없다 — 본문 크기 상한이 막는다). **종류 이름 목록은 서버에 옮겨 적지 않는다**(정본 `scripts/authoring-ledger-check.ts`) |
| 셈이 거절되면 | 에이전트가 **셈만 뺀 같은 몸**을 한 번 더 보낸다 — FAILED 로 바꾸지 않는다(PR · 보류 · 이어하기를 잃지 않게). 보내기 전에 에이전트가 서버의 `커버리지모양검사` 를 import 해 먼저 돌리고, 틀리면 셈을 빼고 로그에 남긴다 |
| 칸 짝 CHECK | `authoring_request_coverage_check` — 네 칸(`total` · `cased` · `excluded` · `missing`)이 전부 NULL 이거나 전부 차고 전부 `>= 0` 이고 `total = cased + excluded + missing` · `held IS NULL OR (cased IS NOT NULL AND held BETWEEN 0 AND cased)` |
| 상세 `coverage` | 요청한 그 행의 `result.coverage` 를 **읽을 때도 모양 검사**해 싣는다 · 아니면 null. `runs[]` 에는 안 싣는다 |
| 화면이 읽는 행 | **머지를 뺀 최신 작성 실행**(`AuthoringDetail.tsx` 의 `작성` — 차이 표와 같다). 머지 대기 · 반영 중 · 반영 끝에도 줄이 남는다 |
