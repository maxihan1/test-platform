**계약 변경: 없음** — 응답 모양 · 오류 코드 그대로. 거절 사유 문장과 판별 규칙만 는다.

## 왜

지금 판별은 fixture(`page` 등)나 그 절차 안 변수에서 시작하지 않는 호출과 `new` 를 보면 판정이 숨었을 수 있다고 보고 절차를 「애매함」으로 친다.
Page Object 를 쓰면 `new 로그인화면(page)` · `로그인.열기()` 가 전부 여기 걸려 **건너뛸 절차가 0 이 된다.** 그래서 #129 는 기능 테스트에 Page Object 를 막아 뒀다.
Page Object 파일은 K7 이 `verify` · `test.step` 을 막으므로 판정을 숨길 수 없다 — 믿어도 된다.
