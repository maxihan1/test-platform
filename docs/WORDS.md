# 표준 낱말

같은 뜻을 화면마다 다른 말로 부르지 않게 정한 말이다. 사용자가 고른 말만 적는다 — 여기 없는 말을 새로 정해야 하면 사용자에게 묻고 줄을 더한다.

| 어디 | 무엇을 따르나 | 막는 장치 |
|------|---------------|-----------|
| 화면 문구 (`apps/admin/src/web/messages/*.ts` 의 한글 키) | §1 · §2 | `apps/admin/src/web/words.test.ts` — 늘 도는 검사(`test:always`)라 문서만 고친 push 를 빼고 매번 돈다 |
| Grafana 대시보드 (`infra/grafana/provisioning/dashboards/*.json` 의 패널 제목 · 설명 · 표 칸 이름 · 표에 찍히는 값) | §1 · §2 | 같은 `words.test.ts` |
| 리포트(PDF · 엑셀 · HTML) · 워드 · 엑셀 내보내기 · 알림 글 (서버 코드) | §1 · §2 | 없음 — 서버 글자는 로그와 섞여 기계로 못 가른다 |
| AI 에이전트 글 — 단발 AI 다섯(수정 AI · PRD 초안 · 노트 · 성능 AI · E2E 흐름 후보) | §1 · §2 | 없음 — 지시문을 만들 때마다 이 표를 읽어 싣는다(`scripts/authoring-prompt-common.ts` 「낱말」) |
| AI 에이전트 글 — 작성 에이전트 자식(케이스 · PRD 문장 · 결과 요약) | §1 · §2 | 없음 — 처음 여는 `korean-ai-tells.md` 가 이 표를 가리킨다 |
| 명세 · 문서 · 시안 | §1 · §2. 결정 기록에 남은 옛 말은 그대로 둔다 | 없음 |
| 대화 · 커밋 · PR | §2 + CLAUDE.md §4 「저장소에서만 쓰는 말은 흔한 말로」 | 없음 |

### 개발자 말 풀어 쓰기 (2026-10-19 사용자 · WEB-F4-14 시작 질문 승인)

화면 글자만 바꾼다 — 서버가 주는 문장 · 코드 식별자는 그대로다.

| 쓰는 말 | 쓰지 않는 말 | 비고 |
|---|---|---|
| 지금까지 반영된 케이스를 기준으로 | 새 main 위에서 · 지금 main 위에서 · 서버가 main 을 못 받아 왔다 | 「서버가 반영된 케이스를 아직 못 받아 왔습니다」 |
| 검사가 완료되길 기다려 반영하므로 | CI 를 기다려 합치므로 | |
| 다른 변경과 부딪혔으면 | 다른 PR 과 충돌했으면 | `PR` 은 그대로 쓴다 |
| 중복 | 겹침 | 오류 안내 문장. 호환성의 「요소 겹침」(결함 종류)은 다른 뜻이다 |

**그대로 쓰는 말** — 모킹 · URL 패턴 · JSON 경로 · trace(QA 가 직접 쓰는 말이다). 진행 글 「겹치는 케이스를 보는 중」은 서버가 정한 글이라 이 표 밖이다.

| 테스트가 못 가거나 AI 가 못 본 화면 | 미점검 화면 | 못 본 화면 |
| 전체 화면 중 세트가 지나는 화면의 몫 | 화면 커버리지 | 덮은 화면 |
| 세트의 어떤 케이스도 안 지나는 화면 | 미커버 화면 | 빠진 화면 |
| 한 대씩 차례로 | 순차 실행 | 하나씩 |
| 같은 모델은 한 대만 | 모델별 1대 | — |
| 케이스를 선택한 길 | 자동 선택 · 직접 추가 | 자동 몫 · 사람 몫 |

성능 화면의 업계 말(가상 사용자 · TPS · 램프업 시간 …)은 도메인/성능 §3.9 「화면 낱말 — 성능 업계 말」 표가 정본이다.

「휴대폰」은 테스트 장비가 아니라 일상 말이라 둔다(「휴대폰 메뉴」 · 「휴대폰에 설치해서 쓰는 앱」). 호환성의 모양 칩도 「디바이스 · 폴더블 · 태블릿」이다(2026-11-08 사용자 — 「스마트폰」 말고 디바이스로 통일). 「쿠폰」 · 「옮기기」 · 「생기기」는 낱말 안에 든 글자라 무늬가 비켜 간다. GitHub 의 「PR 병합」 · gRPC 의 「패키지.서비스/메서드」는 그 도구의 말이라 둔다. 「근거」는 「PRD 관리」의 출처 목록에서만 「출처」로 쓰고 「추천 근거」처럼 이유를 뜻하면 둔다.
API 가 주는 값은 바꾸지 않는다(CLAUDE.md §3) — 그런 키는 검사 파일의 예외 목록에 까닭과 같이 적는다.
