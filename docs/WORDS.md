# 표준 낱말

같은 뜻을 화면마다 다른 말로 부르지 않게 정한 말이다. 사용자가 고른 말만 적는다 — 여기 없는 말을 새로 정해야 하면 사용자에게 묻고 줄을 더한다.

| 어디 | 무엇을 따르나 | 막는 장치 |
|------|---------------|-----------|
| 화면 문구 (`apps/admin/src/web/messages/*.ts` 의 한글 키) | §1 · §2 | `apps/admin/src/web/words.test.ts` — 화면을 고친 push 에서 돈다 |
| 명세 · 문서 · 시안 | §1 · §2. 결정 기록에 남은 옛 말은 그대로 둔다 | 없음 |
| 대화 · 커밋 · PR | §2 + CLAUDE.md §4 「저장소에서만 쓰는 말은 흔한 말로」 | 없음 |

## 1. 화면 낱말

마지막 칸은 검사가 읽는 정규식이다. 줄을 더하면 검사가 저절로 본다.

| 뜻 | 쓰는 말 | 쓰지 않는 말 | 걸러 내는 무늬 |
|----|---------|--------------|----------------|
| 테스트를 돌리는 폰 · 태블릿 | 디바이스 (실제 디바이스 · 가상 디바이스) | 기기 · 폰 · 스마트폰 | `(?<!옮)기기\|(?<!휴대\|쿠)폰` |
| 직전 통과 → 이번 실패 · 직전 실패 → 이번 실패 · 직전 실패 → 이번 통과 | 회귀 실패 · 기존 실패 · 해결 | 깨짐 · 새로 깨짐 · 계속 깨짐 · 고쳐짐 · 신규 실패 · 연속 실패 | `깨[짐진져지]\|고쳐짐\|신규 실패\|연속 실패` |
| 화면 표시가 어긋남 | UI 결함 의심 · 글꼴 표시 오류 · 렌더링 오류 · 텍스트 잘림 · 요소 겹침 | 깨짐 | 위 줄이 막는다 |
| 사람이 아니라고 판정한 의심 | 결함 아님 | 오탐 · 헛짚음 | `오탐\|헛짚` |
| 테스트가 지나는 화면의 몫 | 커버 · 화면 커버리지 · 미커버 | 덮다 · 덮은 · 빠진 화면 | `덮\|빠진 화면` |
| 테스트가 못 가거나 AI 가 못 본 화면 | 미점검 화면 | 못 본 화면 | `못 본 화면` |
| 목록을 조건으로 줄이기 | 필터 | 거르기 · 거르개 · 거른 | `거르\|거른` |
| 저장할 때마다 쌓이는 묶음 | 버전 · 버전 기록 · 현재 버전 | 판 · 판 이력 · 지금 판 | `(?<![가-힣])판(?![정단매])` |
| 되살릴 수 없게 없애기 | 삭제 | 치우기 · 치운 | `치우\|치운` |
| 케이스를 고른 길 | 자동 선택 · 직접 추가 | 자동 몫 · 사람 몫 | `자동 몫\|사람 몫` |
| 카드 제목 · 안내의 할 일 | 다음 단계 | 해야 할 일 | `해야 할 일` |
| 날짜 단위 집계 | 일별 | 하루별 | `하루별` |
| 디바이스 관제 제품 | Device VISION | 팜 · 디바이스 팜 | `팜` |
| 이슈 트래킹 제품 | Issue Bunker (화면은 `btsName.ts` 상수로 쓴다) | BTS | `BTS(?![_A-Z])` |
| 개발용 안쪽 말 | 쓰지 않는다 — 사용자가 아는 말로 푼다 | 관문 · 원장 | `관문\|원장` |

「휴대폰」은 테스트 장비가 아니라 일상 말이라 둔다(「휴대폰 메뉴」 · 「휴대폰에 설치해서 쓰는 앱」). 호환성의 모양 칩도 「디바이스 · 폴더블 · 태블릿」이다(2026-11-08 사용자 — 「스마트폰」 말고 디바이스로 통일). 「쿠폰」 · 「옮기기」는 낱말 안에 든 글자라 무늬가 비켜 간다.
API 가 주는 값은 바꾸지 않는다(CLAUDE.md §3) — 그런 키는 검사 파일의 예외 목록에 까닭과 같이 적는다.
